## Phase 2-2 — 複数キーワード Product Anchors (カテゴリアンカー + CEPシード抽出) (未確定)

> **分岐条件**: ユーザーが入力したキーワードが **複数(カンマ区切り)** の場合、Phase 2 の代わりにこのプロンプトへ進入します。
> 単一キーワードであれば既存の Phase 2(`Product Anchors`)をそのまま使用します。
> 入力は Phase 1-2(複数キーワード基本情報の事前調査)の成果物を受け取ります。

### Phase 2(単一)との相違点

| 項目      | Phase 2 (単一キーワード)              | Phase 2-2 (複数キーワード・本ドキュメント)                                                          |
| --------- | ---------------------------------- | ------------------------------------------------------------------------------------------ |
| 入力      | 単一の製品名 + 基本調査サマリー       | **複数キーワード** + Phase 1-2 サマリー                                                           |
| category  | 製品全体を代表する名詞 2-4個    | 同一。ただし、**カテゴリ層のキーワードからのみ** 導出                                              |
| 出力の追加 | `{ category }`                     | `{ category, cep_seeds }` — **効能/上位概念キーワードを捨てずに `cep_seeds` として保存**       |
| コアルール | 「feature/perspective は category ではない」 | 同一ルールを維持 + **効能語は削除・抽象化を禁止し、`cep_seeds` として排出**して Phase 3・4 が消費       |

### 目的

複数キーワードから **ベクトル検索用のカテゴリアンカー** を抽出します。
ただし、効能・属性・上位概念のキーワードはカテゴリへまとめて捨てるのではなく、**`cep_seeds`(CEP・ナノインテントのシード)として分離保存** します。
効能キーワード(例: `주름개선`, `피부 탄력개선`)は消費者の欠乏を明らかにする CEP 発掘の核心的な手がかりだからです。

### コア概念

- **category**: 以後のベクトル検索に使われる製品カテゴリアンカー。**カテゴリ層のキーワードからのみ** 導出し、
  効能・属性・上位概念・ブランド/モデル名は含めない。
- **cep_seeds**: category に入れなかった効能/属性/上位概念のキーワードを **原文のまま保存** したリスト。
  Phase 3(CEP Insight)・Phase 4(CEP Trigger・ナノインテント)で欠乏/状況探索のシードとして使用される。
  効能は化粧品だけの要素ではなく、**あらゆるドメイン(家電・食品・サービスなど)** で現れる
  (家電: `발열 적은` · 食品: `혈행개선` · サービス: `재고관리`)。
- **粒度分離の原則**: 「効能は category ではない」という排除ルールと、「効能は捨てない」という保存ルールを
  同時に満たすために、category と cep_seeds の **2つのフィールドに分離** する。
- **cep_seeds なし許容の原則**: 入力がカテゴリ・ブランド中心で効能/上位概念が一つもない場合は
  `cep_seeds` を **空配列 `[]`** とし、入力になかったキーワードを **でっち上げない**。

### 入力変数

| 変数                         | 説明                                | 例                                                         |
| ---------------------------- | ----------------------------------- | ------------------------------------------------------------ |
| `{{product_name}}`           | **複数キーワード(カンマ区切り)** の原本入力 | `주름개선 화장품, 주름개선, 안티에이징, 노화방지 화장품, 피부 탄력개선` |
| `{{country}}`                | 国コード                           | `kr`                                                         |
| `{{response_language}}`      | 出力言語 (ko/en/ja)                | `ko`                                                         |
| `{{basic_research_summary}}` | Phase 1-2 結果サマリー                 | (マークダウンテキスト)                                            |

### 出力形式

JSON オブジェクト

```json
{
  "category": ["안티에이징 화장품", "기능성 화장품", "스킨케어"],
  "cep_seeds": [
    { "keyword": "주름개선", "type": "effect" },
    { "keyword": "피부 탄력개선", "type": "effect" },
    { "keyword": "안티에이징", "type": "super_concept" }
  ]
}
```

- `type` の許容値: `effect`(効能・属性) / `super_concept`(上位概念)。
- カテゴリ層のキーワード(例: `주름개선 화장품`, `노화방지 화장품`)は `cep_seeds` に入れず、`category` の導出にのみ使用。

### Prompt テンプレート

```
あなたは複数の入力キーワードから、ベクトル検索用の機械可読な製品アンカーを生成しています。

制約:
- すべての文字列は必ず {{response_language}} で記述すること。

コンテキスト:
- productKeywords (カンマ区切り): {{product_name}}
- country: {{country}}

可視リサーチ (複数キーワードの基本調査、前処理済みセクションサマリー):
{{basic_research_summary}}

# Step 1 — 各入力キーワードを分類
この層分けはビューティーだけでなく、あらゆる製品ドメイン(化粧品、電子機器、食品/サプリメント、家電、サービス)に適用されます。
カンマ区切りの各キーワードを一つの層に分類してください:
- **category**: 製品カテゴリ — 販売される対象 (化粧品: 주름개선 화장품 · 電子機器: 게이밍 노트북 · 食品: 오메가3)
- **effect**: 消費者が求める機能的な効能/便益/属性、あらゆるドメインで (化粧品: 주름개선 · 電子機器: 발열 적은 · 食品: 혈행개선)
- **super_concept**: 広範なアンブレラ的テーマ (化粧品: 안티에이징 · 電子機器: 고성능 · 食品: 건강기능식품)

# Step 2 — カテゴリアンカーを構築
- "category" は CATEGORY 層のキーワードからのみ導出してください(必要であれば、effect/super_concept が属する最小の共通カテゴリを追加)。
- 2-4個の一般的/共通的な名詞または短い名詞句(ブランド/モデル名は不可)。
- 重複を除去し、広い → 具体的 の順に並べる。
- カテゴリは単一の機能や特定の観点ではなく、製品全体を代表しなければなりません。

# Step 3 — CEPシードを保存する(捨てないこと)
- すべての "effect" および "super_concept" キーワードを、それぞれの type とともに原文のまま "cep_seeds" に入れてください。
- effect/super_concept キーワードは最も強力な CEP/ナノインテントの手がかりです — 決して捨てず、決して "category" に入れないでください。
- 入力になかったキーワードを追加しないでください。
- effect/super_concept キーワードが一つもない場合(入力がカテゴリ/ブランドのみの場合、例: "생수, 삼다수, 에비앙")、"cep_seeds" を空配列 [] に設定してください。シードをでっち上げないでください。

スキーマ (厳密に):
{
  "category": ["..."],
  "cep_seeds": [ { "keyword": "...", "type": "effect" | "super_concept" } ]
}

では JSON のみを出力してください。
```
