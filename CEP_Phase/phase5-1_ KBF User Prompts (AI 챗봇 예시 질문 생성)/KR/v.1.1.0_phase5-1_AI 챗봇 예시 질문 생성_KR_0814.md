## 8. Phase 5-1 — KBF User Prompts (AI 챗봇 예시 질문 생성)

### 목적

CEP와 KBF를 기반으로 실제 사용자가 AI 챗봇에 입력할 법한 **자연스러운 질문 4개**를 생성합니다.

질문 4개의 구성은 고정입니다.

| 순번 | 구성            | 설명                                                        |
| ---- | --------------- | ----------------------------------------------------------- |
| 1    | CEP 단독        | CEP 상황 자체를 질문으로 옮긴 것. KBF는 언급하지 않습니다.  |
| 2    | CEP × KBF 1     | CEP 상황에서 첫 번째 KBF를 조건으로 붙인 질문               |
| 3    | CEP × KBF 2     | CEP 상황에서 두 번째 KBF를 조건으로 붙인 질문               |
| 4    | CEP × KBF 3     | CEP 상황에서 세 번째 KBF를 조건으로 붙인 질문               |

> 개정 이력
> - v.1.1.0 (0814): 출력 9개(KBF당 3개) → **4개(CEP 단독 1 + CEP×KBF 3)**로 변경. 질문별 역할을 순번으로 고정.
>   ⚠ 백엔드 정합 필요: 응답 배열 길이 검증값 9 → 4.
> - v.1.0.0 (0714): 나노인텐트가 Phase 4 출력에서 제거됨에 따라 입력 변수 `{{nano_intent}}` 제거.
>   ⚠ 백엔드 정합 필요: `buildKbfUserPromptsPrompt(...)`의 nano_intent 인자 제거.

### 입력 변수

| 변수                          | 설명                                                              | 예시                              |
| ----------------------------- | ----------------------------------------------------------------- | --------------------------------- |
| `{{cep}}`                     | CEP 상황 (`card.cep`)                                             | `아침 샤워 후 머리 빠질 때`       |
| `{{kbf}}`                     | 카드의 모든 KBF를 `", "` 로 연결한 문자열 (`", ".join(kbf_list)`) | `약산성 pH 제품, 무향, 저자극`    |
| `{{response_language_label}}` | 응답 언어 라벨 (locale KR/JP/US 기준, 기본값 Korean)              | `Korean` / `Japanese` / `English` |

**KBF 순서가 곧 질문 순서입니다.** `{{kbf}}`는 `", "` 로 연결된 문자열이므로, 연결한 순서(`kbf_list`의 인덱스 순서)가 그대로 2·3·4번 질문에 대응합니다. 백엔드에서 KBF 순서를 재정렬하면 질문 순서도 함께 바뀝니다.

### 출력 형식

JSON 배열 (정확히 4개)

```json
[
  "CEP 자체를 옮긴 질문",
  "CEP × KBF1 질문",
  "CEP × KBF2 질문",
  "CEP × KBF3 질문"
]
```

KBF가 3개 미만인 경우: `1 + KBF 개수` 만큼만 출력합니다(KBF 2개 → 3개 항목). KBF가 3개를 넘으면 앞의 3개만 사용합니다.

### 요청 모델 및 파라미터

| 파라미터  | 설정값                                       | 비고                                     |
| --------- | -------------------------------------------- | ---------------------------------------- |
| model     | `'gpt-5.4-nano'`                             | 고정                                     |
| input     | `buildKbfUserPromptsPrompt(...)` 결과 문자열 | CEP / KBF / 출력 언어 반영               |
| text      | `{ format: { type: 'text' } }`               | 일반 텍스트 출력                         |
| reasoning | `{ effort: 'none' }`                         | 추론 effort 최소                         |

### Prompt 템플릿

```
<!-- v.1.1.0_phase5-1_AI 챗봇 예시 질문 생성_KR_0814.md -->
아래의 CEP (Category Entry Point)와 KBF (Key Buying Factors)를 활용해, 실제 사용자가 AI 챗봇(ChatGPT, Gemini, Perplexity 등)에 물어볼 법한 자연스러운 질문 4개를 생성하세요.
AI 검색에서 흔히 나타나는, 구매 의도가 높은 프롬프트에 집중하세요.
톤: 도움을 주는 친구와 대화하듯 친근하고 편안하며 다가가기 쉬운 스타일로 작성하세요.

Input:
- CEP (Category Entry Point): {{cep}}
- KBFs (Key Buying Factors): {{kbf}}

KBFs는 ", " 로 구분된 목록입니다. 앞에서부터 순서대로 KBF1, KBF2, KBF3입니다.

질문 4개의 구성은 아래 순서로 고정합니다. 순서를 바꾸지 마세요.
1. CEP 상황 자체를 질문으로 옮깁니다. KBF는 언급하지 않습니다.
2. CEP 상황에 KBF1을 조건으로 붙인 질문
3. CEP 상황에 KBF2를 조건으로 붙인 질문
4. CEP 상황에 KBF3을 조건으로 붙인 질문

작성 규칙:
- 각 질문은 하나의 KBF만 다룹니다. 두 개 이상의 KBF를 한 질문에 섞지 마세요.
- KBF 표현을 그대로 옮겨 붙이지 말고, 사용자가 실제로 쓸 법한 말로 자연스럽게 녹여 쓰세요.
- 네 질문 모두 같은 CEP 상황 안에 있어야 합니다. 상황을 바꾸거나 새로 만들지 마세요.
- 브랜드명이나 제품명은 넣지 마세요.
- 질문마다 문장 구조를 달리해, 같은 문형이 반복되지 않게 하세요.
- KBF가 3개 미만이면 있는 개수만큼만 만들어 총 (1 + KBF 개수)개를 출력합니다. KBF가 3개를 넘으면 앞의 3개만 씁니다.

Output language: {{response_language_label}}

응답 형식(오직 JSON 배열만 출력하고 그 외에는 아무것도 출력하지 마세요):
["질문1", "질문2", "질문3", "질문4"]
```
