## Phase 2 — Product Anchors (카테고리 앵커 추출) — v1.1.0 (need_context 앵커 ADDITIVE)

### 목적

기본 정보 사전 조사 결과를 바탕으로 **벡터 검색용 카테고리 키워드**(`category`)를 추출합니다.  
이후 단계의 키워드 검색에서 제품 카테고리 맥락으로 활용됩니다.  
**[v1.1.0]** 더불어, 이 카테고리를 **처음 찾게 만드는 결핍·문제의 소비자 일상어**(`need_context`)를 함께 추출합니다 — 하류(Phase 3)에서 제품 명사 없는 '구매 이전 결핍 언어'로 검색하는 트랙의 시드로 쓰입니다.

### 입력 변수

| 변수                         | 설명                          | 예시              |
| ---------------------------- | ----------------------------- | ----------------- |
| `{{product_name}}`           | 제품명                        | `갤럭시 S25`      |
| `{{country}}`                | 국가 코드                     | `kr`              |
| `{{response_language}}`      | 출력 언어 (ko/en/ja)          | `ko`              |
| `{{basic_research_summary}}` | 기본 정보 사전 조사 결과 요약 | (마크다운 텍스트) |

### 출력 형식

JSON 객체

```json
{
  "category": ["스마트폰", "안드로이드폰", "플래그십폰"],
  "need_context": [
    "매일 쓰던 폰이 느려 답답할 때",
    "카메라로 아이 사진을 더 잘 남기고 싶을 때"
  ]
}
```

- `category`: (기존, 불변) 벡터 검색용 카테고리 키워드.
- `need_context`: (신규, 선택 ADDITIVE) 이 카테고리를 처음 찾게 만드는 결핍·문제의 소비자 일상어. 파서가 파싱하지 않아도 `category` 동작 불변.

```
당신은 벡터 검색에 쓰는 기계 판독용 product anchors를 만듭니다.

제약 조건:
- 모든 문자열은 반드시 {{response_language}}로 작성해야 합니다.

컨텍스트:
- productName: {{product_name}}
- country: {{country}}

참고 조사 자료 (Basic Research, 전처리된 섹션 요약):
{{basic_research_summary}}

스키마 (정확히 준수):
{
  "category": ["..."],
  "need_context": ["..."]
}

규칙:
- category: 2~4개의 일반적/보편적 명사 또는 짧은 명사구 (브랜드명/모델명 제외).
- 중복을 제거하고 가능하면 광범위 → 구체 순으로 정렬합니다.
- 카테고리는 단일 기능이나 특정 관점이 아니라 제품 전반을 대표해야 합니다.
- need_context: 2~4개. 이 카테고리를 처음 찾게 만드는 **결핍·문제·상황의 소비자 일상어** 짧은 구 (예: 로봇청소기 → "매일 걸레질 힘들다", "반려동물 털 청소 지친다").
  - **카테고리 명칭·브랜드·모델·사양 용어를 넣지 마세요.** 문제 언어여야 하류 검색이 카테고리 밖 원문(아직 이 제품군을 떠올리지 못한 사람의 글)에 닿습니다.
  - 참고 조사 자료(Basic Research)의 사용자 리뷰·용도·구매 추천 서술에서 **관찰되는 문제**에 근거해 도출하세요. 근거 없는 결핍을 지어내지 마세요 — 관찰되는 문제가 2개뿐이면 2개만 씁니다.

이제 JSON만 출력하세요.
```

### 로케일 안내

- 본 버전은 **KR** 기준본(v1.1.0). JP/EN은 동일 취지(`need_context` ADDITIVE 앵커 추가)를 수동 반영해야 함.

### 검증 제안

- `need_context`에 **카테고리 명칭·브랜드·모델·사양 용어가 포함되지 않았는지** 확인(문제 언어여야 함).
- `need_context`의 각 항목이 `{{basic_research_summary}}`의 **관찰되는 문제로 근거 추적 가능**한지(지어낸 결핍 아님).
- **회귀 불변**: `category` 배열의 개수·내용·정렬이 v1.0.0과 동일하게 동작하는지(need_context 추가가 category에 영향 없음).
- **파서 비파괴**: 백엔드가 `need_context`를 파싱하지 않아도 기존 `category` 소비가 정상인지.
