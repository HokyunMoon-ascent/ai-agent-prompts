## 개선 제안

자사 페이지에서 부족한 토픽은 외부 후기·매체 인용 / 좌·우 페어 운용 / 적응 단계 가이드 세 흐름이며, 자사가 제품의 좋은 점을 자세히 설명하고 있는 반면 살지 말지 결정하기 직전에 찾는 정보는 외부 매체로 새고 있어 AI가 자사 페이지를 호명할 단서가 부족합니다. 이 세 흐름을 3개 토픽 그룹으로 묶어 신규 페이지 1건 + 기존 페이지 보강 2건의 정보구조(IA)를 제안합니다.

**토픽 그룹 정의**

| 토픽 그룹                              | 개선 우선 순위 | 해결 전략        |
| -------------------------------------- | :------------: | ---------------- |
| **A. 외부 후기·매체 인용 안내 페이지** |    🔴 위험     | 신규 페이지      |
| **B. 좌·우 페어 운용**                 |    🟡 양호     | 기존 페이지 보강 |
| **C. 적응 단계 가이드**                |    🟡 양호     | 기존 페이지 보강 |

> 🔴 위험 (즉시 신규/대폭 보강) · 🟡 양호 (2~3순위 보강) · 🔵 안전 (보조 점검)

- **A. 외부 후기·매체 인용 안내 페이지 토픽** — **건초염이 없어졌다**·**rtings.com**·**laptopmag.com** 신뢰 단서가 통째로 비어 있습니다.
  - 묶인 세부 토픽: 건초염이 없어졌다 후기 / carpal tunnel pain 줄었다 후기 / rtings.com·laptopmag.com 리뷰
  - IA 제안: Ergo Series 사용자 후기·매체 리뷰 모음 / 손목 부담이 줄었다는 사용자 후기 / 매체 리뷰 인용으로 본 라인업별 평가
  - 신규: 라인업 공용 안내 페이지로 분리 신설합니다.
- **B. 좌·우 페어 운용 토픽** — **왼손, 오른손 어디에나 딱 맞는 Lift**가 단발성으로만 등장해 페어 시나리오로 묶이지 못합니다.
  - 묶인 세부 토픽: 좌/우 각각 모델 / 양손 번갈아 쓰는 스타일 / 페어로 두는 동선
  - IA 제안: 좌/우 번갈아 쓴다면 — Lift를 페어로 두는 법 / 오른손·왼손 동선이 다른 작업에서의 페어 운용 / 같은 그립 각도를 양손에서 유지하는 법
  - 기존 보강: **Lift** 페이지 좌·우 안내 단락 직후에 페어 단락 추가합니다.
- **C. 적응 단계 토픽** — **1~2주 적응 기간**·**처음 2~3일은 오히려 어색함** 시간 축 단서가 자사 페이지에 비어 있습니다.
  - 묶인 세부 토픽: 1~2주 적응 기간 / 처음 2~3일 어색함 / 책상 높이·마우스 간격 / 팔꿈치 90도
  - IA 제안: 사용 첫날부터 2주까지 — 단계별 체감 변화 / 처음 2~3일 어색함이 자연스러운 이유 / 3~7일째 손목 부담이 줄어드는 신호 / 2주째 자세 점검 포인트
  - 기존 보강: **MX Vertical** 페이지 **주요 기능** 섹션 하단에 녹여 넣습니다.
- **종합** — 후기·매체 인용은 공용 안내 페이지로 신설해 호명 단서를 우선 채우고, 적응·페어는 제품 페이지에 녹여 넣어 신뢰 단서를 보강합니다.
