# agent_aiOpt_gap v.0.2.0 실행 답변 예시 — Logitech Ergo Series 케이스

> v.0.2.0 신규: 엔티티 갭 5분류(카테고리/속성/CEP/관계/신뢰) + 원인 신호 4축(관련성/신뢰성/다양성/최신성) + Brand Mention × Content Citation 2축 매트릭스

## 1) 분석 개요

AI 검색 질문의 사용자는 "손목 뻐근함의 원인이 자세인지 빠르게 테스트하고 싶다"는 의도로 50~70° 버티컬 + 좌/우 대응 + 엄지 측면 버튼 + 후기 RTB까지 한 번에 묻는데, 자사 페이지는 제품별 핵심 기능 설명에 집중되어 있어 체감 타임라인·환경 가이드·외부 후기 RTB·"좌/우 번갈아 사용" 시나리오 매칭 영역이 결손되어 단순 노출 확인이 아닌 교정 우선순위 결정 단계에서 5분류 갭이 다층으로 도출된다.

:::accordion{title="개요 확인"}
**➊ AI 검색 질문의 사용자 의도(CEP) 요약**

- **CEP**: "일반 마우스로 손목 뻐근함 → 자세 원인인지 빠르게 테스트"하려는 즉시 검증형 구매 검토
- **KBF 단서**: :k[버티컬], :k[손목이 꺾이는 느낌], :k[좌/우 선택], :k[엄지 측면 버튼], :k[후기/입소문]
- **RTB 단서**: 실제 통증이 줄었다는 후기·입소문·사용자 체감 보고

**➋ AI 응답이 공통적으로 다룬 의미 영역 (공통 영역)**

- **체감 타임라인**: :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]
- **자세·환경 동반 가이드**: :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기]
- **외부 후기·매체 RTB**: :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[다나와]
- **좌/우 번갈아 사용 시나리오**: :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보], :k[좌/우 각각 모델 있음]

**➌ 자사 페이지의 무게중심**

- 자사 페이지는 :k[57° 손목이 편한 각도], :k[근육 긴장 10% 줄여주고], :k[자세 교정] 같은 자체 주장 기반 인체공학 효과 설명과 :k[Lift], :k[MX Vertical], :k[MX ERGO] 라인업 소개에 무게중심이 있음

**➍ 갭 한 줄 통찰**

- 자사 페이지는 "제품 자체의 효익 설명"은 있으나 사용자가 결정 직전에 필요한 시간 축·환경·외부 RTB·시나리오 가이드가 부재해 AI 응답 구성 단계에서 자사 라인업 일부(Lift, MX ERGO)가 호출되지 못함
  :::

## 2) 브랜드 노출 분석

자사 :k[MX Vertical]만 노출되는 "언급 ⭕ × 외부 인용 ❌(외부 의존)" 사분면이 우세하고, :k[Lift]·:k[MX ERGO]는 "언급 ❌ × 외부 인용 ⭕(경쟁 노출)" 사분면에 위치해 외부 매체에서 경쟁 라인업이 자리를 차지하고 있음을 Brand Mention × Content Citation 2축 매트릭스가 드러낸다.

:::accordion{title="브랜드 노출 확인"}
**➊ Brand Mention × Content Citation 2축 매트릭스**

- **언급 ⭕ × 자사 인용 ⭕ (내부 통제 가능)**: 해당 응답에 자사 콘텐츠 인용 사례 없음 — 자사 페이지가 RTB 출처로 인용된 흔적이 응답 1번·2번·3번 모두에서 부재
- **언급 ⭕ × 외부 인용 ❌ (외부 의존)**: :k[MX Vertical] / 외부 인용 단서 — :k[pcgamer.com], :k[rtings.com], :k[laptopmag.com], :k[다나와] (자사 브랜드는 노출되나 RTB는 외부 매체에서만 끌어옴)
- **언급 ❌ × 외부 인용 ⭕ (경쟁 노출)**: 자사 :k[Lift]·:k[MX ERGO]는 빠진 채 :k[Kensington Pro Fit Ergo Vertical]·:k[Perixx PERIMICE-713]·:k[Evoluent VerticalMouse 4]·:k[Kensington Orbit Trackball]이 외부 매체 인용으로 자리를 차지
- **언급 ❌ × 인용 ❌ (전면 결손)**: 좌/우 번갈아 사용 시나리오의 자사 :k[Lift] 페어 운용은 응답 어디에도 등장하지 않음 — CEP·관계 갭 의심 영역

**➋ 사분면별 의미 해석**

- **외부 의존 영역**: :k[MX Vertical]은 노출되나 자사 RTB가 응답 어디에도 없어 외부 후기·매체 신호 회수가 1차 레버, 회수 못 하면 RTB 통제권이 외부에 머무름
- **경쟁 노출 영역**: :k[Lift]·:k[MX ERGO] 부재는 카테고리 갭(트랙볼 대안 라인업 인지 부재)과 관계 갭(좌/우 페어 라인업 미연결)이 동시에 작동
- **전면 결손 영역**: :k[Lift] 페어 시나리오는 CEP 갭(좌/우 번갈아 맥락 결락) + 관계 갭(왼손/오른손 페어 연결 결락) 복합

**➌ 자사 외 브랜드 노출 패턴**

- :k[Kensington Pro Fit Ergo Vertical]: 응답 1번·3번 / :k[약 47° 바디 각도], :k[왼손 전용 모델], :k[손목 회외/회내 부담 감소]
- :k[Perixx PERIMICE-713]: 응답 2번 / :k[좌/우 각각 모델 있음], :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보]
- :k[Evoluent VerticalMouse 4]: 응답 3번 / :k[거의 수직에 가까운 각도]
- :k[Kensington Orbit Trackball]: 응답 3번 / :k[손목 부담 거의 없음] (트랙볼 대안 맥락)

**➍ 자사 브랜드 미노출/약노출 가설**

- 신호 부재 1 — 좌/우 번갈아 시나리오 매칭 부재: 1순위 갭 유형 **CEP 갭** + 보조 **관계 갭**, 부족 신호 **다양성**
- 신호 부재 2 — 외부 후기·리뷰 매체 RTB 부재: 1순위 갭 유형 **신뢰 갭**, 부족 신호 **신뢰성**
- 신호 부재 3 — 트랙볼 대안 카테고리 인지 부재: 1순위 갭 유형 **카테고리 갭** + 보조 **관계 갭**, 부족 신호 **관련성**
  :::

## 3) 의미적 갭 매핑

3개 응답 모두에서 일관되게 등장하지만 자사 페이지에 의미적으로 부재한 4개 공통 갭과 일부 응답에만 등장한 3개 차이 갭이 도출되었으며, 모두 5분류 + 4축 라벨이 부여되어 후속 보강 권장의 우선순위 결정 입력으로 사용된다.

:::accordion{title="의미적 갭 확인"}
**➊ [공통 갭] 체감 타임라인 가이드**

- **갭 유형**: CEP 갭 (1순위) + 신뢰 갭 (보조 — 시점성 단서로 사용자 신뢰 형성)
- **부족 신호**: 관련성, 다양성
- **AI 응답 근거**: 응답 1번·2번·3번 모두 — :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)], :k[1~2주 적응 기간]
- **자사 페이지 점검**: 적응 기간·체감 변화 시점에 대한 언급 부재. :k[근육 긴장 10% 줄여주고] 같은 효익 주장은 있으나 시간 축 가이드는 결손
- **필요 엔티티 후보**: :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]
- **필요 토픽 후보**: 단계별 체감 변화 가이드, 적응기 어색함 솔직 안내, 적응 가속 팁
- **AI 노출 저해 가설**: "지금 사면 언제부터 덜 아프냐"의 답을 자사 페이지가 제공하지 않아 AI가 외부 매체에서 시간 축 답변을 구성

**➋ [공통 갭] 자세·환경 동반 가이드**

- **갭 유형**: CEP 갭 (1순위) + 관계 갭 (보조 — 마우스와 환경 요소의 연결)
- **부족 신호**: 관련성, 다양성
- **AI 응답 근거**: 응답 1번·3번 — :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기], :k[책상 높이(팔꿈치 각도)·마우스 간격]
- **자사 페이지 점검**: 자세·책상·팔 지지 같은 사용 환경 가이드가 부재. 제품 단독 효익 설명 중심
- **필요 엔티티 후보**: :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기]
- **필요 토픽 후보**: 환경 동반 체크리스트, "마우스 + 자세 + 책상" 3요소 가이드
- **AI 노출 저해 가설**: AI가 통증 감소를 마우스 단독이 아닌 환경 가이드와 묶어 답하는데 자사 페이지가 환경 가이드를 다루지 않아 부분 인용에 그침

**➌ [공통 갭] 외부 후기·리뷰 매체 RTB 인용 영역**

- **갭 유형**: 신뢰 갭 (1순위)
- **부족 신호**: 신뢰성, 다양성
- **AI 응답 근거**: 응답 1번·2번·3번 모두 외부 매체 인용 — :k[다나와], :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[Reddit]
- **자사 페이지 점검**: :k[사용자 테스트 완료. 인체공학자 인증.] 같은 자체 검증 문구는 있으나 외부 매체·커뮤니티 인용이 부재
- **필요 엔티티 후보**: 전문 매체 리뷰 인용, 커뮤니티 후기 인용, 임상/사용 사례 인용
- **필요 토픽 후보**: 후기·매체 인용 박스, 사용자 통증 보고 모음
- **AI 노출 저해 가설**: AI는 RTB 신호로 외부 매체를 우선 인용하므로 자체 주장만 있는 페이지는 RTB 출처가 되지 못함

**➍ [공통 갭] 좌/우 번갈아 사용 시나리오 매칭**

- **갭 유형**: CEP 갭 (1순위) + 관계 갭 (보조 — 왼손/오른손 페어 라인업 연결)
- **부족 신호**: 관련성, 다양성
- **AI 응답 근거**: 응답 1번·2번·3번 — :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보], :k[좌/우 각각 모델 있음]
- **자사 페이지 점검**: :k[왼손, 오른손 어디에나 딱 맞는 Lift], :k[왼손용도 있어요]는 있으나 좌/우 페어 운용 시나리오 가이드는 부재
- **필요 엔티티 후보**: :k[Lift] 왼손/오른손 페어, :k[좌/우 각각 모델 있음]
- **필요 토픽 후보**: 좌/우 번갈아 사용자 시나리오 페이지 또는 Lift 페어 운용 가이드
- **AI 노출 저해 가설**: 시나리오가 페이지에서 묶이지 않아 AI는 외부 라인업으로 같은 시나리오를 채움

**➎ [차이 갭] 빠른 테스트 추천 조합**

- **갭 유형**: CEP 갭 (1순위)
- **부족 신호**: 다양성
- **등장 응답**: 응답 2번에만 명확히 등장 — :k[MX Vertical (메인) + Perixx (좌/우 교차 테스트용)]
- **자사 페이지 점검**: 모델별 단독 영역 구성. 사용자 시나리오에 따른 조합 운용 안내 부재
- **필요 엔티티 후보**: 메인 모델 + 보조 모델 페어 라벨
- **필요 토픽 후보**: 시나리오별 조합 추천, 변수 분리 검증 시나리오
- **AI 노출 저해 가설**: 사용자가 원인 검증을 목적으로 둘 때 조합 답을 AI가 만들고 자사 페이지는 단일 모델 답에 한정

**➏ [차이 갭] 솔직한 단점·한계 인정**

- **갭 유형**: 신뢰 갭 (1순위)
- **부족 신호**: 신뢰성
- **등장 응답**: 응답 2번 — :k[처음 2~3일은 오히려 어색함], :k[작은 손이면 큰 모델 불편], :k[게임용으로는 부적합]
- **자사 페이지 점검**: 한계·단점 언급이 없음. 효익 일변도 메시지
- **필요 엔티티 후보**: 비적합 시나리오, 적응기 어색함, 작은 손/큰 모델 미스매치
- **필요 토픽 후보**: "이런 경우엔 부적합" 솔직 카피
- **AI 노출 저해 가설**: AI는 균형 답변을 위해 단점도 인용하는데 자사가 단점을 다루지 않으면 단점 인용은 외부에서 가져옴

**➐ [차이 갭] 손 크기별 모델 매칭 가이드**

- **갭 유형**: 속성 갭 (1순위) + 관계 갭 (보조 — 손 크기 ↔ 라인업 연결)
- **부족 신호**: 다양성
- **등장 응답**: 응답 2번·3번 — :k[작은 손이면 큰 모델 불편], "ELECOM은 손 작은 편"
- **자사 페이지 점검**: :k[조금 작거나 보통 크기의 손에 잘 맞아요](Lift)는 부분 존재. MX Vertical 측 매칭 신호 부재
- **필요 엔티티 후보**: 손 크기 라벨(작은/보통/큰), 모델별 손 크기 권장
- **필요 토픽 후보**: 손 크기 매칭 가이드
- **AI 노출 저해 가설**: 매칭 가이드가 결손되어 AI가 외부 라인업까지 끌어옴
  :::

## 4) 보강 권장사항

7개 갭 중 체감 타임라인·환경 가이드·손 매칭·라인업 시나리오는 통합형, 외부 후기 RTB·통합 인체공학 허브는 분리형으로 가는 것이 적합하며, 각 권장에는 1순위 갭 유형과 부족 신호 축이 어떻게 보충되는지 함께 표기된다.

:::accordion{title="보강 권장사항 확인"}
**➊ [통합형] 체감 타임라인 가이드 보강 (MX Vertical / Lift 영역)**

- 대상 갭: ➊ (CEP 갭 + 신뢰 갭, 관련성·다양성)
