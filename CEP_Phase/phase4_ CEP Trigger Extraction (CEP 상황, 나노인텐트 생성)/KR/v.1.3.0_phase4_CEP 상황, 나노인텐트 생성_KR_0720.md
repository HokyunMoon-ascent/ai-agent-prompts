# Grounding Constraint (CRITICAL)

`situation`의 모든 구체적 디테일 — 시간 표현·장소·인용된 발화·행동·감정 — 은 선택한 유닛의 quote에 반드시 등장해야 합니다.
다음은 금지됩니다:
- **Time assertion**: quote에 없는 기간/시점(예: "첫 주", "주말", "저녁 시간" 추가).
- **Invented place**: quote에 없는 장소(예: "도서관" 추가).
- **Fake quotation**: 의역을 인용처럼 제시하는 것. 인용하려면 유닛의 quote에서 verbatim으로 복사하되, **그 내용을 `""`·`''` 인용부호로 감싸지 마세요(규칙 B).**
- **Invented action**: quote에 없는 행동(예: "다시 검색" 추가).
- **[v1.3.0] Invented feeling/perception**: quote에 없는 감정·체감·인식을 확정 서술로 덧붙이지 마세요(예: quote에 "땀이 식는 타이밍"만 있는데 "피부가 예민해지는 느낌이 든다"로 확정 / "방심하면 안 되겠다" 같은 정서 추가 금지). quote가 상태·조건만 말하면 situation도 상태·조건까지만.

**[v1.2.0] 결론절 그라운딩:** situation의 마무리 절, 즉 "→ 구매를 떠올린다 / 다시 보게 된다 / 알아보기 시작한다" 같은 **구매 전환 동작**도 하나의 구체적 행동입니다. 이 전환 동작을 뒷받침하는 인용이 quote에 없으면 **결론절을 붙이지 말고 장면(계기·감정·상태)까지만** 쓰세요. (단, 종결어미는 규칙 A대로 '~하는 순간/때'로 맞추세요.)

**[v1.2.0] 구체어 보존:** quote에 있는 **수치·구체 행동·고유 표현**을 상위어로 뭉뚱그리지 마세요. (예: "2~3만원 세이브" → "조금 더 비용" 금지 / "점심에 쿠션으로 덧바른다" → "재도포 루틴" 금지). **(49P 재확인: 34건/19P로 최다 반복 — 최우선 규칙.)**

**[v1.2.0] 강도·인과 보존:** quote가 '인상/느낌/경향'(예: "~한 느낌", "~기 좋을 것 같다", "~할 수 있다") 수준이면 situation도 그 강도로 쓰세요. 단정 인과("~때문에 반드시")·필요충분("~해야만 산다")·확정 사건("~무너지는 순간")으로 강화하지 마세요.

**[v1.2.0] 질문형 보존:** quote가 질문("공기청정기 효과 있을까?")이면, 단정 서술·확정 행동("효과를 기대하며 구매한다")으로 바꾸지 말고 '스스로 묻는/확인하려는' 장면으로 표현하세요.

**[v1.3.0] 시점·단계 분리 보존:** 원문/유닛이 두 개 이상의 시점·단계로 나눠 서술한 내용을 하나의 순간으로 압축하지 마세요. 압축이 불가피하면 가장 결정적인 **한 단계만** 남기세요.

장면이 빈약하게 느껴지더라도 빈약한 채로 두세요 — 근거가 희박하더라도 뒷받침되는 카드가 풍부하게 지어낸 카드보다 낫습니다.

# Length Constraint (situation, v1.3.0 · 규칙 D)

- `situation` 길이는 **최소 140 byte ~ 최대 200 byte(UTF-8)** — 한글 기준 **약 46~66자**입니다.
- **140 byte 미만이면** 근거가 뒷받침하는 범위 안에서 계기·상태·감정 등 quote에 실재하는 디테일을 더 담아 최소 길이를 충족하세요(디테일을 지어내서 늘리지는 마세요 — 근거가 부족하면 덜 사용된 섹션의 유닛을 선택).
- **200 byte를 초과하면** 덜 중요한 절을 생략해 줄이세요. 단, 남기는 표현의 **구체어는 그대로 보존**(구체어 보존 규칙)하고, 서로 다른 시점·단계를 한 순간으로 붙이지 마세요(시점·단계 분리 보존).
- 종결어미는 항상 규칙 A('~하는 순간' / '~하는(할) 때')를 지키세요.
