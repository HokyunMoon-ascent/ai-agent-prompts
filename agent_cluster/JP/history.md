### v.0.7.2 — 2026-06-02
**파일**: `v.0.7.2_cf_JP_0602.md` (기준: `v.0.7.1_cf_JP_0602.md`)
**변경 요약**: 입력 키워드는 `버티컬 마우스`였는데 출력이 통째로 `로프리 마우스` 시장으로 나오던(엉뚱한 시드 앵커) 문제 수정. **시드 키워드를 표준 플레이스홀더 `{{keyword}}` 하나로 고정.**
- **원인**: v.0.7.1의 시드 확정이 데이터 휴리스틱("시드=클러스터 A(0번) `h=TRUE` 허브")에 의존 → 혼합/다중 시장 데이터에서 클러스터 A가 입력 키워드라는 보장이 없어, 클러스터 A에 잡힌 다른 제품(로프리)을 시드로 오인. 단일 cf 프롬프트에 사용자 입력 키워드와의 권위 있는 연결 고리(`{{keyword}}`)가 부재했고, 이전 대화(`{{prev_q}}/{{prev_a}}`) 주제로 표류.
- **핵심**: `{{keyword}}`는 리포 표준 플레이스홀더(GEO prompt builder의 "クラスターファインダーに最初に入力された検索語 = {{keyword}}"). 단일 cf 프롬프트에는 누락돼 있었음.
- **신설**: `### 入力キーワード（分析の絶対基準）` 블록을 역할 소개 직후(상단)에 추가 — `クラスターファインダーに最初に入力された検索語 = {{keyword}}`, 시드는 `{{keyword}}` 하나로 고정.
- **`### 単一シードキーワード固定ルール（最優先）` 재작성**: 시드=`{{keyword}}`(절대 기준), `{{keyword}}`에 해당하는 row·클러스터 시장 내부만 분석, 검색량 최댓값·클러스터 A 위치로 시드 교체 금지, 이전 대화 표류 금지, `{{keyword}}` 대응 데이터가 없으면 "대응 데이터 없음" 명시(다른 제품군 임의 분석 금지), `{{keyword}}` 공란일 때만 클러스터 A 허브로 추정(예외).
- 섹션 1 첫 문장 `:k[{{keyword}}]` 단일 시장 선언, 섹션 2 step0/섹션 3 경로 필터를 `{{keyword}}` 기준으로 명확화, 최종 출력 규칙에 `{{keyword}}` 단일 시드 못박음 + 미대응 시 표류 금지.
- **유지**: v.0.7.1의 타 제품군 완전 배제·"OO 시장" 명명 금지. 자가검증 게이트는 계속 미추가(인라인 규칙).
- 표현 다듬기(동작 무관, in-place·버전 범프 없음): 섹션 1의 어색한 "単一市場の内部構造" 선언 문구를 "이번 분석이 :k[{{keyword}}] 한 키워드를 다룬다"는 쉬운 서술로 교체(해석 기준 + Output Format 주석, 3종).
- 검증: KR/JP/EN 3종 구조 패리티(H1=4·H2=22·H3=7·불릿=70·`{{keyword}}` 22회·256행 동일). 구버전 `v.0.7.1_cf_JP_0602.md`는 `_archive/`로 이동.

### v.0.7.1 — 2026-06-02
**파일**: `v.0.7.1_cf_JP_0602.md` (기준: `v.0.7.0_cf_JP_0602.md`)

- **재진단**: 기존 `cf-single-keyword-misfire_260601.html`(v.0.6.3 대상)은 "A/B 라벨 충돌 + 인체공학 키보드 날조(0행)"로 봤으나, v.0.7.0에는 부정확. ① v.0.7.0이 단일/이중 분기를 이미 제거 ② 문제 데이터(`problem/61b6c948-…_cluster.csv`)에서 `인체공학 키보드`는 `v=7906, c=Q, h=true`로 **실존**(날조 아님). 즉 **프레이밍 문제**: 시드(`버티컬 마우스`, `c=A`, `src` 전 행 A)의 공동검색 생태계에 포함된 키보드·패드·손목보호대 등을 동격의 "OO 시장"으로 제시.
- **원인(v.0.7.0)**: ① 시드 앵커 부재(`src`/`Total source keywords` 선언이 v.0.7.0에서 삭제됨) — 브랜드·범용어(`로지텍` v=184,000 > 시드 50,400)가 시드보다 커서 다중 "시장"을 세움 ② 섹션 1 Output Format의 `➊/➋ 대분류`가 각각 독립 검색량+Keywords를 가진 병렬 시장 템플릿 ③ 독립 시장 명명·타 제품군 포함을 막는 규칙 없음.
- **신설**: `### 単一シードキーワード固定ルール（最優先）` — 시드=클러스터 A(0번) 허브(`h=TRUE`), `src` 단일값=단일 입력, 검색량 큰 브랜드/범용어로 시드 교체 금지, 시드 제품 외 타 제품군(키보드·마우스패드·손목보호대·그립) 완전 배제, "OO 시장"/두 번째 키워드 명명 금지.

- 섹션 2 공통 분석 로직에 0번(타 제품군 클러스터 사전 제외) 추가, 섹션 3에 시드 내부 클러스터 간 이동만 사용 규칙 추가.
- 최종 출력 규칙에 단일 시드 1개 시장·타 제품군 미출력·독립 시장 명명 금지 못박음.
- **사용자 결정 반영**: 인접 제품군 = 완전 배제(보조 축 유지 아님), 출력 전 자가검증 게이트 = 추가 안 함(인라인 규칙으로만 강제).
- 검증: KR/JP/EN 3종 구조 패리티(H1=4·H2=22·H3=6·불릿=64·247행 동일). 구버전 `v.0.7.0_cf_JP_0602.md`는 `_archive/`로 이동.
