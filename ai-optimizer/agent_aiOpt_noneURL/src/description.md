## AI 결과 분석의 목표와 방법

### 목표

자사 페이지 URL이 입력되지 않은 상황에서, AI 응답을 사용자 의도(CEP) 기준으로 진단·해설하는 것이 목표입니다. 갭 도출은 수행하지 않으며, **응답 자체의 의미 영역·인용 패턴·의도 정합성**을 강조하여 사용자가 응답을 깊이 이해하도록 돕습니다.

이 결과는 그 자체로 사용자에게 노출되며, 동시에 후속 온드미디어·언드미디어 전략 에이전트가 동일 슬롯에서 동시 렌더링될 때 사용자가 4개 출력을 직렬로 소화할 수 있게 의미 영역 라벨을 핸드오프합니다.

### 갭 분석과의 차이

- 갭 분석은 자사 페이지(A) + AI 검색 질문(B) + AI 응답(C)을 비교하여 **자사 페이지에 결손된 의미 영역**을 도출합니다.
- AI 결과 분석은 자사 페이지가 입력되지 않으므로 비교 대상이 빠집니다. 갭이라는 추가 관점이 사라지고, **응답 진단·해설**이라는 단일 관점만 남습니다.
- 두 변형은 첫 번째 슬롯에서 URL 입력 여부에 따라 토글됩니다. 온드/언드 미디어 전략 에이전트는 URL 유무와 무관하게 항상 노출됩니다.
- 선후행 의존성은 없습니다. 사용자가 어떤 순서로 클릭하든 각 에이전트는 독립적으로 동작하며, 프롬프트 간 결과를 주고받는 체이닝 로직은 불필요합니다.

### 방법

비교 대상은 BC 프레임으로 정의됩니다(A 없음).

1. **B**: CEP별로 만든 프롬프트 — `agents/ai_agent/agent_aio_noneURL/src/B_AI에 던지는 질문 (CEP별로 만든 프롬프트).md` (갭 분석 src에서 그대로 재사용)
2. **C**: 그 프롬프트로 받은 AI 응답
   - `agents/ai_agent/agent_aio_noneURL/src/C_B프롬프트로 받은 AI 응답_1.md`
   - `agents/ai_agent/agent_aio_noneURL/src/C_B프롬프트로 받은 AI 응답_2.md`
   - `agents/ai_agent/agent_aio_noneURL/src/C_B프롬프트로 받은 AI 응답_3.md`

C를 기준으로 다음 두 가지를 진단합니다.

- C에 등장한 브랜드/제품과 그 인용 근거(RTB·속성·수치·후기)
- B(사용자 의도)를 기준으로 C가 다룬 의미 영역의 정합도와 의사결정 함의

도출되는 결과는 "이 문장을 넣으세요" 식의 직접 수정 지시가 아니라, **"AI 응답이 어떤 의미 영역을 다뤘고, 사용자 의도와 어떻게 닿으며, 후속 온드/언드 에이전트가 어떤 라벨로 받아쓰면 되는지"** 수준의 진단 가이드입니다.

### 출력 구조 (4섹션)

1. **분석 개요**: 사용자 의도 요약 / 공통 영역 / AI 응답 무게중심 / 사용자 의도 충족도 한 줄
2. **브랜드 노출 분석**: 인용 브랜드 패턴 / 인용 근거 RTB 유형 / 신호 형성 미비 영역 가설
3. **의미 영역 진단·해설**(핵심): 의미 영역 라벨별 5필드(응답 근거 / 의도 정합성 / 엔티티·토픽 분해 / 의사결정 함의) + 차이 영역의 응답 간 입장 차이
4. **후속 활용·핸드오프 메모**: 추가 검증 권장 영역 / 기회 영역 메모 / 후속 에이전트 핸드오프 라벨
