   ➐ [차이 영역] 조합 운용 시나리오 — 단일 모델이 아닌 메인+보조 페어 검증

   핵심 엔티티 분해: 메인 모델 + 보조 모델 페어, :k[MX Vertical (메인) + Perixx (좌/우 교차 테스트용)]

   의사결정 함의: "1개를 사서 빠르게" 검증보다 "2개 페어를 빌려/사서 변수 분리"가 진단의 정확도가 더 높지만 비용 부담을 함께 고려해야 함
   ➑ [차이 영역] 트랙볼 대안 — 버티컬을 못 쓸 때의 대체 솔루션

   핵심 토픽 분해: 버티컬 대안 카테고리, 손목 부담 vs 정밀도 트레이드오프
   의사결정 함의: 사용자가 버티컬에 적응 못 한다면 트랙볼이 후보가 될 수 있음을 의식해두고, 다만 첫 빠른 테스트 단계에서는 변수 폭을 줄이기 위해 버티컬에 집중하는 편이 합리적
   ➒ [차이 영역] 손 크기·체격별 모델 매칭
   AI 응답 근거: AI 응답 2번 — :k[작은 손이면 큰 모델 불편], :k[ELECOM Shellpha] (손 작은 편 슬림). AI 응답 3번 — :k[크고 무거운 편 → 작은 손이면 불편] (MX Vertical 측 단점)

4. 후속 활용·핸드오프 메모
   추가 검증 권장 영역은 자세·환경 동반 가이드와 조합 운용 시나리오 두 축이며, 기회 영역 메모는 정량 비교·체감 타임라인·외부 후기 RTB 3축이 사용자 의도와 강하게 닿는다. 후속 온드/언드 미디어 전략 에이전트가 받아쓸 의미 영역 라벨은 7개 후보로 정리된다.

   검증 대상 영역 1 — 자세·환경 동반 진단: 응답 3번에서만 명확히 다뤄져 RTB가 약함. 사용자가 "자세 원인 확인" 의도를 충족하려면 :k[팔꿈치 90도]·:k[손목 뜨게]·:k[마우스 높이 낮추기] 환경 3요소를 마우스 변경과 같이 통제해야 결론이 신뢰 가능 — 근거 :k[자세 + 높이 + 팔 지지 같이 안 바꾸면 한계]
