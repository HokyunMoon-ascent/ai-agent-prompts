journey_finder_brand

**v. 25.11.06**

### Instruction

与えられた [ターゲットキーワード] を見て、その検索語がブランド名、製品名、またはサービス名を指す 「ブランド検索語」 であるかどうかを判断します。  
「ブランド検索語」とは、特定のブランド名または特定の製品名／モデル名を含む検索語を指します。  
これは単語1つで構成される場合もありますが、形容詞や他の名詞を伴う名詞句、節、あるいは文の形をとることもあります。  
つまり、特定のブランド名または特定の製品名／モデル名を含むすべての検索クエリはブランド検索語と見なされます。

特定ブランドの製品に関する「ランキング」「おすすめ」「種類」などと組み合わさったキーワード（例：「ソニー テレビ おすすめ」「パナソニック 冷蔵庫 種類」など）の場合、  
「ソニー」「パナソニック」はカテゴリーを表す部分を含んでいますが、このような場合も必ずブランドキーワードとして判断してください。

Output Format では、与えられた検索語が「ブランド検索語」であれば "brand" に "True" を、  
「一般検索語」であれば "False" を返します。また、検索語がブランド検索語であると判断した場合は、その根拠となる 検索語中のブランド部分 を "brand_part" に抽出して返してください。  
検索語が一般（ノンブランド）キーワードの場合は "brand_part" に空文字列を返します。

入力された [シードキーワード] の中には、ノンブランドキーワードが含まれる場合もありますが、  
その製品・サービスカテゴリーにおける主要なブランド名・製品名・サービス名などのブランドキーワードも含まれています。

追加の説明は不要です。結果のみ返してください。

ブランド検索語の例:

- 会社名（例: ソニー、パナソニック）
- サービス名（例: YouTube、Netflix、LINE、メルカリ）
- ブランド名（例: iPhone、Galaxy、VAIO、アクオス）
- 製品（モデル）名（例: S24、MacBook Pro 16、BRAVIA X95L、冷蔵庫 NR-F603）

一般検索語（ノンブランドキーワード）の例:

- 一般的な製品／サービスカテゴリ（例: スマートフォン、配達アプリ、ノートパソコン、洗濯機、冷蔵庫、美容液）
- 一般名詞（例: レチノール、リンゴ、ヒアルロン酸、コラーゲン）
- 「ブランド」という単語を含むが特定ブランドを指さない一般的キーワード（例: ゴルフ ブランド ランキング、2025年 人気ブランド）

[検索結果ページのコンテンツ]:

- 検索結果ページの内容は、検索語がブランドキーワードか一般名詞か判断が曖昧な場合に参照します。  
  例えば、「アップル」は一般名詞（果物）ですが、現在ではブランド名です。  
  また、「トス（Toss）」は動詞でしたが、現在は送金アプリのブランド名となっています。  
  このように検索語がブランドキーワードかどうかの判断が難しい場合や、特定製品名・型番の確認が必要な場合に [検索結果ページコンテンツ] を参考にします。

- ただし、検索語自体に特定ブランド名が含まれていない場合、たとえ検索結果内にブランド名が登場しても ノンブランドキーワード として扱います。

### Output Format

{{
  "keyword": str -> 入力の 'keyword' 値をそのままコピー,
  "target_kewyord": str -> 入力の 'target keyword' 値をそのままコピー,
  "brand": bool,
  "brand_part": str
}}

### Input

[ターゲットキーワード]  
%(input)s

[シードキーワード]  
%(keyword)s

[検索結果ページコンテンツ]  
%(serp)s

(input) = キーワード、対象キーワード、SERPデータが含まれます。  
for keyword in batch:  
 brand_input_str += f”keyword: {keyword}n”  
 brand_input_str += f”target keyword: {target_map[keyword]}n”  
 brand_input_str += f”result: n”  
 brand_input_str += “---n”  
 brand_input_str += f”{serp_map[keyword]}n”  
 brand_input_str += “---nn”

serp : オーガニック検索結果の上位3件のタイトルとスニペット
