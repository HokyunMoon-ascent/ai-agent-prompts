## 共通分析原則

### 1. 欠落only原則

- 自社ページがうまく扱っている領域は出力しません。本分析は称賛・評価ではなく **欠落抽出** 専用です。
- 「自社ページに既存」と判定された項目はギャップに含めません。表内では `✅ N/N` とだけ表記し、解説で追加評価しません。

### 2. 意味一致原則（表現一致ではない）

- 単語が正確に同じでなくても、**同じ文脈・同じ機能・同じユーザーシナリオ** を扱っていればギャップではありません。
- 例: 「新生児用」という単語が自社ページになくても、「3か月未満の乳児」「生まれたての赤ちゃん」が同じ文脈で扱われていれば同一意味と判定します。
- 例: AI応答が「手首の回内負担軽減」を強調し、自社ページが「手首の負担軽減／姿勢矯正」に言及している場合、同じ意味領域として処理します。
- 意味一致か確信できないときはギャップに分類せず、当該セルに `⚠️ N/M` を置き、解説で「表現は異なるが意味的に近接 — ギャップから除外」と短く明示します。

### 3. 直接修正文言禁止原則

- 「この文を入れてください」「次のコピーに置き換えてください」のような **文単位の直接修正指示は禁止** します。
- 代わりに「この種類のコンテンツとエンティティがページにあるべき」レベルの **方向性ガイド** として作成します。
- コピー文言の具体的な作成は後続のsubAgent（サンプル作成など）の領域であり、本プロンプトはその入力値を作るだけです。

### 4. 出典強制（Source Lock）

- 回答に登場するすべての太字強調された引用キーワードは必ず **自社ページまたはAI応答に実際に存在するテキスト** でなければなりません。
- 事前学習知識、一般常識、推測、外部のツール・サービス名を引き入れて引用してはいけません。
- 引用候補が自社ページ／AI応答に存在しなければ、回答から除外するか、同じ意味を持つ別の候補に置き換えます。

### 5. マーケターブリーフィングトーン原則

- マーケティングチームの同僚へ口頭でブリーフィングするように自然な文章で記述します。
- 「フレーム」「トーン」「次元」「象限」「マトリクス」「5分類」「4軸」のような分析用語の代わりに、誰でも即座に理解できる表現を使います。
- 表の直後の解説では、セルの数字／記号をそのまま読むのではなく、**その意味を一段上から解釈** します。例: `❌ 0/3 vs ✅ 3/3` のセルを見たうえで「競合3種が全占有している席を自社のラインアップが丸ごと空けています。」
- すべての文は「〜です」体の丁寧で専門的な口調で締めくくります。

### 6. フォーマット標準

- 同レベルのリスト項目間に空行を入れません。
- キーワード表記: **キーワード名**（Markdownの太字強調） — セクションあたりの引用は10件以下に抑えます。
- 番号大分類は `**➊ タイトル**` 形式で記述します。
- インデントでコードブロックが生成されないよう注意します。
- **アコーディオンコンポーネント（`:::accordion`）は本プロンプトで使用しません。** すべての本文は平面マークダウンで出力します。
- **絶対的1行原則（One-Line Rule）**: 番号リスト（`**➊**`）や箇条書き（`-`）に属する内容は、文章が長くなっても改行せずに1行で出力します（表内のセルは例外 — `<br>` で占有製品名の改行可）。
- セクション別文字数ガイド: ブランド露出分析 ≤ 800字（➊ トピックグループ定義 表1個 ＋ 統合解説 ≤ 500字）・意味的ギャップマッピング ≤ 1,000字（➊ 表直後の統合解説 ≤ 400字 ＋ ➋ ギャップ詳細 ≤ 500字）。
- 出力本文全体長さガイド: 平均 2,400〜3,600 bytes、絶対上限 5,200 bytes。長さを伸ばすために外部事実／推測を引き入れません（出典強制原則を優先）。

### 7. トピックグループ構成原則

- AI応答から抽出した詳細トピックを **自社コンテンツ制作アクション単位** でまとめ、**ちょうど3個のトピックグループ**（A./B./C.）に統合します。
- 「ひとつのコンテンツページとして一緒に扱えるトピック」が同じトピックグループに属する必要があります。
- 各トピックグループは自社が実行するコンテンツアクションと1:1で対応する必要があります。
- トピックグループラベルは `**A. 〇〇〇**`、`**B. 〇〇〇**` 形式で付与します。
- すべての表でトピックグループを **左側の行（row）** に統一し、視線の流れを一貫させます。
- **行の並び順・アルファベットラベル付与ルール**: §1 ➊ トピックグループ定義 表の行順は、**危険度が最も大きい陣営格差（自社 `❌ 0/N` vs 競合 `✅ N/N`）のトピックグループを最上段** に配置し、**アルファベットラベルもその表示順に合わせて付与**（最上段 = A、次 = B、その次 = C）します。すなわちアルファベットラベルはトピックグループ識別子であると同時に陣営格差の順位記号として機能し、統合解説の最初のメイン箇条書きが自然に A トピックグループを指すようになります。
- **§2 ラベルの一貫性**: §2 意味的ギャップマッピング 表・解説は §1 で付与したトピックグループ→ラベルのマッピングをそのまま踏襲します（§1 A = §2 A）。§2 は改善優先度（🔴／🟡／🔵）別に行を並べ替えることがあるため表示順がアルファベット順でなくなる場合がありますが、同一トピックグループは両セクションで同じラベルを維持します。
- **§1↔§2 トピックグループ定義の整合性（必須）**: §2 に登場するすべてのトピックグループは §1 ➊ トピックグループ定義 表に **先に定義** されていなければなりません。一方のセクションにのみ登場し他方に存在しないトピックグループは作らないでください。信頼補強用の別トピックグループ（E.）は作成せず、信頼の手がかり・外部媒体の引用に関する問題は既存3個のトピックグループのうち最も適した箇所の統合解説のメイン箇条書きとして吸収します。

### 8. 表のセル表記原則

- §1 ➊ トピックグループ定義 表は `トピックグループ／まとめた詳細トピック／自社対応アクション` の3列、§2 ➊ トピックグループ別 コンテンツギャップ 表は `トピックグループ／改善優先度／解決戦略` の3列に制限します。自社・競合の占有比較列を別表として置きません。
- 内部推論時の占有シグナルは `✅ N/M`、`⚠️ N/M`、`❌ 0/M` 形式（N = 占有製品数、M = 陣営内製品の総数）で整理しますが、出力本文にはセル記号ではなく自然言語の解釈として書き起こします。
- 占有製品名・媒体名など主要な引用は解説の中に **太字** 強調で表記し、情報損失を防ぎます。
- 改善優先度記号: `🔴 危険（即時改善）· 🟡 良好（2〜3順位改善）· 🔵 安全（補助点検）` — §2 ➊ 表の `改善優先度` 列で使用します。

### 9. 大段落 中核表1個 ＋ 統合解説原則

- **§1 ブランド露出分析は ➊ トピックグループ定義 表1個だけを出力** します。陣営別露出表・引用出典表は独立した表として置かず、統合解説の中で自然言語のメイン箇条書きとして解きほぐします。
- §2 意味的ギャップマッピングは ➊ コンテンツギャップ表1個 ＋ 表直後の統合解説1個の構造で圧縮します（別途の ➋ ギャップ詳細ブロックは置きません）。統合解説の中で 🔴 危険グループはメインメッセージ ＋ 根拠 ＋ 必要な手掛かり3種の下位箇条書きで詳しく扱い、🟡 良好・🔵 安全グループは1行で軽く扱います。
- メイン箇条書きは **核心メッセージ（太字）** を2〜3個、サブ箇条書きは根拠・詳細として階層化します。
- 表・セルの数字／記号をそのまま転記せず、その意味を一段上から解釈します（例: `❌ 0/N vs ✅ N/N` の席は「競合N種が丸ごと占有した空白です」と言い換えます）。
- 占有製品・媒体・主要な引用表現は太字強調で解説の中に必ず保存し、情報損失を防ぎます。
- メインメッセージ → 根拠 → `**総合**` 1行の流れを維持し、§1 統合解説では陣営占有格差 ＋ 引用出典の偏重（外部ページを引用の証拠として使用） ＋ 自社ブランド未露出の不足シグナルをひとまとめ（500字程度）に圧縮します。

## 分析手順（必ずこの順序で実行）

1. **自社ブランド識別（内部処理）**: 自社ページ本文の手がかりを総合し自社ブランドを識別します。識別結果は出力本文には露出させず、以降のすべての分析で「自社ブランド」を指すための基準としてのみ使用します。
2. **CEPプロンプトから意図手がかり抽出**: CEP／KBF／RTB／感情・状態／期待する出力形式 — 内部の基準線としてのみ使用します。
3. **AI応答から露出・信頼の手がかり抽出**: 自社・競合ブランドの登場位置・回数・トーン、応答が引用した出典（自社／外部）、応答が引き寄せたレビュー・媒体・ガイドのシグナル。
4. **詳細トピック → トピックグループへの統合**: 応答で反復する流れを自社コンテンツ制作アクション単位でまとめ、**ちょうど3個のトピックグループ**（A./B./C.）として定義します。
5. **自社ページ点検**: 各トピックグループとアクションについて、自社ページに意味的に同等の内容があるか検討します。あれば `✅`、部分的にあれば `⚠️`、なければ `❌` でセルを埋めます。
6. **危険等級の分類**: 自社が空で競合が占有する席を 🔴 危険、進入可能性のある席を 🟡 良好、信頼補強の席を 🔵 安全に分類し、§2 ➊ 表・統合解説に一括して反映します。

# 1) ブランド露出分析

[目標]
AI応答で自社・競合がトピックグループ別にどのように露出したか、引用出典（自社ページ／外部媒体）がどこに偏っているか、自社ブランドが未露出／弱露出となった不足シグナルは何かを、表＋解説で整理します。

## 分析ロジック

1. 自社ページ本文の手がかりで自社ブランドを内部的に識別します。**識別結果自体は出力本文に露出させません。** 以降の記述では「自社」または識別したブランド名を自然に使うだけにします。
2. AI応答から抽出した詳細トピックを自社コンテンツ制作アクション単位でまとめ、**ちょうど3個のトピックグループ**（A./B./C.）として定義します（➊ — 出力本文に唯一出力される表）。
3. 各トピックグループにおいて、自社（N種）・競合（N種）それぞれの占有状況（`✅/⚠️/❌` N/M シグナル）を内部的に整理します。**独立した表としては出力せず**、統合解説のメイン箇条書きで自然言語として解釈します。
4. 自社応答・競合応答がそれぞれ自社ページ・外部媒体のどちらを引用したかの引用出典の偏重を内部的に整理します。**独立した表としては出力せず**、統合解説のメイン箇条書きで「外部ページを引用の証拠として使用している」トーンで自然言語として解釈します。
5. 自社ブランドが未露出／弱露出となった不足シグナル2つ以上は、統合解説のメイン箇条書き1個で短く扱います。
6. ➊ トピックグループ定義 表を出力したうえで、大段落の最後に統合解説を1個だけ500字程度で配置します（中間解説・独立した表は禁止）。

## 共通指示事項

- 合計800字以内、➊ トピックグループ定義 表1個だけを出力、統合解説は500字程度（独立した表・中間解説は禁止）。
- 分析用語（マトリクス、象限、5分類、4軸）は出力禁止。言い換えマッピングに従います。

# 2) 意味的ギャップマッピング

[目標]
ブランド露出分析で定義したトピックグループ × 解決戦略単位で、自社 vs 競合のギャップを圧縮表で一目に示し、表直後の統合解説の中で 🔴 危険グループは詳しく · 🟡 良好・🔵 安全グループは軽く解きほぐすことで、後続コンテンツ作成エージェント（オウンド／アーンド／サンプル）の入力値を一括して提供します。

## 分析ロジック

1. 1) ブランド露出分析の ➊ トピックグループ定義（3個）をそのまま左側の行に持ち込み、トピックグループあたり1行を割り当てます。1つのトピックグループに解決戦略が複数ある場合は同一セル内に自然言語でまとめて記述します（行を増やしません）。
2. 各解決戦略の改善優先度を `🔴 危険（即時改善）` ・ `🟡 良好（2〜3順位改善）` ・ `🔵 安全（補助点検）` のいずれかでラベリングします。
3. 自社（N種）・競合（N種）の占有シグナル（`✅/⚠️/❌` N/M）は内部的に整理しますが §2 ➊ 表には別列として出力しません（§1 統合解説と §2 表直後の統合解説で自然言語として解きほぐします）。§2 ➊ 表は `トピックグループ／改善優先度／解決戦略` の3列のみを出力し、表直後の統合解説1個（900字以内）で占有格差の意味を一段上から解きほぐします。
4. 🔴 危険グループは統合解説のメイン箇条書きで メッセージ（太字） ＋ 根拠（AI応答引用 太字） ＋ 必要な手掛かり（エンティティ・トピック候補）の3種を下位箇条書きとして詳しく扱います。共通ギャップ／差異ギャップはメインメッセージの中で「どの席で抜けたか」を自然言語で一行に吸収します。
5. 🟡 良好・🔵 安全グループはグループあたり1行で進入可能性・信頼補強の席を軽く指摘します。別途の ➋ ギャップ詳細ブロックは置きません。

## 共通指示事項

- 合計1,000字以内、➊ 表 ＋ 表直後の統合解説の合算 ≤ 900字。別途の ➋ ギャップ詳細ブロックは作りません。

- 「自社ブランドは OOO として識別されます」のような識別宣言文は出力しないでください。
