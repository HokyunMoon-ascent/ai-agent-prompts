# 작업 목표

agent_aiOpt_gap 프롬프트의 2) 브랜드 노출 분석과 3) 의미적 갭 매핑 두 섹션의 Output Format을 테이블 기반 구조로 교체해 주세요. (description/0515/table_layout.md 참고)

## 수정

기존 v0.2.1은 불릿 리스트 기반 출력이라 모바일 카드 렌더링에서 가독성이 떨어지고, 갭 우선순위가 한눈에 잡히지 않습니다. 신규 버전은 토픽 그룹 정의표 + 압축 매트릭스 + 글머리 기호 해설 구조로 변경해 다음을 달성합니다.

- 토픽을 자사 콘텐츠 제작 액션 단위로 그룹핑해 N개 세부 토픽을 4~5개 그룹으로 통합
- 자사 vs 경쟁사 진영 단위 2행 비교로 모바일 셀에서도 줄바꿈 안정성 확보
- 각 매트릭스 하단에 글머리 기호 기반 해설을 배치해 표 → 인사이트 흐름 통일
- 모든 매트릭스에서 토픽 그룹을 좌측 행(row)으로 통일해 시선 흐름 일관성 확보
- 그리고 분석 개요 및 인사이트는 같은 이야기의 반복이라 제외합니다
- 아코디언 형태는 이번 프롬프트에서는 제외합니다.

## 출력 구조 규칙

AI 응답에서 추출한 세부 토픽들을 자사 콘텐츠 제작 액션 단위로 묶어 4~5개 그룹으로 통합합니다.
"하나의 콘텐츠 페이지로 함께 다룰 수 있는 토픽들"이 같은 그룹에 속해야 합니다.
각 그룹은 자사가 실행할 콘텐츠 액션과 1:1로 매칭되어야 합니다.
그룹 라벨은 A. 〇〇〇 B. 〇〇〇 형식으로 부여합니다.

매트릭스 구조 규칙

모든 매트릭스에서 토픽 그룹을 좌측 행(row) 으로 배치합니다.
진영 비교 매트릭스의 열은 자사(N종) | 경쟁사(N종) 2열로 제한합니다.
셀 표기는 ✅ N/M ⚠️ N/M ❌ 0/M 형식으로 통일하며, 진영 내 점유 제품명을 셀 안에 보조 표기합니다(이탤릭).
범례: ✅ 강점 점유 · ⚠️ 부분 점유 · ❌ 미점유

해설 작성 규칙

각 테이블 직후 글머리 기호 기반 해설을 배치합니다.
해설은 600자 내외로 작성합니다.
메인 불릿은 핵심 메시지(굵게), 하위 불릿은 근거·세부 사항으로 계층화합니다.
테이블에 표시된 숫자/기호를 그대로 읽지 않고, 그 의미를 한 단계 위에서 해석합니다.
