## 8. Phase 5-1 — KBF User Prompts (AI 챗봇 예시 질문 생성)

### 목적

CEP와 KBF를 기반으로 실제 사용자가 AI 챗봇에 입력할 법한 **자연스러운 질문**을 생성합니다.

**개수는 `1 + KBF 개수`입니다. 고정값이 아닙니다.**
KBF 3개면 4개, 2개면 3개, 1개면 2개, 0개면 1개입니다.
질문의 구성은 아래 순서로 고정하되, **KBF가 없는 자리는 만들지 않습니다.**

| 순번 | 구성        | 설명                                                                             |
| ---- | ----------- | -------------------------------------------------------------------------------- |
| 1    | CEP 단독    | CEP 상황 자체를 질문으로 옮긴 것. KBF는 언급하지 않되, **문제 영역은 남깁니다.** |
| 2    | CEP × KBF 1 | CEP 상황에서 첫 번째 KBF를 조건으로 붙인 질문                                    |
| 3    | CEP × KBF 2 | CEP 상황에서 두 번째 KBF를 조건으로 붙인 질문                                    |
| 4    | CEP × KBF 3 | CEP 상황에서 세 번째 KBF를 조건으로 붙인 질문                                    |

▎**KBF가 2개면 3번까지만 만듭니다.** 4번 자리를 채우려고 KBF 두 개를 섞은 질문을
추가하지 마세요. 그것은 규격 위반이며, 아래 작성 규칙의 "하나의 KBF만" 조항과도 충돌합니다.

> 개정 이력
>
> - v.1.2.0 (0825): 1번 질문(CEP 단독)에 **문제 영역 유지** 조건과 **카테고리 소환 자가 점검** 추가.
> - v.1.2.0 (0825): 1번 질문(CEP 단독)에 **문제 영역 유지** 조건과 **카테고리 소환 자가 점검** 추가.
>   개수 표기를 4 고정에서 `1 + KBF 개수` 가변으로 전면 교체 — 본문 여러 곳의 "4개"가 앵커로 작동했다.
>   근거: 1473 5장 중 **4장이 개수 위반**(KBF 2 → 질문 4, KBF 0 → 질문 4). 잉여 질문은 모두 KBF를 섞은 형태였다.
>   ⚠ 백엔드 정합 필요: 응답 배열 길이 검증값을 **1~4 가변**으로. 현재 고정값 4면 KBF 0개 카드가 실패한다.
> - v.1.1.0 (0814): 출력 9개(KBF당 3개) → **4개(CEP 단독 1 + CEP×KBF 3)**로 변경. 질문별 역할을 순번으로 고정.
>   ⚠ 백엔드 정합 필요: 응답 배열 길이 검증값 9 → 4.
> - v.1.0.0 (0714): 나노인텐트가 Phase 4 출력에서 제거됨에 따라 입력 변수 `{{nano_intent}}` 제거.
>   ⚠ 백엔드 정합 필요: `buildKbfUserPromptsPrompt(...)`의 nano_intent 인자 제거.

### 입력 변수

| 변수                          | 설명                                                              | 예시                              |
| ----------------------------- | ----------------------------------------------------------------- | --------------------------------- |
| `{{cep}}`                     | CEP 상황 (`card.cep`)                                             | `아침 샤워 후 머리 빠질 때`       |
| `{{kbf}}`                     | 카드의 모든 KBF를 `", "` 로 연결한 문자열 (`", ".join(kbf_list)`) | `약산성 pH 제품, 무향, 저자극`    |
| `{{response_language_label}}` | 응답 언어 라벨 (locale KR/JP/US 기준, 기본값 Korean)              | `Korean` / `Japanese` / `English` |

**KBF 순서가 곧 질문 순서입니다.** `{{kbf}}`는 `", "` 로 연결된 문자열이므로, 연결한 순서(`kbf_list`의 인덱스 순서)가 그대로 2·3·4번 질문에 대응합니다. 백엔드에서 KBF 순서를 재정렬하면 질문 순서도 함께 바뀝니다.

### 출력 형식

JSON 배열 (**길이 = 1 + KBF 개수**, 최대 4개)

```json
// KBF 3개 → 4개
["CEP 자체를 옮긴 질문", "CEP × KBF1 질문", "CEP × KBF2 질문", "CEP × KBF3 질문"]

// KBF 2개 → 3개
["CEP 자체를 옮긴 질문", "CEP × KBF1 질문", "CEP × KBF2 질문"]

// KBF 0개 → 1개
["CEP 자체를 옮긴 질문"]
```


KBF가 3개 미만인 경우: `1 + KBF 개수` 만큼만 출력합니다(KBF 2개 → 3개 항목). KBF가 3개를 넘으면 앞의 3개만 사용합니다.
**KBF가 0개면 1번 질문 하나만 출력합니다.** Phase 5 v.2.1.0부터 근거를 붙이지 못한 KBF는 내지 않으므로 0개가 정상입니다.

### Prompt 템플릿

```
<!-- v.1.2.0_phase5-1_AI 챗봇 예시 질문 생성_KR_0825.md -->
아래의 CEP (Category Entry Point)와 KBF (Key Buying Factors)를 활용해, 실제 사용자가 AI 챗봇(ChatGPT, Gemini, Perplexity 등)에 물어볼 법한 자연스러운 질문을 생성하세요.

**만들 질문의 개수는 `1 + KBF 개수`입니다.** 먼저 KBF가 몇 개인지 세고 시작하세요.
KBF 3개 → 4개 / 2개 → 3개 / 1개 → 2개 / 0개 → 1개.
AI 검색에서 흔히 나타나는, 구매 의도가 높은 프롬프트에 집중하세요.
톤: 도움을 주는 친구와 대화하듯 친근하고 편안하며 다가가기 쉬운 스타일로 작성하세요.

Input:
- CEP (Category Entry Point): {{cep}}
- KBFs (Key Buying Factors): {{kbf}}

KBFs는 ", " 로 구분된 목록입니다. 앞에서부터 순서대로 KBF1, KBF2, KBF3입니다.

질문의 구성은 아래 순서로 고정합니다. 순서를 바꾸지 마세요.
**KBF가 없는 번호는 만들지 않습니다.**
1. CEP 상황 자체를 질문으로 옮깁니다. KBF는 언급하지 않습니다.
2. CEP 상황에 KBF1을 조건으로 붙인 질문
3. CEP 상황에 KBF2를 조건으로 붙인 질문
4. CEP 상황에 KBF3을 조건으로 붙인 질문

작성 규칙:
- 각 질문은 하나의 KBF만 다룹니다. 두 개 이상의 KBF를 한 질문에 섞지 마세요.
- **개수를 채우려고 KBF를 섞은 질문을 덧붙이지 마세요.** KBF가 2개면 질문은 3개에서 끝입니다.
  ("A와 B를 함께 고려해서…", "A 말고도 어떤 점을…" 같은 문장이 나왔다면 잉여 질문을 만든 것입니다.)
- KBF 표현을 그대로 옮겨 붙이지 말고, 사용자가 실제로 쓸 법한 말로 자연스럽게 녹여 쓰세요.
- 네 질문 모두 같은 CEP 상황 안에 있어야 합니다. 상황을 바꾸거나 새로 만들지 마세요.
- 브랜드명이나 제품명은 넣지 마세요.
- 질문마다 문장 구조를 달리해, 같은 문형이 반복되지 않게 하세요.
- KBF가 3개 미만이면 있는 개수만큼만 만들어 총 (1 + KBF 개수)개를 출력합니다. KBF가 3개를 넘으면 앞의 3개만 씁니다. KBF가 0개면 1번 질문 하나만 출력합니다.

카테고리 소환 조건:
- 1번 질문은 KBF를 쓰지 않지만, **무엇을 하려다 막혔는지(문제 영역)는 반드시 남깁니다.**
  영역까지 지우면 이 카테고리와 무관한 생활 상담 질문이 됩니다.
  (✗ 아이 낮잠 시간에 큰 소리가 날까 봐 신경 쓰이는데 어떻게 대처할까? — 답은 백색소음기·방음이 된다)
  (✓ 무릎 꿇고 바닥을 닦다 보니 헹구고 짜는 게 번거로운데 어떤 방식이 덜 지칠까? — 답에 이 카테고리가 들어온다)
- **자가 점검** — 만든 질문을 AI 챗봇에 넣었다고 상상하세요. 답에 이 카테고리가 후보로 나옵니까?
  생활 조언이나 관리 요령만 나온다면, 그것은 질문의 문제가 아니라 **CEP 문장에 영역이나 수단이 빠진 것**입니다.
- 그런 경우에도 **질문에 없는 말을 넣어 억지로 카테고리를 부르지 마세요.** CEP 상황에 있는 말로만 씁니다.
  상황을 보정해 그럴듯하게 만들면 상류 단계의 문제가 가려집니다. 있는 그대로 쓰세요.

Output language: {{response_language_label}}

출력 직전 자가 점검: **배열 길이가 `1 + KBF 개수`와 같습니까?** 세어 보고 다르면 맞추세요.

응답 형식(오직 JSON 배열만 출력하고 그 외에는 아무것도 출력하지 마세요):
["질문1", "질문2", ...]   ← 길이는 1 + KBF 개수
```
