brand_nonBrand (CEP)

**v. 26.07.06**

### Instruction

与えられた検索語 {{keyword}} を見て、この検索語が「ブランド検索語」かどうかを判断します。  
**「ブランド検索語」**とは、**特定のブランド**あるいは**特定の製品/モデル**と直接関連する検索語を指します。  
**「ブランド」という単語が含まれていても、特定のブランドを指すのではなく一般名詞として使われている場合（例：ランキング、おすすめ、種類 などと結合）には「一般検索語」と判断します。**

与えられた検索語が「ブランド検索語」であれば "brand" に true を、「一般検索語」であれば false を返してください。  
検索語が「ブランド検索語」であれば、判断の根拠となる**検索語の一部分**を**抽出**して "brand_part" に併せて返してください。（**検索語に現れたそのまま返してください。**）  
検索語が「一般検索語」であれば "brand_part" に空文字列を返してください。

追加の説明なしに結果のみを返してください。

**ブランド検索語：**

- 会社名（例：LG、삼성）
- サービス名（例：유튜브、넷플릭스）
- ブランド名（例：갤럭시、그램、아이폰）
- 特定ブランドの主要な**製品（モデル）名**（例：s25、프로 16）
- ブランド名と製品カテゴリが結合された検索語（例：시디즈 게이밍 의자）

**一般検索語：**

- 一般的な製品カテゴリ（例：스마트폰、노트북、세탁기、냉장고、세정제、화장품）
- 一般名詞（例：레티놀、사과）
- **「ブランド」という単語が含まれた一般的なキーワード（例：골프 브랜드 순위、2025 최고의 브랜드）**

**判断基準：**

- あくまで**検索語自体**に特定のブランド名・製品名・モデル名が含まれているかを基準に判断します。（別途の検索結果は提供されないため、検索語のテキストのみで判断します。）
- '애플'（果物でありブランド）、'토스'（動詞であり送金アプリ）のように、一般名詞とブランド名が重なって意味が曖昧な場合には、一般的に通用する意味と検索語の文脈を基に判断します。

### Output Format

{
"keyword": str -> 入力の {{keyword}} 値をそのままコピー,
"brand": bool,
"brand_part": str
}

### Input

{{keyword}}
