# 샘플 입력 fixture — agent_aio_gap의 4섹션 출력 모킹

> 이 파일은 `agent_aio_owned`의 검증을 위해 작성된 모킹 데이터입니다. 동일 도메인(Logitech MX Vertical 라인업)에서 갭 분석 에이전트가 산출했을 법한 4섹션 마크다운을 가정합니다.
>
> - 의미적 갭 매핑: [공통 갭] 2개 + [차이 갭] 1개
> - 보강 권장사항: [통합형] 1개 + [분리형] 1개 + **언드 단독** 1개(필터링 검증용)
>
> 본 fixture는 `agent_aio_gap/src/A_*.md`(MX Vertical/Lift/MX ERGO 페이지 파싱) + `B_*.md`(수직 마우스 검색 질문) + `C_*_1~3.md`(GPT 3회 응답)를 입력으로 한 가상의 진단 결과입니다.

---

## 1) 분석 개요

수직 마우스 추천 의도에는 손목 부담 완화 근거가 핵심이지만, 자사 페이지는 자세 교정 효용 위주로만 무게중심이 잡혀 있어 정량 비교·연령별 적합성·실사용자 후기 신호가 결손되어 있습니다.

:::accordion{title="개요 확인"}
**➊ AI 검색 질문의 사용자 의도(CEP) 요약**

- **CEP**: 장시간 PC 작업으로 손목 통증을 겪는 30~50대 사용자가 인체공학 마우스를 비교 탐색하는 상황
- **KBF 단서**: :k[손목 부담], :k[수직 각도], :k[자세 교정]
- **RTB 단서**: 정량 비교 수치, 인체공학자 인증, 사용자 후기 인용

**➋ AI 응답이 공통적으로 다룬 의미 영역 (공통 영역)**

- **공통 영역 1**: 인체공학 근거(각도·근육 긴장 완화) — :k[57° 수직 각도], :k[근육 긴장 완화]
- **공통 영역 2**: 경쟁 제품 정량 비교 — :k[Anker 수직 마우스 비교], :k[가격 대비 성능]
- **공통 영역 3**: 사용자 후기·실사용 시나리오 — :k[장시간 사용 후기], :k[손목 통증 완화 경험담]

**➌ 자사 페이지의 무게중심**

- 자세 교정·근육 긴장 완화 효용 진술 + 사양 및 호환성 섹션 + 지속가능성 메시지에 분량 집중
- :k[자연스러운 악수하는 듯한 자세], :k[손 움직임 75% 감소]

**➍ 갭 한 줄 통찰**

- 자사 페이지는 "왜 인체공학적인가"의 자체 근거는 충실하지만, "왜 다른 제품보다 나은가"의 비교·후기 신호가 결손되어 AI 응답에 자사 브랜드가 약하게 인용됩니다.
  :::

## 2) 브랜드 노출 분석

자사 브랜드는 AI 응답 1번에서만 언급되고 2·3번에는 등장하지 않으며, 그 자리에 Anker·Logitech Lift 등 정량 비교가 가능한 제품이 인용되어 있습니다.

:::accordion{title="브랜드 노출 확인"}
**➊ 자사 브랜드 노출 현황**

- **노출 여부**: 부분 노출
- **노출 위치**: AI 응답 1번의 "추천 1순위" 단락 — :k[로지텍 MX Vertical]
- **노출되지 않은 응답**: AI 응답 2번, AI 응답 3번

**➋ 자사 외 브랜드 노출 패턴**

- **브랜드 X (Anker 수직 마우스)**: 등장 응답 — AI 응답 2번, AI 응답 3번 / 인용 근거 — :k[가격 대비 성능], :k[입문용 추천]
- **브랜드 Y (Logitech Lift)**: 등장 응답 — AI 응답 3번 / 인용 근거 — :k[작은 손에 적합한 크기], :k[중간 가격대]

**➌ 자사 브랜드 미노출/약노출 가설**

- 자사 페이지에 부족한 신호 유형 1: "정량적 비교 수치 부재" — 경쟁 제품과의 각도·무게·DPI 비교 표 없음
- 자사 페이지에 부족한 신호 유형 2: "사용자 후기 인용 부재" — 실사용 시나리오·통증 완화 경험담 인용 없음
  :::

## 3) 의미적 갭 매핑

공통 갭은 비교 신호와 후기 신호의 부재로 수렴하며, 차이 갭은 연령별 적합성 안내 부재로 나타납니다.

:::accordion{title="의미적 갭 확인"}
**➊ [공통 갭] 경쟁 제품 정량 비교 — 비교 신호 부재**

- **AI 응답 근거**: AI 응답 1번·2번·3번 모두 — :k[Anker 수직 마우스 비교], :k[가격 대비 성능]
- **자사 페이지 점검**: 없음 — 자사 페이지는 자체 사양만 나열하고 경쟁 제품과의 정량 비교 표가 없음
- **필요 엔티티 후보**: :k[Anker 수직 마우스], :k[Logitech Lift], :k[수직 각도], :k[무게]
- **필요 토픽 후보**: 비교 표, 정량 사양 대조, 가격대별 추천 가이드
- **AI 노출 저해 가설**: 비교 데이터가 없어 AI가 "비교 가능한 정보"를 자사 페이지에서 회수하지 못함

**➋ [공통 갭] 사용자 후기·실사용 시나리오 — 경험 신호 부재**

- **AI 응답 근거**: AI 응답 1번·2번·3번 모두 — :k[장시간 사용 후기], :k[손목 통증 완화 경험담]
- **자사 페이지 점검**: 표현은 있으나 의미적으로 인접 부재 — :k[자연스러운 악수하는 듯한 자세] 같은 자체 메시지만 있고 외부 사용자 인용 없음
- **필요 엔티티 후보**: :k[장시간 사용 후기], :k[손목 통증 완화 경험담], :k[직장인 사용 사례]
- **필요 토픽 후보**: 사용자 후기 카드, 실사용 시나리오 단락, 인터뷰 인용
- **AI 노출 저해 가설**: 외부 인용 신호가 없어 AI가 "신뢰할 만한 후기"를 자사 페이지에서 인용하지 못함

**➌ [차이 갭] 연령별 적합성 안내 — 30~50대 맞춤 신호 부재**

- **등장 응답**: AI 응답 3번에만 등장 — :k[중장년 직장인 추천], :k[연령별 손목 통증 빈도]
- **자사 페이지 점검**: 없음 — 연령·직군별 적합성에 대한 별도 안내 없음
- **필요 엔티티 후보**: :k[30~50대 직장인], :k[중장년 사용자], :k[연령별 손목 통증 빈도]
- **필요 토픽 후보**: 연령별 적합성 가이드, 직군별 사용 팁
- **AI 노출 저해 가설**: 연령 단서가 없어 AI가 30~50대 추천 맥락에서 자사 제품을 우선 인용하지 못함
  :::

## 4) 보강 권장사항

비교·후기 신호는 기존 페이지에 통합 보강하고, 연령별 적합성은 별도 페이지로 분리하며, 외부 인용 신호 일부는 언드 채널로 라우팅합니다.

:::accordion{title="보강 권장사항 확인"}
**➊ [통합형] 권장 1**

- **대상 갭**: 의미적 갭 매핑의 ➊ 경쟁 제품 정량 비교 — 비교 신호 부재
- **보강 방향**: 자사 페이지의 "사양 및 호환성" 섹션 하단에 경쟁 제품과의 정량 비교 표를 추가해 비교 신호를 보강할 필요가 있음
- **엔티티 후보**: :k[Anker 수직 마우스], :k[Logitech Lift], :k[수직 각도], :k[무게]
- **토픽 후보**: 비교 표, 정량 사양 대조
- **채널 힌트**: 온드
- **통합 판단 근거**: 자사 페이지의 사양 섹션이 이미 자체 사양을 다루고 있어 동일 컨텍스트 내 보강이 자연스러움

**➋ [분리형] 권장 2**

- **대상 갭**: 의미적 갭 매핑의 ➌ 연령별 적합성 안내 — 30~50대 맞춤 신호 부재
- **보강 방향**: 30~50대 직장인의 손목 통증 빈도와 사용 시나리오를 다루는 별도 가이드 페이지가 필요함
- **엔티티 후보**: :k[30~50대 직장인], :k[연령별 손목 통증 빈도], :k[중장년 사용자]
- **토픽 후보**: 연령별 적합성 가이드, 직군별 사용 팁
- **채널 힌트**: 온드+샘플
- **분리 판단 근거**: 연령별 가이드는 제품 페이지의 사양·기능 무게중심과 결이 달라 별도 페이지로 분리하는 편이 사용자 의도와 정합함

**➌ [통합형] 권장 3**

- **대상 갭**: 의미적 갭 매핑의 ➋ 사용자 후기·실사용 시나리오 — 경험 신호 부재
- **보강 방향**: 외부 사용자 인용·인터뷰는 자사 페이지보다 커뮤니티·리뷰·전문가 인용 영역에서 자연 형성되도록 하는 편이 신뢰도가 높음
- **엔티티 후보**: :k[장시간 사용 후기], :k[손목 통증 완화 경험담]
- **토픽 후보**: 사용자 후기 카드, 인터뷰 인용
- **채널 힌트**: 언드
- **통합 판단 근거**: 자사 페이지에 외부 후기를 직접 게재하면 자연스럽지 않으며, 언드 채널에서 형성된 인용을 AI가 회수하는 편이 효과적임
  :::
