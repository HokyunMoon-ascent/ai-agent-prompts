# agent_aiOpt_gap v.0.2.0 Execution Answer Example — Logitech Ergo Series Case

> v.0.2.0 new: 5 Entity Gap Categories (Category / Attribute / CEP / Relation / Trust) + 4 Causal Signals (Relevance / Trustworthiness / Diversity / Freshness) + Brand Mention × Content Citation 2-axis Matrix

## 1) Analysis Overview

The AI search query's user asks in one shot for a 50–70° vertical with left/right coverage, side thumb buttons, and review-based RTB, with the intent "quickly test whether wrist soreness is caused by posture." Meanwhile the Owned Page concentrates on per-product core-feature descriptions, so the perceived-effect timeline, posture/environment guide, external review RTB, and the "alternating left/right use" scenario matching are all missing, and at the remediation-prioritization stage — rather than mere exposure confirmation — 5-category gaps surface in multiple layers.

:::accordion{title="Overview Check"}
**➊ Summary of AI search query user intent (CEP)**

- **CEP**: an immediate-verification purchase consideration aimed at "wrist soreness with a regular mouse → quickly test whether posture is the cause"
- **KBF cues**: :k[버티컬], :k[손목이 꺾이는 느낌], :k[좌/우 선택], :k[엄지 측면 버튼], :k[후기/입소문]
- **RTB cues**: reviews, word-of-mouth, and user-perception reports that pain has actually decreased

**➋ Semantic areas the AI Responses commonly cover (Consensus area)**

- **Perceived-effect timeline**: :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]
- **Posture / environment companion guide**: :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기]
- **External review / media RTB**: :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[다나와]
- **Alternating left/right use scenario**: :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보], :k[좌/우 각각 모델 있음]

**➌ Owned Page center of gravity**

- The Owned Page centers on self-claim-based ergonomic-effect descriptions such as :k[57° 손목이 편한 각도], :k[근육 긴장 10% 줄여주고], :k[자세 교정] and the lineup introduction of :k[Lift], :k[MX Vertical], :k[MX ERGO]

**➍ One-line gap insight**

- The Owned Page covers "product-level benefit descriptions" but lacks the time-axis, environment, external RTB, and scenario guides users need right before the decision, so part of the owned lineup (Lift, MX ERGO) is not being called up at the AI Response composition stage
  :::

## 2) Brand Exposure Analysis

The "Mention ⭕ × External Citation ❌ (External Dependency)" quadrant — where only the owned brand :k[MX Vertical] is exposed — dominates, while :k[Lift] and :k[MX ERGO] sit in the "Mention ❌ × External Citation ⭕ (Competitor Exposure)" quadrant, with the Brand Mention × Content Citation 2-axis matrix revealing that competitor lineups are taking the seats via external media.

:::accordion{title="Brand Exposure Check"}
**➊ Brand Mention × Content Citation 2-axis Matrix**

- **Mention ⭕ × Owned Citation ⭕ (internally controllable)**: no instance of owned content citation in these responses — no trace of the Owned Page being cited as an RTB source in Responses 1, 2, or 3
- **Mention ⭕ × External Citation ❌ (external dependency)**: :k[MX Vertical] / External citation cues — :k[pcgamer.com], :k[rtings.com], :k[laptopmag.com], :k[다나와] (owned brand is exposed but RTB is pulled only from external media)
- **Mention ❌ × External Citation ⭕ (competitor exposure)**: with owned :k[Lift] / :k[MX ERGO] missing, :k[Kensington Pro Fit Ergo Vertical], :k[Perixx PERIMICE-713], :k[Evoluent VerticalMouse 4], and :k[Kensington Orbit Trackball] take the seats via external media citations
- **Mention ❌ × Citation ❌ (total absence)**: the owned :k[Lift] pair operation in the alternating left/right scenario appears nowhere in the responses — suspected CEP / Relation Gap area

**➋ Quadrant-Level Interpretation**

- **External dependency area**: :k[MX Vertical] is exposed but owned RTB is nowhere in the responses, so multiplying earned media signals is the primary lever; without recovery, RTB control stays external
- **Competitor exposure area**: absence of :k[Lift] / :k[MX ERGO] is driven by both Category Gap (no recognition of the trackball-alternative lineup) and Relation Gap (left/right pair lineup not connected) at once
- **Total absence area**: the :k[Lift] pair scenario combines CEP Gap (missing alternating left/right context) and Relation Gap (missing left/right pair linkage)

**➌ Non-Owned Brand Exposure Patterns**

- :k[Kensington Pro Fit Ergo Vertical]: Responses 1 and 3 / :k[약 47° 바디 각도], :k[왼손 전용 모델], :k[손목 회외/회내 부담 감소]
- :k[Perixx PERIMICE-713]: Response 2 / :k[좌/우 각각 모델 있음], :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보]
- :k[Evoluent VerticalMouse 4]: Response 3 / :k[거의 수직에 가까운 각도]
- :k[Kensington Orbit Trackball]: Response 3 / :k[손목 부담 거의 없음] (trackball-alternative context)

**➍ Hypotheses for Owned Brand Non-/Weak Exposure**

- Missing signal 1 — absence of alternating left/right scenario matching: primary gap category **CEP Gap** + supplementary **Relation Gap**, missing signal **Diversity**
- Missing signal 2 — absence of external review / media RTB: primary gap category **Trust Gap**, missing signal **Trustworthiness**
- Missing signal 3 — absence of recognition for the trackball-alternative category: primary gap category **Category Gap** + supplementary **Relation Gap**, missing signal **Relevance**
  :::

## 3) Semantic Gap Mapping

Four Consensus gaps appearing consistently across all three responses but semantically absent from the Owned Page, plus three Variance gaps appearing only in some responses, are derived; all carry 5-category and 4-axis labels, used as input for prioritization in the downstream enhancement recommendations.

:::accordion{title="Semantic Gap Check"}
**➊ [Consensus Gap] Perceived-effect timeline guide**

- **Gap category**: CEP Gap (primary) + Trust Gap (supplementary — timeliness cues form user trust)
- **Missing signal**: Relevance, Diversity
- **AI Response evidence**: Responses 1, 2, and 3 — :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)], :k[1~2주 적응 기간]
- **Owned Page check**: no mention of adaptation periods or perception-change milestones. Benefit claims like :k[근육 긴장 10% 줄여주고] exist, but time-axis guidance is absent
- **Required entity candidates**: :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]
- **Required topic candidates**: step-by-step perception-change guide, honest note about adaptation-period awkwardness, adaptation-acceleration tips
- **AI exposure inhibition hypothesis**: because the Owned Page doesn't answer "if I buy now, when does it stop hurting," AI composes the time-axis answer from external media

**➋ [Consensus Gap] Posture / environment companion guide**

- **Gap category**: CEP Gap (primary) + Relation Gap (supplementary — connecting mouse with environment elements)
- **Missing signal**: Relevance, Diversity
- **AI Response evidence**: Responses 1 and 3 — :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기], :k[책상 높이(팔꿈치 각도)·마우스 간격]
- **Owned Page check**: usage-environment guidance like posture, desk, and arm support is absent. The focus is on product-only benefit descriptions
- **Required entity candidates**: :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기]
- **Required topic candidates**: environment companion checklist, "mouse + posture + desk" three-element guide
- **AI exposure inhibition hypothesis**: AI bundles pain reduction with environment guidance rather than the mouse alone, so the Owned Page — which doesn't cover environment guidance — is only partially cited

**➌ [Consensus Gap] External review / media RTB quotation area**

- **Gap category**: Trust Gap (primary)
- **Missing signal**: Trustworthiness, Diversity
- **AI Response evidence**: Responses 1, 2, and 3 all directly quote external media — :k[다나와], :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[Reddit]
- **Owned Page check**: self-verification statements like :k[사용자 테스트 완료. 인체공학자 인증.] exist but external-media or community quotations are absent
- **Required entity candidates**: specialist media review quotation, community review quotation, clinical / use-case quotation
- **Required topic candidates**: review / media quotation box, user pain-report collection
- **AI exposure inhibition hypothesis**: AI prioritizes external media as RTB signals, so a page with only self-claims fails to become an RTB source

**➍ [Consensus Gap] Alternating left/right use scenario matching**

- **Gap category**: CEP Gap (primary) + Relation Gap (supplementary — connecting left/right pair lineup)
- **Missing signal**: Relevance, Diversity
- **AI Response evidence**: Responses 1, 2, and 3 — :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보], :k[좌/우 각각 모델 있음]
- **Owned Page check**: :k[왼손, 오른손 어디에나 딱 맞는 Lift] and :k[왼손용도 있어요] exist, but a left/right pair-operation scenario guide is absent
- **Required entity candidates**: :k[Lift] left/right pair, :k[좌/우 각각 모델 있음]
- **Required topic candidates**: alternating left/right user scenario page or Lift pair operation guide
- **AI exposure inhibition hypothesis**: because the scenario is not bundled on the page, AI fills the same scenario with external lineups

**➎ [Variance Gap] Quick-test recommendation combination**

- **Gap category**: CEP Gap (primary)
- **Missing signal**: Diversity
- **Appearing responses**: clearly only in Response 2 — :k[MX Vertical (메인) + Perixx (좌/우 교차 테스트용)]
- **Owned Page check**: structured by per-model standalone areas. No guidance on combination operation by user scenario
- **Required entity candidates**: main-model + supporting-model pair labels
- **Required topic candidates**: per-scenario combination recommendations, variable-isolation verification scenarios
- **AI exposure inhibition hypothesis**: when users target cause verification, AI builds combination answers and the Owned Page is limited to single-model answers

**➏ [Variance Gap] Honest acknowledgment of drawbacks / limits**

- **Gap category**: Trust Gap (primary)
- **Missing signal**: Trustworthiness
- **Appearing responses**: Response 2 — :k[처음 2~3일은 오히려 어색함], :k[작은 손이면 큰 모델 불편], :k[게임용으로는 부적합]
- **Owned Page check**: no mention of limits or drawbacks. A purely benefit-focused message
- **Required entity candidates**: unsuitable scenarios, adaptation-period awkwardness, small-hand / large-model mismatch
- **Required topic candidates**: honest "in these cases not suitable" copy
- **AI exposure inhibition hypothesis**: AI cites drawbacks for a balanced answer, so without owned coverage drawback quotations come from external sources

**➐ [Variance Gap] Hand-size model matching guide**

- **Gap category**: Attribute Gap (primary) + Relation Gap (supplementary — connecting hand size ↔ lineup)
- **Missing signal**: Diversity
- **Appearing responses**: Responses 2 and 3 — :k[작은 손이면 큰 모델 불편], "ELECOM suits smaller hands"
- **Owned Page check**: :k[조금 작거나 보통 크기의 손에 잘 맞아요] (Lift) partially exists. Matching signal on the MX Vertical side is absent
- **Required entity candidates**: hand-size labels (small / medium / large), per-model hand-size recommendations
- **Required topic candidates**: hand-size matching guide
- **AI exposure inhibition hypothesis**: because the matching guide is missing, AI pulls in external lineups
  :::

## 4) Enhancement Recommendations

Of the seven gaps, the perceived-effect timeline, environment guide, hand matching, and lineup scenarios fit Integrated, while the external review RTB and integrated ergonomics hub fit Separated; each recommendation indicates how the primary gap category and missing-signal axis will be supplemented.

:::accordion{title="Enhancement Recommendation Check"}
**➊ [Integrated] Perceived-effect timeline guide enhancement (MX Vertical / Lift area)**

- Target gap: ➊ (CEP Gap + Trust Gap, Relevance · Diversity)
- Enhancement direction: enhance with an adaptation-stage perception-change guide in the product area
- Entity candidates: :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]
- Channel hint: Owned + Sample / Integration rationale: adding it with the same pattern next to benefit descriptions is most natural

**➋ [Integrated] Posture / environment companion guide (lineup hub)**

- Target gap: ➋ (CEP Gap + Relation Gap, Relevance · Diversity)
- Entity candidates: :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기]
- Channel hint: Owned / Integration rationale: shared across the lineup, so integrate into a higher-level guide area

**➌ [Separated] External review / media RTB hub (Ergo Series separate page)**

- Target gap: ➌ (Trust Gap, Trustworthiness · Diversity)
- Entity candidates: specialist media reviews, user reviews, clinical / case quotations
- Channel hint: Earned + Owned / Separation rationale: separate into a lineup-level hub to gather external search visibility

**➍ [Integrated] Alternating left/right use scenario (Lift area)**

- Target gap: ➍ (CEP Gap + Relation Gap, Relevance · Diversity)
- Entity candidates: :k[Lift] left/right pair
- Channel hint: Owned + Earned / Integration rationale: close to the essence of the Lift lineup

**➎ [Separated] Integrated ergonomics guide page**

- Target gap: bundle of ➊ + ➋ + ➐
- Entity candidates: adaptation stages, posture elements, hand-size labels
- Channel hint: Owned / Separation rationale: guide signals are common across multiple products, so separate into a single hub

**➏ [Integrated / Sample] Honest drawback / limit acknowledgment copy (product area)**

- Target gap: ➏ (Trust Gap, Trustworthiness)
- Entity candidates: :k[처음 2~3일은 오히려 어색함], :k[작은 손이면 큰 모델 불편], :k[게임용으로는 부적합]
- Channel hint: Sample + Owned / Integration rationale: drawback copy is short and varies per product, so integrate within each product area
  :::
