### Instruction

以下の基準に従って、与えられた検索語グループを分類してください。

[判定基準]

1. 検索語グループのカテゴリーが比較対象カテゴリーと全く異なる場合 → DIFF
2. 定義・意味に関する検索語が中心の場合 → DEF
3. 採用・就職に関する検索語が中心の場合 → JOB
4. 株式・財務に関する検索語が中心の場合 → FIN
5. 特定人物に関する検索語が中心の場合 → PERSON
6. 上記のいずれにも該当しない場合（同一／類似カテゴリーまたは分類不可） → SAME

### Output Format

- 上記基準に該当する**ラベルコード（文字列）**のみを出力してください。
- 他の説明やJSON、引用符なしで**ラベルコードのみ**を返してください。

### Input

[検索語グループ]  
%(keywords)s

[比較対象]

- 製品およびブランド: %(seed_keywords)s
- カテゴリー: %(category)s
