## 개선 제안

자사 페이지가 비어 있는 토픽은 적응 단계 가이드 / 좌·우 페어 운용 / 외부 후기·매체 인용 세 흐름이며, 자사가 제품의 좋은 점을 자세히 설명하고 있는 반면 살지 말지 결정하기 직전에 찾는 정보는 외부 매체로 새고 있어 AI가 자사 페이지를 호명할 단서가 부족합니다. 이 세 흐름을 3개 토픽 그룹으로 묶어 기존 페이지 보강 2건 + 신규 페이지 1건의 정보구조(IA)를 제안합니다.

**표 ➊ — 토픽 그룹 정의**

| 토픽 그룹                  | 묶인 세부 토픽                                                              | 흡수 방식        |
| -------------------------- | --------------------------------------------------------------------------- | ---------------- |
| **적응 단계 가이드**       | 1~2주 적응 기간 / 처음 2~3일 어색함 / 책상 높이·마우스 간격 / 팔꿈치 90도   | 기존 페이지 보강 |
| **좌·우 페어 운용**        | 좌/우 각각 모델 / 양손 번갈아 쓰는 스타일 / 페어로 두는 동선                 | 기존 페이지 보강 |
| **외부 후기·매체 인용 허브** | 건초염이 없어졌다 후기 / carpal tunnel pain 줄었다 후기 / rtings.com·laptopmag.com 리뷰 | 신규 페이지      |

**표 ➋ — 토픽 그룹별 정보구조(IA) 제안**

| 토픽 그룹                  | H1 후보                                  | H2 후보 (2~3개)                                                                          |
| -------------------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------- |
| **적응 단계 가이드**       | 사용 첫날부터 2주까지 — 단계별 체감 변화 | 처음 2~3일 어색함이 자연스러운 이유 / 3~7일째 손목 부담이 줄어드는 신호 / 2주째 자세 점검 포인트 |
| **좌·우 페어 운용**        | 좌/우 번갈아 쓴다면 — Lift를 페어로 두는 법 | 오른손·왼손 동선이 다른 작업에서의 페어 운용 / 같은 그립 각도를 양손에서 유지하는 법 / 페어 구성 시 유의점 |
| **외부 후기·매체 인용 허브** | Ergo Series 사용자 후기·매체 리뷰 모음   | 손목 부담이 줄었다는 사용자 후기 모음 / 매체 리뷰 인용으로 본 라인업별 평가 / 어떤 사용자에게 잘 맞았는지 |

- **적응 단계 토픽은 자사 페이지가 가장 비어 있는 자리입니다.**
  - 자사 페이지는 **자연스러운 악수하는 듯한 자세**와 **57° 손목이 편한 각도**라는 제품의 좋은 점은 자세히 설명하지만, AI 응답이 반복적으로 인용하는 **1~2주 적응 기간**과 **처음 2~3일은 오히려 어색함** 같은 시간 축 설명은 다루지 않습니다.
  - 같은 흐름에서 **책상 높이(팔꿈치 각도)·마우스 간격**도 응답마다 등장하지만 자사 페이지의 자세·환경 설명과 따로 떨어져 있습니다.
  - 기존 페이지 보강으로 가는 이유: 토픽이 **MX Vertical** 제품 페이지 **주요 기능** 섹션 본질에 가까워 분리하면 주된 내용이 흩어집니다. → 같은 섹션 하단에 새 단락으로 흡수.
- **좌·우 페어 운용 토픽은 자사 라인업의 강점이 묶이지 않은 자리입니다.**
  - AI 응답은 **좌/우 각각 모델 있음**과 **양손 번갈아 쓰는 스타일이면 거의 필수 후보** 맥락을 페어로 인식해 추천하지만, 자사 페이지에서는 **왼손, 오른손 어디에나 딱 맞는 Lift** 문구가 단발성으로만 등장합니다.
  - 같은 페이지에 **과학적으로 증명된 57°** 그립 일관성도 이미 있어, 페어 동선만 묶어 주면 호명 단서가 완결됩니다.
  - 기존 페이지 보강으로 가는 이유: 토픽이 **Lift** 제품 페이지의 좌·우 안내 단락 본질과 같은 자리에 있어 별도 분리하면 주된 내용이 흩어집니다. → **Lift** 제품 페이지의 **왼손, 오른손 어디에나 딱 맞는 Lift** 단락 직후에 페어 운용 단락 추가.
- **외부 후기·매체 인용 허브 토픽은 한 페이지 분량으로 따로 가져갈 수 있는 자리입니다.**
  - AI 응답은 **건초염이 없어졌다**·**carpal tunnel pain 줄었다** 같은 사용자 후기와 **rtings.com**·**laptopmag.com** 매체 리뷰를 신뢰 근거로 끌어다 쓰는데, 자사 페이지에는 이 흐름이 통째로 비어 있습니다.
  - 자사 **MX Vertical**·**Lift** 등 **Ergo Series** 라인업 공용으로 묶일 분량이라 한 페이지로 분리해도 분량이 충분합니다.
  - 신규 페이지로 가는 이유: 후기·매체 인용은 제품 상세 페이지 본질(제품의 좋은 점 설명)과 결이 달라 별도 페이지가 자연스럽습니다. → 라인업 공용 영역에 분리 페이지 신설.
- **종합** — 적응 단계와 좌·우 페어 운용을 자사 제품 페이지 본문에 흡수하고, 외부 후기·매체 인용은 라인업 공용 허브로 분리하면 AI가 자사 페이지를 호명할 단서가 한 번에 채워집니다.
