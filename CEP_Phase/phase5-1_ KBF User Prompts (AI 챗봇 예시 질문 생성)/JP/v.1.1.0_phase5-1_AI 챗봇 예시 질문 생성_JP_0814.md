## 8. Phase 5-1 — KBF User Prompts (AIチャットボット向け質問例の生成)

### 目的

CEPとKBFをもとに、実際のユーザーがAIチャットボットに入力しそうな**自然な質問4個**を生成します。

質問4個の構成は固定です。

| 順番 | 構成          | 説明                                                            |
| ---- | ------------- | --------------------------------------------------------------- |
| 1    | CEP単独       | CEPの状況そのものを質問にしたもの。KBFには触れません。          |
| 2    | CEP × KBF 1   | CEPの状況に1つ目のKBFを条件として加えた質問                     |
| 3    | CEP × KBF 2   | CEPの状況に2つ目のKBFを条件として加えた質問                     |
| 4    | CEP × KBF 3   | CEPの状況に3つ目のKBFを条件として加えた質問                     |

> 改訂履歴
> - v.1.1.0 (0814): 出力9個（KBFごとに3個）→ **4個（CEP単独1 + CEP×KBF 3）**に変更。質問ごとの役割を順番で固定。
>   ⚠ バックエンド整合が必要: レスポンス配列の長さ検証値 9 → 4。
> - v.1.0.0 (0714): nano-intentがPhase 4の出力から削除されたため、入力変数 `{{nano_intent}}` を削除。
>   ⚠ バックエンド整合が必要: `buildKbfUserPromptsPrompt(...)` の nano_intent 引数を削除。

### 入力変数

| 変数                          | 説明                                                                 | 例                                |
| ----------------------------- | -------------------------------------------------------------------- | --------------------------------- |
| `{{cep}}`                     | CEPの状況 (`card.cep`)                                               | `아침 샤워 후 머리 빠질 때`       |
| `{{kbf}}`                     | カードのすべてのKBFを `", "` で連結した文字列 (`", ".join(kbf_list)`) | `약산성 pH 제품, 무향, 저자극`    |
| `{{response_language_label}}` | 応答言語ラベル（locale KR/JP/US基準、デフォルトはKorean）             | `Korean` / `Japanese` / `English` |

**KBFの順序がそのまま質問の順序になります。** `{{kbf}}` は `", "` で連結された文字列なので、連結した順序（`kbf_list` のインデックス順）が2・3・4番目の質問に対応します。バックエンドでKBFの順序を並べ替えると、質問の順序も一緒に変わります。

### 出力形式

JSON配列（正確に4個）

```json
[
  "CEP自体を質問にしたもの",
  "CEP × KBF1 の質問",
  "CEP × KBF2 の質問",
  "CEP × KBF3 の質問"
]
```

KBFが3個未満の場合：`1 + KBFの個数` だけ出力します（KBF 2個 → 3項目）。KBFが3個を超える場合は先頭の3個のみを使います。

### リクエストモデルおよびパラメータ

| パラメータ | 設定値                                       | 備考                       |
| --------- | -------------------------------------------- | -------------------------- |
| model     | `'gpt-5.4-nano'`                             | 固定                       |
| input     | `buildKbfUserPromptsPrompt(...)` の結果文字列 | CEP / KBF / 出力言語を反映 |
| text      | `{ format: { type: 'text' } }`               | 通常テキスト出力           |
| reasoning | `{ effort: 'none' }`                         | 推論effortを最小化         |

### Prompt テンプレート

```
<!-- v.1.1.0_phase5-1_AI 챗봇 예시 질문 생성_JP_0814.md -->
以下のCEP (Category Entry Point)とKBF (Key Buying Factors)を活用して、実際のユーザーがAIチャットボット（ChatGPT、Gemini、Perplexityなど）に尋ねそうな自然な質問を4個生成してください。
AI検索で頻繁に見られる、購買意図の高いプロンプトに焦点を当ててください。
トーン：頼れる友人と会話するように、親しみやすく、カジュアルで、話しかけやすいスタイルで書いてください。

Input:
- CEP (Category Entry Point): {{cep}}
- KBFs (Key Buying Factors): {{kbf}}

KBFsは ", " で区切られたリストです。先頭から順にKBF1、KBF2、KBF3です。

質問4個の構成は以下の順序で固定します。順序を変えないでください。
1. CEPの状況そのものを質問にします。KBFには触れません。
2. CEPの状況にKBF1を条件として加えた質問
3. CEPの状況にKBF2を条件として加えた質問
4. CEPの状況にKBF3を条件として加えた質問

作成ルール：
- 各質問で扱うKBFは1つだけです。2つ以上のKBFを1つの質問に混ぜないでください。
- KBFの表現をそのまま貼り付けるのではなく、ユーザーが実際に使いそうな言葉として自然に溶け込ませてください。
- 4つの質問はすべて同じCEPの状況の中になければなりません。状況を変えたり新しく作ったりしないでください。
- ブランド名や製品名は入れないでください。
- 質問ごとに文の構造を変え、同じ文型が繰り返されないようにしてください。
- KBFが3個未満の場合は、ある個数の分だけ作り、合計（1 + KBFの個数）個を出力します。KBFが3個を超える場合は先頭の3個のみを使います。

Output language: {{response_language_label}}

応答形式（JSON配列のみを出力し、それ以外は何も出力しないでください）：
["質問1", "質問2", "質問3", "質問4"]
```
