# agent_aiOpt_gap v.0.2.3 실행 답변 예시 — Logitech Ergo Series 케이스

> v.0.2.3 변경 포인트: 출력을 2개 섹션(브랜드 노출 분석 / 의미적 갭 매핑)으로 압축 / 토픽 그룹 4~5개 정의 + 자사·경쟁사 2열 진영 표 / 각 표 직후 글머리 해설 / 아코디언 컴포넌트 제거(평면 마크다운)

## 1) 브랜드 노출 분석

자사 **MX Vertical** 한 모델만 손목 중립 영역에서 호출됐을 뿐 **Lift**·**MX ERGO** 라인업은 좌/우 페어·엄지 측면 버튼 영역에서 통째로 빠져 있고, AI가 자사 브랜드를 다룰 때에도 근거 인용은 자사 페이지가 아닌 외부 매체에 통제권이 있어 신뢰 단서까지 외부에 끌려가 있는 구도입니다.

**➊ 토픽 그룹 정의**

| 그룹                                   | 묶인 세부 토픽                                                       | 자사 대응 액션                                 |
| -------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------- |
| **A. 버티컬 각도 + 손목 중립 테스트**  | **버티컬**, **손목이 꺾이는 느낌**, 손목 중립 즉시 검증              | 자사 라인업 비교형 손목 중립 가이드 콘텐츠     |
| **B. 좌/우 페어 시나리오 운용**        | **좌/우 선택**, **자기 손에 맞는 전용 모델을 고르는 쪽**, 좌/우 페어 | **Lift** 왼손·오른손 페어 운용 시나리오 페이지 |
| **C. 엄지 측면 버튼·생산성 부가 기능** | **엄지 측면 버튼**, **추가 엄지 버튼 2개**                           | **MX ERGO** 엄지 버튼 활용 시나리오 가이드     |
| **D. 자세·환경 동반 가이드**           | **책상 높이(팔꿈치 각도)·마우스 간격**, **1~2주 적응 기간**          | Ergo Series 공용 적응·환경 가이드 허브         |

**➋ 토픽 그룹 × 진영별 노출 표**

| -------------------------------------- | :---------------------: | :-------------------------------------------------------------------------------: |

| **D. 자세·환경 동반 가이드**           |         ❌ 0/3          |                                      ❌ 0/3                                       |

> ✅ 강점 점유 · ⚠️ 부분 점유 · ❌ 미점유

- **버티컬 각도 영역(A)은 양 진영 모두 한 모델로만 호출되어 자사 우위를 만들 여지가 충분합니다.**
  - 자사는 **MX Vertical** **추천 1순위** 노출에 그쳐 **Lift**·**MX ERGO**가 같은 토픽으로 묶이지 못했습니다.
  - 경쟁사 역시 **Kensington Pro Fit Ergo Vertical** 단일 모델로 **약 47° 바디 각도**만 가져갔습니다.
- **좌/우 페어 시나리오(B)는 경쟁사 3종이 통째로 점유한 가장 큰 진영 격차입니다.**
  - **Kensington Pro Fit Ergo Vertical**, **CHERRY MW 4500**, **Perixx PERIMICE-713**이 모두 **왼손 전용 모델(Left-handed)**·**좌/우 전용 모델**로 호출됐습니다.
  - 자사는 **왼손, 오른손 어디에나 딱 맞는 Lift** 단서가 있음에도 페어 시나리오로 묶이지 못했습니다.
- **엄지 측면 버튼(C)·환경 가이드(D)는 롱테일 — D는 양 진영 공백으로 자사가 선점 가능한 자리입니다.**
- **종합** — 자사 라인업 3종 중 2종이 응답에서 통째로 빠져 있어 라인업 단위 인지 단서가 부재한 구조입니다.

**➌ 인용 출처 × 진영 노출 표**

| 인용 출처            | 자사 응답 (MX Vertical) | 경쟁사 응답 (3종) |
| -------------------- | :---------------------: | :---------------: |
| **자사 페이지 인용** |           ❌            |      ✅ 3/3       |
| **외부 매체 인용**   |           ✅            |      ✅ 3/3       |

- **자사는 자사 페이지가 자기 응답에도 인용되지 못한 반면, 경쟁사는 자기 페이지가 모든 응답에 함께 끌려 들어가 있습니다.**
  - 자사 **MX Vertical** 추천 근거는 **pcgamer.com**·**rtings.com**·**laptopmag.com** 같은 외부 매체에서만 끌어왔습니다.
  - 경쟁사 추천 근거는 브랜드 공식 페이지의 **좌/우 전용 모델**·**추가 엄지 버튼 2개** 같은 라인업 단서가 그대로 인용됐습니다.
- **결과** — 신뢰 단서 통제권이 자사 페이지 바깥에 놓여 있어 자사 페이지가 RTB 자리에서 호출되지 못하고 있습니다.

**➍ 자사 브랜드 미노출/약노출 가설**

- **부족 신호 1** — **사용자 테스트 완료. 인체공학자 인증.** 같은 자체 주장만 있고 외부 매체·후기 인용이 부재 → 신뢰 단서가 자사 페이지에 없습니다.
- **부족 신호 2** — **왼손, 오른손 어디에나 딱 맞는 Lift** 표현이 좌/우 페어 시나리오로 묶이지 않음 → 연관 토픽과의 연결이 부재합니다.

## 2) 의미적 갭 매핑

자사 페이지는 **57° 손목이 편한 각도**·**자세 교정** 같은 효익 설명에는 강점이 있지만, AI가 답변에 끌어다 쓰는 좌/우 페어 시나리오·외부 후기·환경 가이드 자리에서 라인업 단위로 비어 있어 **Lift**·**MX ERGO**가 호출되지 못하는 직접 원인이 되고 있습니다.

**➊ 토픽 그룹별 콘텐츠 갭 표**

| 토픽 그룹                              | 콘텐츠 액션                                         | 우선순위  | 자사 (3종) | 경쟁사 (3종) |
| -------------------------------------- | --------------------------------------------------- | :-------: | :--------: | :----------: |
| **B. 좌/우 페어 시나리오 운용**        | **Lift** 왼손·오른손 페어 운용 시나리오 페이지 신설 | 🔴 결정적 |   ❌ 0/3   |    ✅ 3/3    |
| **E. 신뢰 보강**                       | 외부 매체·실사용 후기·**1~2주 적응 기간** 회수 허브 | 🔴 결정적 |   ❌ 0/3   |    ✅ 3/3    |
| **A. 버티컬 각도 + 손목 중립 테스트**  | 자사 라인업 3종 비교형 손목 중립 가이드             |  🟡 기회  |   ⚠️ 1/3   |    ⚠️ 1/3    |
| **C. 엄지 측면 버튼·생산성 부가 기능** | **MX ERGO** 엄지 버튼 시나리오 가이드               |  🟡 기회  |   ❌ 0/3   |    ⚠️ 1/3    |
| **D. 자세·환경 동반 가이드**           | Ergo Series 공용 적응·환경 가이드 허브              |  🟡 보강  |   ❌ 0/3   |    ❌ 0/3    |

> 🔴 결정적 (즉시 제작) · 🟡 기회/보강 (2~3순위)

- **🔴 결정적 액션 2개(B·E)가 가장 시급한 콘텐츠 공백 — 자사 0/3 vs 경쟁사 3/3 구도가 동시에 작동합니다.**
  - **B 그룹**: **왼손, 오른손 어디에나 딱 맞는 Lift**·**왼손용도 있어요** 단서가 페어 시나리오로 묶이지 못해 연관 토픽 연결이 부재합니다.
  - **E 그룹**: **사용자 테스트 완료. 인체공학자 인증.** 같은 자체 주장만 있고 외부 후기·**처음 2~3일은 오히려 어색함** 같은 솔직한 단점 안내가 빠져 신뢰 단서가 부재합니다.
- **🟡 기회 액션 (A·C 그룹) — 자사 진입 가능성 보유**
  - **A**: 양 진영 1/3 점유 구도라 자사 **Lift**·**MX ERGO**를 묶은 비교형 가이드로 손목 중립 영역을 선점할 여지가 있습니다.
  - **C**: 경쟁사 **추가 엄지 버튼 2개** 자리에 **MX ERGO** 엄지 버튼 시나리오를 묶어 차별화 진입할 수 있습니다.
- **🟡 D 그룹** — 양 진영 모두 공백이라 자사가 **책상 높이(팔꿈치 각도)·마우스 간격** 환경 가이드를 먼저 채우면 RTB 자리 전체를 회수할 수 있습니다.

**➋ 갭 상세 (공통 갭 / 차이 갭 분리)**

각 🔴 결정적 갭마다 다음 7항목을 채웁니다.

- **갭 라벨 (B)**: **Lift** 좌/우 페어 시나리오 페어로 묶기
  - **어떤 자리에서 빠졌는가**: 연관 토픽 연결 부재(1순위) + 구매 직전 상황 단서 부재(보조)
  - **AI가 못 끌어간 원인**: 답변 의도와의 거리 + 표현 다양성 부족
  - **AI 응답 근거**: AI 응답 1번에서 **자기 손에 맞는 전용 모델을 고르는 쪽**을 좌/우 페어 시나리오의 정답으로 다루며 경쟁사 3종을 모두 호출
  - **자사 페이지 점검**: **왼손, 오른손 어디에나 딱 맞는 Lift** 표현은 있으나 의미적으로 페어 시나리오 단위로 묶여 있지 않아 인접 부재
  - **필요 엔티티 후보**: **Lift**, **왼손용도 있어요**
  - **필요 토픽 후보**: 좌/우 페어 운용 시나리오 가이드(왼손 사용자 X 오른손 사용자 페어 구성 예시)
  - **AI 노출 저해 가설**: 자사 라인업이 단일 제품 페이지에 흩어져 있어 AI가 페어 시나리오 단서로 묶지 못합니다.
- **갭 라벨 (E)**: 외부 매체·후기 인용 RTB 자사 페이지 회수
  - **어떤 자리에서 빠졌는가**: 신뢰 단서 부재(1순위) + 다뤄야 할 영역인데 부재(보조)
  - **AI가 못 끌어간 원인**: 신뢰 단서 부족 + 답변 의도와의 거리
  - **AI 응답 근거**: AI 응답 1·2번이 **pcgamer.com**·**rtings.com**·**laptopmag.com**에서 사용자 후기·적응 가이드를 RTB로 끌어다 사용
  - **자사 페이지 점검**: **사용자 테스트 완료. 인체공학자 인증.** 자체 주장만 있고 외부 매체·후기 인용은 없음
  - **필요 엔티티 후보**: **pcgamer.com**, **rtings.com**
  - **필요 토픽 후보**: 외부 매체 리뷰 발췌·실사용 후기·**1~2주 적응 기간** 적응 가이드를 묶은 RTB 허브
  - **AI 노출 저해 가설**: 자사 페이지가 RTB 자리를 비워 두어 AI가 신뢰 단서를 외부 매체로 회수해 가고 있습니다.
