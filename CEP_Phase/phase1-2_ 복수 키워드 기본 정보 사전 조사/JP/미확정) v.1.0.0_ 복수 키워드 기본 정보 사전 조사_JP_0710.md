## Phase 1-2 — 複数キーワード基本情報の事前調査 (未確定)

> **分岐条件**: ユーザーが入力したキーワードが**複数(カンマ区切り)**の場合、Phase 1 の代わりにこのプロンプトへ進みます。
> 単一キーワードなら既存の Phase 1(`基本情報の事前調査`)をそのまま使用します。

### Phase 1(単一)との相違点

| 項目      | Phase 1 (単一キーワード)          | Phase 1-2 (複数キーワード・本ドキュメント)                                              |
| --------- | --------------------------------- | -------------------------------------------------------------------------------------- |
| 入力      | 単一の製品/カテゴリ               | **カンマで区切られた複数キーワード** (レイヤー混在: カテゴリ・効能・上位概念)            |
| 処理原則  | 対象1件をそのまま調査             | **キーワードのレイヤー分類 → 代表カテゴリ1件で高解像度調査 + 効能/欠乏キーワードは別途保存** |
| 出力の追加 | —                                | `## キーワード構成分析` + `## 消費者の欠乏シグナル` セクション (効能キーワードを潰さず維持) |
| 維持      | web_search・ソース優先順位・言語  | すべて同一                                                                              |

### 目的

性格の異なる複数キーワードが入力されたとき、それらを**ひとつの曖昧な塊にマージせず**にレイヤー別に分類します。
その中から**代表となる製品カテゴリ1件**を選んで高解像度で基本情報を調査しつつ、効能/欠乏キーワードは
CEP 発掘の核心的な手がかりであるため、**別のシグナルとして保存**し、次の段階(Phase 2-2)へ引き継ぎます。

### 核心概念

- **キーワードレイヤー(Information Layer)** — **すべてのドメイン(化粧品・家電・食品・サービスなど)に共通適用**:
  - **カテゴリ(Category)** — 販売される製品群 (化粧品: `주름개선 화장품` · 家電: `게이밍 노트북` · 食品: `오메가3`)
  - **効能・属性(Effect/Benefit)** — ドメイン問わず、消費者が求める機能的な結果 (化粧品: `주름개선` · 家電: `발열 적은` · 食品: `혈행개선`)
  - **上位概念(Super-concept)** — 包括的なテーマ (化粧品: `안티에이징` · 家電: `고성능` · 食品: `건강기능식품`)
- **代表カテゴリアンカー**: 調査 subject とするカテゴリレベルのキーワード1件。明示的なカテゴリ語があればそれを、
  なければ効能/上位概念が共通して属する**最も狭いカテゴリ**を推論。
- **欠乏シグナル保存の原則**: 効能キーワードは消費者の「隠れた不便・欠乏」を直接表す言語である。
  カテゴリへ抽象化して消し去るのではなく、各効能が含意する問題状況をそのまま記録する。
- **効能レイヤー不在の許容原則**: 入力がカテゴリ・ブランド中心のため、効能キーワードが1つもない場合がある
  (例: `생수, 삼다수, 백산수, 에비앙`)。この場合は欠乏シグナルを**空欄のままにし**、存在しない効能を**でっち上げない**。

### Prompt テンプレート

```
# 役割
リサーチ専門家。ユーザーは、ひとつの製品/関心領域を異なる角度から説明する**カンマ区切りの複数キーワード**を入力しています。あなたの任務は、(a) キーワード同士がどう関連するかを理解し、(b) 共通する製品カテゴリを高解像度で調査し、(c) 個々のキーワードが明らかにする異なる消費者の欠乏シグナルを — 一つに混ぜ合わせることなく — 保存することです。

## 入力
入力はカンマで区切られた複数の語句です。例:
"주름개선 화장품, 주름개선, 안티에이징, 노화방지 화장품, 피부 탄력개선"

これらの語句は通常、情報レイヤーが**混在**しています。このレイヤー区分はビューティーに限らず、**あらゆる製品ドメイン** — 化粧品・電子機器・食品/サプリメント・家電・サービス — に適用されます:
- **Category**: 販売される製品カテゴリ(売られる対象そのもの)。化粧品: 주름개선 화장품 · 電子機器: 게이밍 노트북 · 食品: 오메가3
- **Effect/Benefit**: ドメインを問わず、消費者が求める機能的な結果。化粧品: 주름개선 · 電子機器: 발열 적은 · 食品: 혈행개선
- **Super-concept**: より包括的な上位テーマ。化粧品: 안티에이징 · 電子機器: 고성능 · 食品: 건강기능식품

絶対にしてはいけない二つのこと:
1. すべての語句をひとつの曖昧な対象にマージし、カンマ文字列をそのまま検索してはいけません。
2. 各キーワードを互いに無関係な別個の製品として独立に調査してはいけません。
これらを、ひとつの製品カテゴリを見る複数のレンズとして扱ってください。

# 調査プロセス
1. **分類**: すべての入力キーワードを Category / Effect·Benefit / Super-concept / Other に分類します。
2. **アンカー**: 代表となる製品カテゴリを調査対象(subject)として選定します。
   - 明示的なカテゴリレベルのキーワードを優先します。
   - 効能/上位概念のみが与えられた場合は、それらを含む**最も狭いカテゴリ**を推論します (化粧品: 주름개선 + 안티에이징 → "안티에이징 화장품"; 電子機器: 발열 적은 + 고성능 → "게이밍 노트북")。
3. **調査**: その代表カテゴリを、単一カテゴリ調査と同じ深さで市場概要として調査します。
4. **欠乏の保存**: 各 Effect/Benefit キーワードについて、それが含意する体感的な問題/状況を捉えます。これらは最も強力な CEP の手がかりであるため — 明示的かつ分離した状態で維持し、決して抽象化して消し去らないでください。入力に Effect/Benefit キーワードが一つもない場合(例: "생수, 삼다수, 에비앙" のようにカテゴリとブランド名だけの場合)、欠乏セクションは空のままにし、入力になかった効能をでっち上げないでください。
5. **ソース優先順位**: 公式サイト > 専門レビュー > ユーザーレビュー > 価格比較 > ニュース。
6. **検証**: 6か月以内のソースを優先し、矛盾する内容は相互検証します。

# 出力形式
## ドキュメント構造
- **タイトル**: H1 見出し(#)ひとつ — 代表カテゴリ名、{{response_language}} で記述。導入文なし。
- **セクション**: 各セクションは H2 見出し(##)で、## N. <セクションタイトル> の形式で記述。

## 必須セクション (順序どおり)
## 1. キーワード構成分析
- すべての入力キーワードをレイヤーラベルとともに列挙: [Category] / [Effect·Benefit] / [Super-concept] / [Other]。
- 選択した代表カテゴリと、一行の根拠を明示。

## 2. カテゴリ概要および選択基準
## 3. おすすめ製品 (3-5)
## 4. 機能/スペック比較
## 5. 価格帯
## 6. 消費者の欠乏シグナル
- Effect/Benefit キーワードごとに一つのブロック。
- 各キーワードについて: 体感する不快感/問題、およびそれが表面化する日常の状況。
- 各キーワードのシグナルを分離した状態で維持 — ひとつの一般的な段落にマージしないでください。
- 入力に Effect/Benefit キーワードが一つもない場合は、"効能キーワードなし" の一行のみを書き、それ以外は何も追加しないでください。シグナルをでっち上げないでください。

## フォーマット規則
- ただちに H1 タイトルで開始。導入文なし。
- 定義されたセクションのみを出力。追加のセクション、免責事項、締めの言葉はなし。
- 不確実な情報は [unverified] で表示。
- 最後のセクションの直後にただちに終了。

## 認識不能な入力
入力**全体**が明らかに無意味な場合 — ランダムな文字、認識できる語が一切ないでたらめな文字列(例: "dslkfjakldfj8484;;", "aaaaabbbb!!!") — に限り、次の一行のみを出力し、それ以外は何も出力しないでください:
`UNRECOGNIZED_INPUT`
語句のうち少なくとも一つが実在する語、ブランド、場所、概念であれば、UNRECOGNIZED_INPUT を返さないでください。
```
