# agent_aiOpt_noneURL v.0.2.0 실행 답변 예시 — 버티컬 마우스 케이스

> v.0.2.0 신규: 3계층 분해(응답 프레임 / 브랜드 언급 / 근거 인용) + 4 KPI 한 줄 진단(Brand Visibility / Citation Visibility / Brand Sentiment / AI Traffic) + 순위 위치·역할 컨텍스트

## 1) 분석 개요

AI 검색 질문의 사용자는 "손목 뻐근함이 자세 원인인지 빠르게 테스트하고 싶다"는 의도로 50~70° 버티컬 + 좌/우 + 엄지 측면 버튼 + 후기 RTB까지 한 번에 묻는데, 3개 응답은 :k[Logitech MX Vertical]을 공통 1순위로 두고 좌/우 라인업 대안과 적응 기간 가이드를 묶어 답해 노출 확인 수준에서는 충족되나 정밀 진단 단위로 보면 응답 프레임·근거 인용 층이 응답마다 변동을 보인다.

:::accordion{title="개요 확인"}
**➊ AI 검색 질문의 사용자 의도(CEP) 요약**

- **CEP**: "일반 마우스로 손목 뻐근함 → 자세 원인인지 빠르게 테스트"하려는 즉시 검증형 구매 검토
- **KBF 단서**: :k[버티컬], :k[손목이 꺾이는 느낌], :k[좌/우 선택], :k[엄지 측면 버튼], :k[후기/입소문]
- **RTB 단서**: 실제 통증이 줄었다는 후기·입소문·사용자 체감 보고

**➋ AI 응답이 공통적으로 다룬 의미 영역**

- 버티컬 각도와 손목 중립: :k[중립(악수 자세)], :k[약 57° 각도]
- 좌/우 대응 라인업 분기: :k[좌/우 각각 모델 있음], :k[왼손 전용 모델]
- 엄지 측면 버튼 접근성: :k[추가 엄지 버튼 2개], :k[엄지 버튼 / 제스처 버튼]
- 체감 타임라인: :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]
- 외부 후기·매체 RTB: :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[다나와]

**➌ AI 응답의 무게중심**

- 3개 응답 모두 :k[Logitech MX Vertical]을 1순위 표준으로 두고 :k[약 57° 바디 각도]·:k[손목 중립]·:k[양손 사용 친화]의 3축으로 정당화
- 좌/우 시나리오에서는 :k[Kensington Pro Fit Ergo Vertical], :k[CHERRY MW 4500 LEFT], :k[Perixx PERIMICE-713], :k[Evoluent VerticalMouse 4]가 응답마다 보조 후보로 호출

**➍ 사용자 의도 충족도 한 줄**

- 사용자 의도의 4개 축(각도·좌우·엄지·후기)은 3개 응답 모두에서 충족되나, "당장 덜 불편한지" 빠른 검증 의도에는 적응 기간·자세 동반 가이드·조합 운용 같은 검증 절차 가이드가 응답별로 누적되어야 답이 완성된다는 점이 한계

**➎ 4 KPI 한 줄 진단**

- **Brand Visibility**: :k[Logitech MX Vertical]이 응답 1번·2번·3번 모두에서 1순위 표준으로 등장하고, :k[Kensington]·:k[CHERRY]·:k[Perixx]·:k[Evoluent]·:k[ELECOM]·:k[Kensington Orbit Trackball]이 응답마다 다른 보조 후보로 분산 노출됨
- **Citation Visibility**: 응답들은 :k[rtings.com], :k[laptopmag.com], :k[pcgamer.com], :k[다나와], :k[Reddit] 등 매체·커뮤니티와 :k[ergonomicdistribution.com], :k[kensington.com] 같은 브랜드 공식 자료를 RTB 출처로 인용함
- **Brand Sentiment**: 자사·경쟁 브랜드 모두 중립~긍정 톤으로 :k[손목/팔 피로가 줄었다], :k[carpal tunnel pain 줄었다] 효익 진술 위주, :k[처음 2~3일은 오히려 어색함]·:k[작은 손이면 큰 모델 불편] 같은 부정 톤은 단점 단락에서만 부분 등장
- **AI Traffic**: 응답을 본 사용자는 :k[약 57° 바디 각도] 각도 비교, :k[Lift] 좌/우 페어 운용, 매체 후기 직접 확인을 위해 라인업 페이지·외부 매체로 분기될 가능성이 높음
:::

## 3) 의미 영역 진단·해설

3개 응답이 일관되게 다룬 5개 공통 영역과 일부 응답에만 등장한 4개 차이 영역이 도출되었으며, 각 영역은 응답 프레임 / 브랜드 언급 / 근거 인용 3계층으로 분해되어 정밀 진단 단위로 정리된다.

:::accordion{title="의미 영역 진단 확인"}
**➊ [공통 영역] 버티컬 각도와 손목 중립 자세**

- **AI 응답 근거**: 응답 1번·2번·3번 모두 — :k[중립(악수 자세)], :k[약 57° 각도], :k[약 47° 바디 각도], :k[거의 수직에 가까운 각도]
- **3계층 분해 — 응답 프레임**: AI는 사용자 질문을 "각도·자세 메커니즘으로 손목 회내 부담을 줄이는 문제"로 해석함
- **3계층 분해 — 브랜드 언급**: :k[Logitech MX Vertical]을 1순위 대표 해답으로, :k[Kensington Pro Fit Ergo Vertical](47°)·:k[Evoluent VerticalMouse 4](수직)을 강도별 대안으로 배치
- **3계층 분해 — 근거 인용**: 공식 스펙(:k[약 57° 바디 각도]) + 매체 리뷰(:k[rtings.com]) + 정량 효과(:k[전완 근육 사용량 약 10% 감소])
- **사용자 의도 정합성**: KBF :k[버티컬], :k[손목이 꺾이는 느낌]에 직접 닿는 핵심 축
- **핵심 엔티티 분해**: :k[Logitech MX Vertical](57°), :k[Kensington Pro Fit Ergo Vertical](47°), :k[Evoluent VerticalMouse 4]
- **핵심 토픽 분해**: 각도 정량 비교, 회내 부담 감소 메커니즘, "악수 자세" 직관 비유
- **의사결정 함의**: 50~70° 범위면 57° 표준이 안전, 더 강한 교정은 거의 수직 라인업으로 갈수록 적응 난이도 상승

**➋ [공통 영역] 좌/우 대응 라인업 분기**

- **AI 응답 근거**: 응답 1번·2번·3번 모두 — :k[양손 사용 친화적인 편], :k[좌/우 각각 모델 있음], :k[왼손 전용 모델]
- **3계층 분해 — 응답 프레임**: AI는 사용자 질문을 "겸용 표준 vs 좌/우 전용 페어 의사결정 분기 문제"로 해석
- **3계층 분해 — 브랜드 언급**: 겸용은 :k[Logitech MX Vertical] 1순위, 전용은 :k[Kensington]·:k[CHERRY]·:k[Perixx]·:k[Evoluent]가 응답마다 분산 등장
- **3계층 분해 — 근거 인용**: 공식 스펙 + 매체 리뷰 + 라인업별 좌/우 모델 존재 사실 — :k[BestReviews] (응답 3번)
- **사용자 의도 정합성**: KBF :k[좌우를 번갈아 쓰는 저한테 맞게]에 직접 닿음
- **핵심 엔티티 분해**: :k[Logitech MX Vertical], :k[Kensington Pro Fit Ergo Vertical], :k[CHERRY MW 4500 LEFT], :k[Perixx PERIMICE-713], :k[Evoluent VerticalMouse 4]
- **핵심 토픽 분해**: 겸용 vs 전용 분기, 왼손/오른손 페어 운용, 좌/우 클릭 스위치 메커니즘
- **의사결정 함의**: 진짜 페어 운용이라면 좌/우 전용, 어느 쪽이든 편하게라면 겸용 표준이 안전

**➌ [공통 영역] 엄지 측면 버튼 접근성**

- **AI 응답 근거**: 응답 1번·2번·3번 모두 — :k[엄지 쪽 그립에서 버튼 접근], :k[추가 엄지 버튼 2개]
- **3계층 분해 — 응답 프레임**: 버튼 "유무"가 아니라 "그립에서 자연 접근 위치" 문제로 해석
- **3계층 분해 — 브랜드 언급**: 표준 6버튼 구성을 :k[Logitech MX Vertical] 기준으로 두고 :k[CHERRY MW 4500 LEFT]의 추가 엄지 버튼을 비교 대상으로 인용
- **3계층 분해 — 근거 인용**: 매체 평가(:k[tomsguide.com]) + 공식 스펙(:k[cherry.de]) — 그립별 엄지 자연 접근 위치 평가
- **사용자 의도 정합성**: KBF :k[엄지가 닿기 쉬운 측면 버튼]에 직접 대응
- **핵심 엔티티 분해**: 6버튼 구성, 엄지 페이지 점프 버튼, 제스처 버튼, DPI 버튼
- **핵심 토픽 분해**: 그립별 엄지 자연 접근 위치, 버튼 커스터마이즈
- **의사결정 함의**: "버튼 유무"가 아니라 "엄지가 자연스럽게 닿는가"가 차별화 변수, 손 크기와 결합되어야 의사결정 가능

**➍ [공통 영역] 체감 타임라인**

- **AI 응답 근거**: 응답 1번·2번·3번 모두 — :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]
- **3계층 분해 — 응답 프레임**: AI는 검증을 "단일 시점이 아닌 시간 축 위 단계별 평가" 문제로 해석
- **3계층 분해 — 브랜드 언급**: 적응 기간이 라인업·각도와 무관하게 공통 적용된다는 전제로 모든 후보에 동일 시간 축 부여
- **3계층 분해 — 근거 인용**: 매체 가이드(:k[Improve Workspace]) + 공식 자료 + 사용자 후기(:k[Reddit])
- **사용자 의도 정합성**: 의도 "빠르게 테스트"의 시간 축 기대치를 직접 형성
- **핵심 엔티티 분해**: 1~3일·3~7일·2주+ 단계, :k[처음 2~3일은 오히려 어색함]
- **핵심 토픽 분해**: 단계별 체감 변화, 적응기 어색함 솔직 안내, 1~2주 후 재평가 권장
- **의사결정 함의**: 1~3일 안에 변화 없다고 실패 판정 말고 2주 단위로 재평가하는 멘탈 모델 형성 필요

**➎ [공통 영역] 외부 후기·매체 RTB 인용**

- **AI 응답 근거**: 응답 1번·2번·3번 모두 — :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[Reddit], :k[다나와]

## 4) 후속 활용·핸드오프 메모

추가 검증 권장 영역은 자세·환경 가이드와 조합 운용 두 축이며, 기회 영역은 정량 비교·체감 타임라인·외부 후기 RTB 3축이 사용자 의도와 강하게 닿는다. 후속 온드/언드 미디어 전략 에이전트의 입력 후보는 7개 라벨로 정리된다.

:::accordion{title="후속 활용 확인"}
**➊ 추가 검증 권장 영역**

- 검증 대상 영역 1 — 자세·환경 동반 진단: 응답 3번에서만 다뤄져 RTB 약함 — :k[자세 + 높이 + 팔 지지 같이 안 바꾸면 한계]
- 검증 대상 영역 2 — 조합 운용 시나리오 효과: 응답 2번 단독, 매체 인용 부재 — :k[각도 문제인지 / 좌·우 사용 때문인지 둘 다 확인 가능]
- 검증 대상 영역 3 — 손 크기 매칭의 라인업별 임계치: 작은 손 대안과 단점 언급은 있으나 임계치 가이드 부재 — :k[작은 손이면 큰 모델 불편]

**➋ 기회 영역 메모**

- 기회 영역 1 — 각도 정량 비교 표: 라인업별 각도(:k[약 57°], :k[약 47°], :k[거의 수직에 가까운 각도])를 표 단위로 정리
- 기회 영역 2 — 체감 타임라인 가이드: 단계별(:k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]) 가이드 명시
- 기회 영역 3 — 외부 후기·매체 RTB 큐레이션: 매체별·커뮤니티별·정량 후기 묶어 큐레이션
- 기회 영역 4 — 좌/우 시나리오 분기 가이드: 페어 vs 겸용 갈래로 자르고 각 갈래에 라인업 매칭
- 기회 영역 5 — 솔직한 단점·비적합 시나리오: :k[처음 2~3일은 오히려 어색함] 같은 단점 신호 매체 단위 정리

**➌ 후속 에이전트 핸드오프 라벨**

- 온드 미디어 입력 후보: 각도 정량 비교 표, 체감 타임라인 단계별 가이드, 좌/우 시나리오 분기 가이드, 자세·환경 동반 진단 체크리스트, 손 크기 매칭 가이드
- 언드 미디어 입력 후보: 외부 후기·매체 RTB 큐레이션, 솔직한 단점·비적합 시나리오 큐레이션, 조합 운용 검증 사례 큐레이션
:::
