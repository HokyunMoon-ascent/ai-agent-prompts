## Phase 3-2 — 複数キーワード CEP Insight Research (cep_seedsごとの独立コンテキスト調査) (未確定)

> **分岐条件**: Phase 2-2(複数キーワード Product Anchors)が `cep_seeds` を1つ以上算出した場合、Phase 3 の代わりにこのプロンプトに進みます。
> `cep_seeds` が空の場合(カテゴリ・ブランドのみ入力)は、既存の Phase 3 をそのまま使用します。

### Phase 3(単一)との違い

| 項目      | Phase 3 (単一キーワード)                   | Phase 3-2 (複数キーワード · 本ドキュメント)                                                    |
| --------- | ----------------------------------------- | -------------------------------------------------------------------------------------------- |
| 入力      | product_name + category                   | product_name + category + **`cep_seeds`** (Phase 2-2 算出)                                    |
| 処理原則  | カテゴリ1つを基準に状況/コンテキストをweb検索 | **`cep_seeds` の項目ごとに別セクショングループ**として独立web検索(検索経路の分岐を保持、統合禁止) |
| 検索言語  | カテゴリ = ソリューション探索言語          | カテゴリ = ソリューション言語 / **effect 項目 = 欠乏の言語**(「笑うと目尻のしわが」)でクエリを分離 |
| 出力      | 散文 (H1 + 最大10個の H2 セクション)       | 同一フォーマット。ただし **各セクションタイトルの末尾に出典タグ** `[cep_seed: 주름개선]` を付与し §N↔`cep_seeds` のマッピングを保持 |
| 維持      | web_search · コミュニティ例 · 7W · 親しみやすいトーン | すべて同一                                                                                    |

### 目的

複数キーワードで保持された `cep_seeds`(effect·super_concept)の各項目が持つ**固有の検索経路を独立してweb検索**します。
effect 項目は消費者の**欠乏の言語**へ、カテゴリは**ソリューション探索言語**へと流れるため、1つに統合して調査すると
「高解像度のポートレート」だったプロンプトが再び「ぼやけた一般キーワード」へ戻ってしまう解像度の損失が発生します。
したがって `cep_seeds` 項目ごとに検索経路を分けて調査し、各セクションに出典項目をタグ付けして、次のステップ(Phase 3.5→4)が
`cep_seeds` の出典を `source_ref` で追跡できるようにします。

### コアコンセプト

- **`cep_seeds` 項目ごとの独立探索**: `cep_seeds` の各項目を別々の検索経路として調査する。effect 項目はその効能が含意する
  **欠乏/不便な状況**を直接狙って検索し(例: `주름개선` → 「目尻のしわが気になるのはいつか」)、
  カテゴリは製品探索・比較のコンテキストで検索する。
- **出典タグ付け**: 各 H2 セクションタイトルの末尾に、そのセクションが `cep_seeds` のどの項目から生まれたかを `[cep_seed: <キーワード>]` で表記する。
  カテゴリ全般から生まれたセクションは `[cep_seed: category]` と表記する。このタグが Phase 3.5 の `source_ref §N` を通じて
  Phase 4 まで `cep_seeds` の出典を伝える橋渡しとなる。
- **統合禁止の原則**: 異なる `cep_seeds` 項目の状況を1つのセクションに混ぜない。1セクション = 1つの項目のコンテキスト。

# リサーチフォーカス
発見した各状況について、消費者の議論の中で自然に現れる以下の次元を探索してください:

**状況的コンテキスト (7W's Framework)**
- When: 時間帯、季節、ライフステージ、特定の機会
- Where: 場所、環境、シーン
- While (何をしている時): ニーズを引き起こす活動、タスク、イベント
- With Whom: 一人、家族、同僚、友人
- With What: 併用している他の製品、サービス、ツール
- hoW Feeling: 感情の状態、気分、ストレスレベル、動機

**状況を形づくる消費者の条件**
- 生活環境: ライフステージ、仕事の状況、住まいの形態
- 身体的/実際的な制約: 状況を緊急または具体的にする制限
- 経験レベル: 初心者 vs 経験者 — これが進入点をどう変えるか

**状況から生じるニーズと目標**
- 機能的ニーズ: 状況が生み出す問題
- 感情的ニーズ: この状況の中で、または後にどう感じたいか
- 社会的ニーズ: 状況が他者の認識とどう関わるか

**重要**: web 検索ツールがコンテキストを裏付ける web 出典を提供する場合は、
