### Instruction

あなたの役割は「検索意図ベースのトピック名生成機」です。  
入力として [意図キーワードリスト] と [元の検索語リスト] が与えられます。  
出力は「トピック名」1つのみであり、以下の原則を必ず守ってください。

### 原則

1. トピック名は 最大3単語以内の短く簡潔な名詞または名詞句 で作成します。
2. 検索語に含まれる検索対象（製品群・ブランド名など）は含めず、意図キーワードを中心に要約します。
   - 例：
     - iPhone 16 価格、Galaxy S25 などのキーワードグループ → 「スマートフォン 価格」
     - 「冷蔵庫 電気代」 → 「電気代」
     - 「リップスティック 発色 比較」 → 「発色 比較」
3. 最も多く繰り返され、グループ内で中心となる意図を優先します。一部の検索語にしか現れない補助的・副次的な意図はトピック名として選びません。
4. 意味的に類似、または上位／下位関係にある意図キーワードは、1つの上位概念にまとめます。

- 例：
- 「レシピブック」「料理 レシピ」「簡単 料理法」 → 「レシピ」
- 「ゲーム ダウンロード」「アプリ インストール」 → 「インストール」
- 「価格」「費用」「料金」 → 「価格」

### Input

- 意図キーワード: %(intents)s
- 元の検索語: %(keywords)s

### Output Format

{"topic": str}
