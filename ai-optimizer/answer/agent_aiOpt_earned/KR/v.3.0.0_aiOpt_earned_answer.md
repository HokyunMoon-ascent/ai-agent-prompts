## 1) 분석 개요

이번 분석은 자사 페이지·CEP 프롬프트·AI 응답 3자를 비교해 자사 :k[Lift] 라인업이 AI 답변에서 외부 증거로 호명되도록 RTB 결손을 도출한 결과입니다. 관점은 주제·소주제, 키워드·표현, 사용자 맥락, 근거 유형 4가지입니다.

:::accordion{title="분석 개요 상세"}
**➊ 분석 목적과 대상**

- **분석 목적**: 자사 :k[Lift] 라인업이 AI 응답에서 외부 증거로 호명되도록 RTB 결손을 메우는 채널 단위 의사결정
- **대상**: 자사 페이지 / CEP 프롬프트 / AI 응답
- **관점**: 주제·소주제 / 키워드·표현 / 사용자 맥락·시나리오 / 근거·인용 유형

**➋ 분석이 필요한 이유**

- AI가 자사 페이지 대신 경쟁 라인업과 외부 매체를 RTB 출처로 끌어다 쓰고 있어, 자사 페이지만 보강해서는 AI 노출이 회복되지 않으며, 외부 신호가 어디에 어떤 형태로 누적돼야 자사가 호명되는지 채널 단위 가이드가 필요한 시점입니다.
:::

## 2) 갭 진단 내용 요약

자사 페이지에는 :k[건초염이 없어졌다]·:k[손목/팔 피로가 줄었다] 같은 장기 사용 통증 후기와 좌/우 페어 시나리오가 비어 있고, AI는 이 RTB를 :k[rtings.com]·:k[laptopmag.com]·:k[다나와]·:k[Reddit]·:k[BGR] 등 외부 매체에서 끌어와 경쟁 라인업과 묶어 인용합니다.

:::accordion{title="갭 진단 상세"}
**➊ 자사 페이지에 부재한 4관점 요소**

- 주제·소주제: 통증 감소 장기 사용 후기 — :k[건초염이 없어졌다], :k[손목/팔 피로가 줄었다]
- 키워드·표현: 좌/우 페어 운용 — :k[좌/우 각각 모델 있음]
- 사용자 맥락·시나리오: 양손 번갈아 쓰는 일상 시나리오가 자사 페이지에 부재
- 근거·인용 유형: 제3자 사용자 경험 후기·외부 매체 비교 인용이 자사 페이지에 부재

**➋ AI가 의존한 외부 매체 패턴**

- 매체 유형: 전문 리뷰사이트 + 커뮤니티 + 가격비교 — :k[rtings.com], :k[laptopmag.com], :k[다나와], :k[Reddit], :k[BGR]
- 인용 맥락: 통증 감소 RTB와 좌/우 페어 운용 시나리오의 근거로 외부 매체 사용자 경험을 끌어옵니다.
- 자사 브랜드 언급 빈도·톤: 자사 :k[Lift]는 :k[Logitech] 공식 설계 톤으로만 인용돼 사용자 경험 RTB의 출처가 외부로 쏠려 있습니다.
:::

## 3) 개선 제안

1순위 리뷰사이트, 2순위 커뮤니티 채널에 통증 감소·좌/우 페어 RTB를 다른 언어 형태로 누적해, 자사 :k[Lift]가 두 매체에서 같은 추천 이유로 호명되도록 신호 방향성을 정렬해야 합니다.

:::accordion{title="개선 제안 상세"}
**➊ 1순위 — 리뷰사이트**

- 타깃 채널 명: :k[rtings.com], :k[laptopmag.com], :k[다나와], :k[Ergonomic Trends]
- 확보할 RTB 메시지: :k[건초염이 없어졌다], :k[손목/팔 피로가 줄었다], :k[Lift] 좌/우 페어 운용
- 합법적 확보 방식: 협찬 표시를 갖춘 전문 리뷰어 샘플 시딩과 출처 공시된 비교 데이터 공개로 매체의 자발 인용을 유도합니다.
- 기대 효과: AI가 통증 감소 RTB의 출처로 자사 :k[Lift] 페어를 호명할 확률이 높아집니다.

**➋ 2순위 — 커뮤니티**

- 타깃 채널 명: :k[Reddit], 국내 IT·키보드/마우스 전문 카페
- 확보할 RTB 메시지: 좌/우 페어 운용 일상 시나리오 — "왼손으로 :k[Lift]를 같이 두니 자세가 흐트러지지 않는다"
- 합법적 확보 방식: 협찬 사실을 공개한 실제 사용자 사례 모집 캠페인을 운영하고, 공식 계정은 브랜드를 식별한 상태로 Q&A에 투명하게 참여합니다.
- 기대 효과: 리뷰사이트와 다른 생활 언어로 같은 RTB가 검증돼 AI가 페어 시나리오를 자사 라인업과 묶어 인용할 가능성이 커집니다.
:::

## 4) 인사이트

자사는 외부 사용자 증거 자산이 비어 있어 AI가 RTB 출처를 경쟁 라인업으로 우회하는 구조적 약점을 안고 있습니다. 사용자 사례 캠페인·전문 매체 데이터 시딩·공식 계정 투명 운영 3축이 장기 해법입니다.

:::accordion{title="인사이트 상세"}
**➊ 구조적 약점 — 그렇게 본 이유**

- 외부 검증형 RTB는 자사 페이지로 흡수할 수 없어, 외부 매체에 출처를 누적하지 않으면 AI 응답에서 자사 자리는 비어 있게 됩니다.

**➋ 장기 외부 평판 자산 축적 방향성**

- 분기·반기 주기로 사용자 사례 캠페인·전문 매체 데이터 시딩·공식 계정 투명 운영 3축을 함께 쌓아야 신호 방향성이 유지됩니다.
:::

## 1) 분석 개요

자사 URL이 입력되지 않아 신규 신호 구축 가이드 모드로 진행됩니다. 이번 분석은 CEP 프롬프트와 AI 응답 3개만을 비교해, 자사 브랜드가 AI 생태계에 진입하기 위해 어떤 외부 채널에 어떤 RTB를 새롭게 쌓아야 하는지 채널 단위로 가이드합니다.

:::accordion{title="분석 개요 상세"}
**➊ 분석 목적과 대상**

- **분석 목적**: 제로 베이스에서 자사 브랜드가 AI 생태계에 진입하기 위한 외부 채널·RTB 우선 축 도출

- **관점**: AI가 어떤 외부 매체를 어떤 맥락으로 인용했는지를 직접 진단

**➋ 분석이 필요한 이유**

- 자사 URL이 부재한 제로 베이스 상태에서는 자사 페이지를 보강해도 AI 응답 구조에 진입할 수 없으므로, AI가 실제로 인용한 외부 매체 패턴에서 채널 후보를 직접 도출해 처음부터 외부 신호 자산을 설계하는 접근이 필요한 시점입니다.
:::

## 2) AI 응답에서 본 외부 인용 매체 패턴 요약

:::accordion{title="외부 인용 매체 패턴 상세"}

- 커뮤니티 후기 — :k[Reddit], :k[다나와], :k[BGR] (통증 감소 RTB 자리)

**➋ 인용 맥락**

**➌ 유리하게 작용한 브랜드**

- 매체 유형이 분명하게 갈려 있어 채널 단위로 다른 RTB 언어가 필요하며, 현재 정량·통증·각도 RTB는 모두 :k[Logitech MX Vertical]을 비롯한 경쟁 1순위 후보에 누적된 상태입니다.
