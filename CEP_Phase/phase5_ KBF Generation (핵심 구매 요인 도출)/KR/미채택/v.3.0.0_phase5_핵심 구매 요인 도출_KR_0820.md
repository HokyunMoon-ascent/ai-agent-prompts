# Task

1. KBF는 각 카드 안에서 확정합니다. 카드마다 따로 처리하며 전체 공통 목록을 만들지 않습니다.
   - 근거는 그 카드의 `situation`·`context`·`kbf_hints`입니다.
   - {{basic_research}}는 표현을 다듬거나 근거를 확인할 때만 참조하며, 카드가 인용하지 않은 내용을 새 KBF로 가져오지 않습니다.
2. `kbf_hints`는 **후보**입니다.
   - 카드의 `situation`·`context`로 뒷받침되지 않는 힌트는 탈락시킵니다.
   - `situation`·`context`에 드러나지만 힌트에 빠진 조건은 추가합니다.
3. 다음은 KBF로 올리지 않습니다.
   - 카드의 `rtb`에 이미 담긴 신뢰 근거
   - 소비자가 무차별을 명시한 항목("어느 쪽이든 상관없다")
   - 소비자가 필요 없다고 밝힌 항목 — 라벨을 붙여 남기지 말고 **목록에서 빼세요**
   - 특정 모델·브랜드 언급 — 비교 대상이지 기준이 아닙니다
4. 상황 서술을 그대로 옮기지 않고 {{product_name}} 비교가 가능한 **제품 속성이나 제약 조건**으로 바꿔 씁니다. 각 KBF는 완전한 문장이 아니라 간결한 명사구입니다.
5. **속성 그라운딩** — 지어내지 말아야 할 것은 수치만이 아닙니다.
   - 수치·범위("100–150g", "pH 5.5", "20°~40°")는 {{basic_research}}나 카드 근거에 명시된 경우에만 씁니다. 없으면 정성적으로 서술합니다("경량 설계", "완만한 경사 각도").
   - **성분·효능**("식이섬유 포함으로 포만감"), **형태·구조**("납작한 바 구조", "슬림 사이즈"), **보관·처리**("실온 보관"), **구성·번들**("다양한 용량 구성", "액세서리 포함") 같은 정성 속성도 근거에 없으면 출력하지 않습니다.
   - 소비자 동기에서 "있으면 좋을 속성"을 상상해 채우지 말고, 근거가 뒷받침하는 속성만 냅니다.
6. **카드당 1~3개.** 근거가 뒷받침하는 속성이 하나뿐이면 하나만 냅니다. 개수를 채우려 카테고리 일반론이나 근거 없는 속성을 추가하지 마세요 — 줄이는 편이 창작보다 낫습니다.
7. KBF가 경쟁 브랜드에 유리하게 작용해도 괜찮습니다. 자사에 유리한 항목으로 고르지 마세요.

# Output

{{response_language}}로 씁니다. 카드의 순서와 기존 필드는 그대로 유지하고 `kbfs`만 확정합니다.

JSON 배열 하나만 반환하세요. 각 요소는 `id`와 `kbfs` 두 키를 가진 객체입니다.

```
[
  { "id": 0, "kbfs": ["주변 소음 차단 정도", "외부 소리 확인 편의", "착용 지속 시간"] },
  { "id": 1, "kbfs": ["문턱·매트 단차 주행", "예약 시간 지정"] }
]
```

## Output Rules (STRICT, JSON-ONLY)

- 유효한 단일 JSON 배열만 반환합니다. 코드 펜스(```)를 쓰지 마세요.
- JSON 밖에 산문·설명·목록·HTML 주석을 쓰지 마세요. 탈락시킨 힌트를 주석으로 남기지 않습니다.
- 후행 쉼표를 쓰지 마세요. 모든 키와 문자열 값에 큰따옴표를 씁니다.
- **배열 길이는 입력 카드 수와 같아야 합니다.** `id`는 0부터 시작하는 정수로, 입력된 카드 순서와 1:1로 대응합니다.
- `kbfs`는 1~3개의 문자열 배열입니다.
- KBF 문자열에 `(필수)`·`(보조)` 같은 무게 라벨을 붙이지 마세요. 이 문자열은 하류 예시질문 생성과 카드 화면에 그대로 노출됩니다.
- 인용부호 `""`·`''`를 KBF 문자열에 넣지 마세요.

**반례 (이런 것을 생성하지 마십시오)**

- "저용량·경량 설계 무게(예: 100–150g)" — 지어낸 수치 범위
- "식이섬유 포함으로 포만감 보조" — 본문에 저당만 있는데 성분·효능을 창작
- "납작한 바 구조", "실온 보관 및 위생 처리" — 본문은 휴대성만 말하는데 형태·보관을 창작
- "주변 소음 차단 정도(필수)" — 무게 라벨이 문자열에 들어감
- 대신: "저용량·경량 설계", "주변 소음 차단 정도" / 근거가 없으면 그 속성을 **빼세요**
