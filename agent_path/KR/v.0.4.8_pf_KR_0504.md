# 2) Top 3 경로 추천

[목표] 제공된 키워드 경로 데이터를 분석하여 사용자의 검색 경로를 파악하고, 이를 기반으로 상위 3가지 핵심 경로를 탐색하는 것이 목표입니다.

## 분석 단계 및 지침

1. 입력 데이터 해석:
   - 이 프로세스는 CSV 파일 내의 특정 컬럼에 전적으로 의존합니다. 텍스트의 의미론적 관계를 추론하지 말고, 오직 명시적인 데이터 구조만 사용하십시오.
   - **주요 컬럼**:
     - `id`: 키워드 노드의 고유 식별자 (정수 또는 문자열).
     - `name`: 실제 키워드 텍스트 (표시 라벨).
     - `outgoing`: 이 노드가 가리키는 직접적인 이웃 노드들의 id를 포함하는 JSON 배열 문자열 (방향성 엣지). 예시: `["52", "62"]`는 현재 노드에서 노드 52와 노드 62로 향하는 방향성 경로가 있음을 의미함.
     - `volume`: 경로 우선순위 지정에 사용되는 검색량 지표 (선택 사항이나 점수 산정에 권장됨).

2. 그래프 구축 로직:
   - 경로를 생성하기 전, 방향성 그래프(Directed Graph) 구조를 구축합니다.
   - CSV의 모든 행(Row)을 순회하며 각 행에 대해 `id`로 인덱싱 가능한 노드(Node)를 생성합니다.
   - **엣지(Edge) 정의**:
     - `outgoing` 컬럼 내용을 타겟 ID 리스트로 파싱합니다.
     - 노드 B의 `id`가 노드 A의 `outgoing` 리스트에 존재하는 경우에만 **방향성 엣지 (A → B)**를 수립합니다.
     - **참고**: 노드 B가 데이터셋에 실제로 존재하는지 확인하십시오. `outgoing`에 있는 타겟 ID가 `id` 컬럼에 없다면, 해당 엣지는 무시하십시오.

3. 경로 탐색 알고리즘 (깊이 우선 탐색, DFS):
   - 의미 있는 탐색 경로를 발견하기 위해 다음 규칙을 준수하여 순회(DFS 권장)를 수행합니다.
   - **순회 규칙**:
     - **시작점**: 그래프의 모든 노드는 잠재적인 시작점이 될 수 있습니다.
     - **확장**: 현재 노드 A에서 노드 B로의 이동은, B가 A의 `outgoing` 리스트에 있는 경우에만 가능합니다.
     - **순환(Cycle) 방지**: 현재 경로 시퀀스에 이미 존재하는 노드는 다시 방문하지 않습니다 (예: A → B → A 는 무효).
     - **경로 길이**:
       - **최소 길이**: 5 노드 (폭넓은 탐색을 위한 기본 기준).
       - **최대 길이**: (선택 사항, 예: 10) 과도한 깊이를 방지하기 위함.
   - **단계별 로직 (의사 코드)**:
     ```
     변수 초기화: PathList = []
     그래프의 각 노드 "StartNode"에 대하여:
         Stack = [(StartNode, [StartNode])]
         While Stack이 비어있지 않은 동안:
             (Current, Path) = Stack.pop()
             If 길이(Path) >= 5: PathList에 Path 추가
             For 각 NeighborID in Current.outgoing:
                 If NeighborID가 Path에 없음:
                     NewPath = Path + [NeighborID]
                     Stack.push((Node(NeighborID), NewPath))
     ```

4. 점수 산정 및 선별:
   - 유효한 후보 경로를 모두 생성한 후, 다음 위계에 따라 "상위" 경로를 선별합니다.
   - **경로 길이 (1순위)**: 더 긴 경로를 선호합니다 (더 깊은 사용자 여정을 의미).
   - **볼륨 지표 (2순위)**: 길이가 같다면, 높은 검색량(`volume`)을 가진 키워드가 포함된 경로를 우선합니다 (더 높은 사용자 트래픽/관심도를 의미). 지표로는 경로 내 Max(volume) 또는 Sum(volume)을 사용합니다.

5. 검증 체크리스트:
   - LLM이 경로를 출력할 때, 반드시 다음 사항을 검증해야 합니다.
   - 모든 노드 쌍 `(Step[i], Step[i+1])`에 대하여, `Step[i+1].id`가 `Step[i].outgoing`에 포함되어 있는가?
   - 표시된 이름(`name`)이 해당 ID와 정확히 매핑되어 있는가?
   - 경로에 중복된 노드(루프)가 없는가?

# 3) Top 3 구조 분석 (Hub & Branch)

[목표]
제공된 키워드 데이터를 분석하여 브랜드와 논브랜드 키워드를 파악하고, 이를 기반으로 ‘정보 탐색 → 구매 고려 단계로 전환되는 지점’과 ‘브랜드 중심 탐색이 발생하는 경로를 식별’한다.

## 분석 단계 및 지침

1. 키워드 분해 및 의도 식별:
   a. name 컬럼을 확인하세요.
   b. 각 키워드에서 ‘타겟 키워드'를 식별하고 이를 제외한 나머지 부분에서 **'의도 키워드(Intent Keyword)'**를 추출하세요.

2. 개념 설명
   a. 타겟 키워드: 특정 제품의 이름(브랜드 키워드), 브랜드의 이름(브랜드 키워드), 서비스나 제품의 카테고리 명(논브랜드 키워드), 인물의 이름, 개념이며, 주로 명사나 대명사, 혹은 명사형이 위치합니다.
   b. 의도 키워드: 검색어 안에서 타겟 키워드와 쌍을 이루어 검색하는 사람의 맥락과 상황, 의도를 명확하게 해주는 단어나 구를 말합니다. 형용사로서 검색자의 의도를 보여주는 의도 키워드라고 할 수 있습니다.

3. 단계 식별:
   a. ‘정보 탐색 → 구매 고려 단계로 전환’되는 지점은 다음 두 가지 방법으로 식별.
   - 타겟 키워드가 논브랜드 키워드에서 브랜드나 제품으로 변화하는 시점
   - 의도 키워드가 상태나 고민을 확인하는 단계에서 검증이나 구매 단계로 넘어가는 시점

   b. 브랜드 중심 탐색이 일어나는 과정은 다음 방법으로 식별.
   - 타겟 키워드가 논브랜드 키워드에서 브랜드나 제품으로 변화하는 시점

4. 중요도 평가 및 Top 3 선정:
   위 분석을 바탕으로 가장 중요한 '전환점' 역할을 하는 키워드 3개를 선정하십시오.
   선정 기준은 다음과 같습니다.
   a. 연결성: `edges`가 많아 여러 경로로 분기되는 허브(Hub) 역할을 하는 키워드일 것.
   b. 전환 빈도: 해당 키워드 이후의 경로(`edges`)에서 '브랜드 구체화'나 '구매 단계 전환'이 자주 발생하는 키워드일 것.
   c. 동일한 경로 수가 나타난다면, 검색량(volume) 수치가 높은 것에 우선 순위를 둔다.
