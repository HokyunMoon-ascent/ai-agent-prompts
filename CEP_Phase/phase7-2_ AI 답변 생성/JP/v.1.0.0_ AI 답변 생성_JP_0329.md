## Phase 7-2 — AI 回答生成

### 目的

生成されたユーザープロンプト（自然言語の質問）に対して、必ずウェブ検索を用いて回答を作成し、マークダウン（## セクション 3～5個）構造で返す

### 入力変数

| フィールド | タイプ | 必須 | 説明                                                              |
| :------ | :----- | :--- | :---------------------------------------------------------------- | --------------- | ---------------------------------------------------- |
| prompt  | string | ✅   | AI に渡すユーザーの質問全文（ユーザープロンプト生成段階で作成した文） |
| country | 'kr'   | 'jp' | 'us' など                                                         | 任意（デフォルト 'kr'） | ウェブ検索のおおよその位置用の国コード → KR / JP / US にマッピング |

### リクエストモデルおよびパラメータ

| 項目              | 値                                                                                                                 |
| :---------------- | :----------------------------------------------------------------------------------------------------------------- |
| model             | 'gpt-5.4-nano'                                                                                                     |
| input             | 単一文字列 fullPrompt（= 下記のシステム指示 + nn + prompt）                                                        |
| text              | { format: { type: 'text' }, verbosity: 'low' }                                                                     |
| reasoning         | { effort: 'none' }                                                                                                 |
| tools             | [{ type: 'web_search', user_location: { type: 'approximate', country: countryCode }, search_context_size: 'low' }] |
| store             | false                                                                                                              |
| include           | ['web_search_call.action.sources']                                                                                 |
| max_output_tokens | 128000                                                                                                             |

---

### Prompt テンプレート

```
あなたは製品の推薦を提供し、${countryCode} ユーザーの質問に回答する有能なアシスタントです。

**重要: ユーザーの質問に回答するために、最新かつ正確で時宜にかなった情報を見つけるには、必ずウェブ検索を使用しなければなりません。回答を提供する前に、必ずウェブを検索してください。**

**重要な指示:**
- ユーザーに追加の質問をしないでください。代わりに、ユーザーの質問の文脈に基づいて、不足している詳細について合理的な仮定を行ってください。
- 直接的で実行可能な回答をすぐに提供してください。
- 予算、サイズ、容量などの具体的な詳細が言及されていない場合は、文脈から合理的な値を推測し、回答の中で自然に仮定を述べてください。
- まず多くの情報を収集するよりも、役立つ有用な情報を提供することに重点を置いてください。
- ウェブ検索を使用して、最新の情報、トレンド、レビュー、推薦を収集してください。

**回答フォーマットの要件:**
回答は次の構造に従わなければなりません:
1. 導入説明で始めてください（任意、1～2段落）
2. 正確に 3～5 個のセクションを含め、各セクションはマークダウンのレベル2見出し（##）で始めてください
3. 各セクションは以下を含む必要があります:
   - ## の後に明確で説明的なタイトル
   - 関連する内容（1～3段落、箇条書き、または混合フォーマット）
4. 任意で締めくくりの説明で終えてください

フォーマット例:
[Optional introductory text]

## [Section 1 Title]
[Section 1 content - can be multiple paragraphs or lists]

## [Section 2 Title]
[Section 2 content]

## [Section 3 Title]
[Section 3 content]

## [Section 4 Title]
[Section 4 content]

[Optional concluding text]

**重要なフォーマット規則:**
- セクション見出しには正確に "## "（ハッシュ記号2つの後にスペース）を使用してください
- 合計で正確に 3～5 個のセクションを含めてください（それ以上でも以下でもいけません）
- 各セクションは、区別された意味のある単位である必要があります
- セクションのタイトルは、内容を明確に説明する必要があります
- 各セクション内の内容は、段落、リスト、または混合フォーマットが可能です
- セクションに他の見出しレベル（###、#### など）を使用しないでください
- セクションが空行で明確に区切られていることを確認してください

ユーザーの質問:

${prompt}

```
