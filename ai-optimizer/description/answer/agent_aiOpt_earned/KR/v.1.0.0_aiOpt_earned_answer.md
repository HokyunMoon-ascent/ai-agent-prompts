## 2) 매체별 RTB 갭 매핑

갭 분석 결과의 언드 활성화 항목 2건 모두 공통 갭이며, 각각 외부 후기·리뷰 매체 RTB 허브와 좌/우 번갈아 사용 시나리오 매칭으로 분리되어 1순위 리뷰사이트, 보조 커뮤니티 매체 카테고리로 매핑된다.

:::accordion{title="RTB 갭 매핑 확인"}
**➊ [공통 갭] 외부 후기·리뷰 매체 RTB 인용 영역**

- **출처 갭**: 갭 분석 결과의 의미적 갭 매핑 공통 갭 — 외부 후기·리뷰 매체 RTB 인용 영역 (보강 권장 ➌ [분리형] 외부 후기·리뷰 매체 RTB 허브, 채널 힌트 언드 + 온드)
- **현재 인용 매체**: AI 응답 1번·2번·3번 모두 외부 매체에서 끌어옴 — :k[다나와]가 :k[건초염이 없어졌다]를, :k[BGR]가 :k[carpal tunnel pain 줄었다]를, :k[laptopmag.com]이 :k[손목/팔 피로가 줄었다]를 인용 / 자사 매체(자사 페이지·자사 운영 채널)에서 형성된 RTB 인용은 응답에 없음
- **필요 RTB**: :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[손목/팔 피로가 줄었다], 전문 매체 리뷰 인용, 사용자 후기 인용, 임상/사용 사례 인용
- **1순위 매체 카테고리**: 리뷰사이트
- **보조 매체 카테고리**: 커뮤니티
- **AI 노출 저해 가설**: 자사 페이지에 :k[사용자 테스트 완료. 인체공학자 인증.] 같은 자체 검증 문구만 있고, 외부 매체·커뮤니티에서 자사 라인업과 묶인 통증 감소 RTB가 누적되지 않아 AI가 RTB 인용을 외부 라인업 위주로 가져감

**➋ [공통 갭] 좌/우 번갈아 사용 시나리오 매칭 — 라인업 가시성 문제**

- **출처 갭**: 갭 분석 결과의 의미적 갭 매핑 공통 갭 — 좌/우 번갈아 사용 시나리오 매칭 (보강 권장 ➍ [통합형] 좌/우 번갈아 사용 시나리오 매칭, 채널 힌트 온드 + 언드)
- **현재 인용 매체**: AI 응답 2번이 :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보]를 :k[Perixx PERIMICE-713] 시나리오로, AI 응답 3번이 :k[좌/우 각각 모델 있음]을 :k[Evoluent VerticalMouse 4]와 :k[BestReviews] 인용으로 풀어냄 / 자사 :k[Lift] 페어 시나리오는 외부 매체에 형성된 흔적이 없음
- **필요 RTB**: :k[Lift] 왼손/오른손 페어, :k[좌/우 각각 모델 있음] 라인업 신호, "좌/우 번갈아 사용자 페어 운용" 시나리오 토픽
- **1순위 매체 카테고리**: 리뷰사이트
- **보조 매체 카테고리**: 커뮤니티
- **AI 노출 저해 가설**: 좌/우 번갈아 사용 시나리오가 :k[Perixx PERIMICE-713]·:k[Evoluent VerticalMouse 4] 라인업과 묶여 외부 매체·커뮤니티에 이미 누적되어 있고, 같은 시나리오에서 :k[Lift] 페어 운용을 다룬 외부 인용 후보가 부재해 AI가 호출하지 못함
:::

## 3) 채널별 활성화 전략

리뷰사이트 카테고리에 외부 후기 RTB와 좌/우 페어 시나리오 두 축의 신호를 1순위로 누적하고, 커뮤니티 카테고리에서는 동일 RTB가 사용자 자발적 후기·공식 계정 Q&A 형태로 보조 형성되도록 가이드한다.

:::accordion{title="채널 전략 확인"}
**➊ 리뷰사이트 — 1순위 RTB**

- **목표 매체 후보**: :k[rtings.com], :k[laptopmag.com], :k[다나와], :k[BestReviews], :k[Ergonomic Trends]
- **필요 RTB**: :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[손목/팔 피로가 줄었다], :k[좌/우 각각 모델 있음], :k[Lift] 왼손/오른손 페어
- **콘텐츠 형식**: 외부 매체 리뷰·비교 페이지에 자사 라인업이 통증 감소 RTB·좌/우 페어 시나리오와 묶여 등장하도록 제3자 검증 가능한 데이터 제공·체험단 모집·전문 매체 리뷰 의뢰 등의 정직한 활성화 형식만 사용
- **인증·투명성 요건**: 체험단·협찬 리뷰는 협찬 표시 의무 / 비교 데이터는 출처 공시 / 매수 평점·자작 리뷰 금지 / 공식 응답 시 브랜드 식별 명시
- **분리 판단 근거**: 외부 매체에 누적된 제3자 검증 RTB는 자사 페이지로 흡수 불가능하며, AI 응답이 RTB 출처로 외부 매체를 우선 인용하는 패턴이 응답 1번·2번·3번에서 일관되게 관찰됨

**➋ 커뮤니티 — 보조 RTB**

- **목표 매체 후보**: :k[Reddit], 국내 IT·가성비·키보드/마우스 전문 커뮤니티 (네이버 카페·디시·전문 포럼)
- **필요 RTB**: :k[손목 통증 완화됨 경험 다수], :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보], :k[Lift] 페어 운용 사례
- **콘텐츠 형식**: 사용자 자발적 후기 토픽이 형성되도록 실제 사용자 사례 모집 캠페인을 운영하거나 공식 계정이 브랜드 식별을 명시한 채 Q&A·자료 공유에 투명하게 참여하는 방향만 사용
- **인증·투명성 요건**: 공식 계정은 브랜드 식별 명시 / 모집 캠페인 참여자에게 협찬·대가 사실 공시 의무 / 사용자 사칭·대리 작성·다계정 도배 금지 / 경쟁 제품 비방 금지
- **분리 판단 근거**: 좌/우 번갈아 사용 시나리오의 경험담은 자사 페이지에 직접 게시할 수 없는 외부 사용자 사회적 증거 영역이며, AI 응답 3번이 같은 시나리오를 :k[Reddit]에서 끌어온 사실상 이 카테고리의 출처 공백을 그대로 드러냄
:::

## 4) 윤리 가드레일 자체 점검

본 출력의 매체별 RTB 매핑·채널 전략은 모두 정직한 활성화 방향만 다루며, 위장·미공시·도배·비방·사칭 5개 배제 원칙은 모두 미포함이다.

:::accordion{title="윤리 가드 확인"}
**➊ 배제 원칙 적용 결과**

- 일반 사용자/소비자/환자 위장 게시물 제안 — 미포함 ✓
- 금전·제품 대가 미공시 후기 제안 — 미포함 ✓
- 동일 인물·계정 반복 게시·도배 제안 — 미포함 ✓
- 경쟁사 비방·허위 비교 제안 — 미포함 ✓
- 언론사·기자·인플루언서·전문가 사칭 제안 — 미포함 ✓

**➋ 신뢰 가능한 활성화 원칙 적용**

- 모든 채널 전략(리뷰사이트·커뮤니티)에 협찬 표시 의무·공식 계정 브랜드 식별·이해관계 공시·매수 평점 금지·사용자 사칭 금지 같은 인증·투명성 요건이 명시됨
- 콘텐츠 형식은 실제 사용자 사례 모집 캠페인·체험단(협찬 표시)·전문 매체 리뷰 의뢰·공식 계정 Q&A 참여 등 신원과 이해관계가 투명한 활성화 방식만 채택

**➌ 잔여 리스크 노트**

- 특이 사항 없음
