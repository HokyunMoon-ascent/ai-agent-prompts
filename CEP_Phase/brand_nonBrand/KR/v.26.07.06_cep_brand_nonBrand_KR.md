brand_nonBrand (CEP)

**v. 26.07.06**

### Instruction

주어진 검색어 {{keyword}} 를 보고 이 검색어가 '브랜드 검색어'인지 판단합니다.  
**'브랜드 검색어'**란 **특정 브랜드** 혹은 **특정 제품/모델**과 직접 연관된 검색어를 말합니다.  
**'브랜드'라는 단어가 포함되어 있더라도, 특정 브랜드를 지칭하는 것이 아니라 일반 명사로서 사용된 경우 (예: 순위, 추천, 종류 등과 결합)에는 '일반 검색어'로 판단합니다.**

주어진 검색어가 '브랜드 검색어'라면 "brand"에 true, '일반 검색어'라면 false를 반환하세요.  
검색어가 '브랜드 검색어'라면 판단 근거가 되는 **검색어의 일부분**을 **추출**하여 "brand_part"에 함께 반환하세요. (**검색어에 나타난 그대로 반환하세요.**)  
검색어가 '일반 검색어'라면 "brand_part"에 빈 문자열을 반환하세요.

추가 설명 없이 결과만 반환하세요.

**브랜드 검색어:**

- 회사 이름 (예: LG, 삼성)
- 서비스 이름 (예: 유튜브, 넷플릭스)
- 브랜드 이름 (예: 갤럭시, 그램, 아이폰)
- 특정 브랜드의 주요 **제품(모델) 이름** (예: s25, 프로 16)
- 브랜드 이름과 제품군이 결합된 검색어 (예: 시디즈 게이밍 의자)

**일반 검색어:**

- 일반 제품 카테고리 (예: 스마트폰, 노트북, 세탁기, 냉장고, 세정제, 화장품)
- 일반 명사 (예: 레티놀, 사과)
- **'브랜드'라는 단어가 포함된 일반적인 키워드 (예: 골프 브랜드 순위, 2025 최고의 브랜드)**

**판단 기준:**

- 오직 **검색어 자체**에 특정 브랜드명·제품명·모델명이 포함되어 있는지를 기준으로 판단합니다. (별도의 검색 결과는 제공되지 않으므로 검색어 텍스트만으로 판단합니다.)
- '애플'(과일이자 브랜드), '토스'(동사이자 송금 앱)처럼 일반 명사와 브랜드명이 겹쳐 의미가 모호한 경우에는, 일반적으로 통용되는 의미와 검색어의 맥락을 바탕으로 판단합니다.

### Output Format

{
"keyword": str -> 입력의 {{keyword}} 값을 그대로 복사,
"brand": bool,
"brand_part": str
}

### Input

{{keyword}}
