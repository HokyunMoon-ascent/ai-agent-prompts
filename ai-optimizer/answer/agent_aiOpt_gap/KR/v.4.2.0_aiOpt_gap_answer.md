# agent_aiOpt_gap v.0.2.6 실행 답변 예시 — Logitech Ergo Series 케이스

> v.0.2.6 변경 포인트
>
> 1. **표현 정돈** (description 0518 1·3): "신뢰 통제권"·"비대칭 구도"·"1순위를 정당화"·"통증 RTB" 같은 분석 어휘를 본문에서 추방하고, "외부 페이지를 인용의 증거로 사용", "특정 제품에 편중", "주요 근거로 안내", "커뮤니티 후기를 인용하고 있다" 같은 자연어로 풀어쓰기. "허브"는 "안내 페이지"로 통일.
> 2. **§2 표 헤더 변경** (description 0518 5): `토픽 그룹 | 콘텐츠 액션 | 우선순위` → `토픽 그룹 | 개선 우선 순위 | 해결 전략`. 컬럼 순서도 우선순위가 두 번째, 해결 전략이 세 번째로 재배치.
> 3. **라벨 어휘 통일** (description 0518 5): 🔴 결정적 / 🟡 기회/보강 (2단계) → 🔴 위험 (즉시 개선) / 🟡 양호 (2~3순위 개선) / 🔵 안전 (보조 점검) (3단계).
> 4. **§2 ➋ 갭 상세 7항목 블록 제거** (description 0518 4): "약하게 표현" 지침에 맞춰 별도 상세 블록을 두지 않고 위험 토픽 그룹 메인 불릿 + 근거 + 필요 단서 3종 하위 불릿로 통합 해설에 흡수. 양호·안전 토픽 그룹은 1줄로 가볍게 처리.
> 5. **토픽 그룹 카디널리티 3개 고정 + 어휘 통일**: 5개 토픽 그룹(A/B/C/D/E) → 3개로 축소. 진영 격차 가장 큰 자리부터 A. 좌/우 페어(🔴 위험) → B. 신뢰 보강(🔴 위험, 구 E.) → C. 엄지 측면 버튼(🟡 양호, 구 B.) 순으로 재라벨링. 구 C. 버티컬 각도(박빙 1/3)·구 D. 자세·환경(양 진영 공백)은 드롭. 단독 "그룹" 표현을 "토픽 그룹"으로 통일.

## 1) 브랜드 노출 분석

자사 **MX Vertical** 한 모델만 손목 중립 영역에서 호출되었습니다. **Lift**·**MX ERGO** 라인업은 좌/우 페어·엄지 측면 버튼 영역에서 통째로 빠져 있고, AI가 자사 브랜드를 다룰 때에도 근거 인용은 자사 페이지가 아닌 외부 매체에서 다루고 있어, 외부에 끌려가 있는 구도입니다.

**➊ 토픽 그룹 정의**

| 토픽 그룹                              | 묶인 세부 토픽                                                                                                   | 자사 대응 액션                                        |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| **A. 좌/우 페어 시나리오 운용**        | **좌/우 선택**, **자기 손에 맞는 전용 모델을 고르는 쪽**, 좌/우 페어                                             | **Lift** 왼손·오른손 페어 운용 시나리오 페이지        |
| **B. 신뢰 보강**                       | 외부 매체·실사용 후기, **사용자 테스트 완료. 인체공학자 인증.** 자체 주장, **처음 2~3일은 오히려 어색함** 단점 안내 | 외부 매체·실사용 후기·**1~2주 적응 기간** 안내 페이지 |
| **C. 엄지 측면 버튼·생산성 부가 기능** | **엄지 측면 버튼**, **추가 엄지 버튼 2개**                                                                       | **MX ERGO** 엄지 버튼 활용 시나리오 가이드            |

- **A. 좌/우 페어 시나리오는 경쟁사 3종이 통째로 점유한 가장 큰 진영 격차입니다.**
  - **Kensington Pro Fit Ergo Vertical**·**CHERRY MW 4500**·**Perixx PERIMICE-713**이 **좌/우 전용 모델**로 호출됐고, **왼손, 오른손 어디에나 딱 맞는 Lift**가 페어로 묶이지 못했습니다.
  - C. 엄지 측면 버튼 토픽 그룹도 경쟁사 1종(**CHERRY MW 4500**)만 부분 점유한 공백으로 **MX ERGO** 엄지 시나리오가 응답에서 빠져 있습니다.
- **B. 신뢰 보강 영역도 외부 페이지를 인용의 증거로 사용하고 있어 자사 인용이 약합니다.**
  - 경쟁사 응답 3종은 자사 페이지·외부 매체 양쪽 모두 인용된 반면 자사 응답은 외부 매체에서 인용하고 있습니다.
- **부족 신호** — **사용자 테스트 완료. 인체공학자 인증.** 자체 주장만 있고 외부 후기 부재(신호 1) · **Lift** 페어 시나리오 미연결(신호 2).
- **종합** — A·B 영역에서 제품 라인업 인지 단서와 인용 시 신뢰도를 보여주는 단서가 동시에 비어 결정적 점유 공백이 가장 큰 구조입니다.

## 2) 의미적 갭 매핑

자사 페이지는 **57° 손목이 편한 각도**·**자세 교정** 같은 효익 설명에는 강점이 있지만, AI가 답변에 끌어다 쓰는 좌/우 페어 시나리오·외부 후기·환경 가이드 자리에서 라인업 단위로 비어 있어 **Lift**·**MX ERGO**가 호출되지 못하는 직접 원인이 되고 있습니다.

**➊ 토픽 그룹별 콘텐츠 갭 표**

| 토픽 그룹                              | 개선 우선 순위 | 해결 전략                                          |
| -------------------------------------- | :------------: | -------------------------------------------------- |
| **A. 좌/우 페어 시나리오 운용**        |    🔴 위험     | **Lift** 왼손·오른손 페어 운용 시나리오 페이지 신설        |
| **B. 신뢰 보강**                       |    🔴 위험     | 외부 매체·실사용 후기·**1~2주 적응 기간** 안내 페이지 신설 |
| **C. 엄지 측면 버튼·생산성 부가 기능** |    🟡 양호     | **MX ERGO** 엄지 버튼 시나리오 가이드 추가                 |

> 🔴 위험 (즉시 개선) · 🟡 양호 (2~3순위 개선) · 🔵 안전 (보조 점검)

- **🔴 위험 토픽 그룹 A — Lift 좌/우 페어 시나리오 페어로 묶기**: 자사 0/3 vs 경쟁사 3/3 구도가 동시에 작동해 가장 시급한 공백입니다.
  - 근거: 응답 1번이 **자기 손에 맞는 전용 모델을 고르는 쪽**을 페어 정답으로 다루며 경쟁사 3종(**Kensington Pro Fit Ergo Vertical**·**CHERRY MW 4500**·**Perixx PERIMICE-713**)을 호출했고, 자사 **왼손, 오른손 어디에나 딱 맞는 Lift**는 단발성으로만 등장합니다.
  - 필요 단서: **Lift**·**왼손용도 있어요** 엔티티 + 좌/우 페어 운용 시나리오 가이드(왼손×오른손 페어 구성 예시) 토픽.
- **🔴 위험 토픽 그룹 B — 외부 후기·매체 인용 안내 페이지 신설**: 자사 자체 주장만 있고 외부 후기·매체 인용이 부족해 외부 페이지를 인용의 증거로 사용하는 구도가 굳어집니다.
  - 근거: **사용자 테스트 완료. 인체공학자 인증.** 자체 주장만 자사 페이지에 있고 **처음 2~3일은 오히려 어색함** 같은 단점 안내가 빠져 있어 균형 인용이 안 됩니다.
  - 필요 단서: **건초염이 없어졌다** 후기·**rtings.com**·**laptopmag.com** 매체 리뷰 엔티티 + Ergo Series 사용자 후기·매체 리뷰 모음 토픽.
- **🟡 양호 토픽 그룹 C** — **MX ERGO** 엄지 시나리오로 차별화 가능한 자리이므로 비교형 가이드로 선점합니다.
- **종합** — A·B를 즉시 개선해 페어 시나리오와 외부 신뢰 단서를 동시에 채우고, C는 순차 보강하는 방향이 자사 우선순위입니다.
