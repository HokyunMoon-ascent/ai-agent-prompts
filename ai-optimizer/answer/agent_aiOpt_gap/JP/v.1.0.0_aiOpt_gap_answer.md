1. 分析概要
   AI検索クエリのユーザーは「手首のだるさの原因が姿勢かを素早くテストしたい」という意図で 50〜70° バーティカル＋左／右対応＋親指サイドボタン＋レビューRTBまで一度に尋ねるが、自社ページは製品別の主要機能説明に集中しており、体感タイムライン・環境ガイド・外部レビューRTB・「左／右を交互に使う」シナリオマッチング領域が欠落している。
   :::accordion{title="概要確認"} ➊ AI検索クエリのユーザー意図(CEP)サマリ
   CEP: 「一般マウスで手首がだるい → 姿勢が原因か素早くテスト」したい即時検証型の購入検討
   KBF手がかり: :k[버티컬], :k[손목이 꺾이는 느낌], :k[좌/우 선택], :k[엄지 측면 버튼], :k[후기/입소문]
   RTB手がかり: 実際に痛みが減ったというレビュー・口コミ・ユーザー体感報告
   ➋ AI応答が共通的に扱った意味領域 (共通領域)
   体感タイムライン: :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)], :k[1~2주 적응 기간]
   姿勢・環境同伴ガイド: :k[책상 높이(팔꿈치 각도)·마우스 간격], :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기]
   外部レビュー・媒体RTB: :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다], :k[다나와]
   左／右を交互に使うシナリオ: :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보], :k[좌/우 각각 모델 있음]
   素早いテスト用の正直な短所認識: :k[처음 2~3일은 오히려 어색함], :k[게임용으로는 부적합], :k[작은 손이면 큰 모델 불편]
   ➌ 自社ページの重心
   自社ページは :k[57° 손목이 편한 각도], :k[근육 긴장 10% 줄여주고], :k[자세 교정] のような自社主張ベースの人間工学的効果説明と :k[Lift], :k[MX Vertical], :k[MX ERGO] ラインアップ紹介に重心がある
   左／右モデルの存在事実(:k[왼손, 오른손 어디에나 딱 맞는 Lift], :k[왼손용도 있어요])と手の大きさマッチング(:k[조금 작거나 보통 크기의 손에 잘 맞아요])はページ内に存在
   ➍ ギャップ1行洞察
   自社ページには「製品自体の便益説明」はあるが「ユーザーが決定直前に必要とする体感タイムライン・環境ガイド・外部レビューRTB・左／右交互使用シナリオ」が不在のため、AI応答の構成段階で自社ラインアップの一部(Lift, MX ERGO)が呼び出されていない :::

3. 意味的ギャップマッピング
   3つの応答すべてで一貫して登場するが自社ページに意味的に不在の4つの共通ギャップと、一部応答にのみ登場した3つの差異ギャップが導出された。
   :::accordion{title="意味的ギャップ確認"} ➊ [共通ギャップ] 体感タイムラインガイド — 「いつから痛みが減るか」段階別案内
   AI応答根拠: AI応答1番・2番・3番すべて — :k[1~2주 적응 기간], :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]
   自社ページ点検: 自社ページに適応期間・体感変化時点に関する言及が全くない。:k[근육 긴장 10% 줄여주고] のような便益主張はあるが時間軸ガイドは不在
   必要エンティティ候補: 適応段階ラベル(:k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)])
   必要トピック候補: 段階別体感変化ガイド、「最初のN日は違和感があり得る」正直案内、適応加速のヒント
   AI露出阻害仮説: ユーザーが決定直前に最も知りたい「今買えばいつから痛みが減るか」の答えを自社ページが提供しないため、AIがこの領域の出典を外部媒体から取得することになる
   ➋ [共通ギャップ] 姿勢・環境同伴ガイド — マウスだけ変えても限界というシグナル
   AI応答根拠: AI応答1番・3番 — :k[책상 높이(팔꿈치 각도)·마우스 간격], :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기]
   自社ページ点検: 自社ページに姿勢・机・腕サポートのような使用環境ガイドが不在。製品単独の便益説明中心
   必要エンティティ候補: :k[팔꿈치 90도], :k[손목 뜨게], :k[마우스 높이 낮추기], 机の高さ・マウス間隔
   必要トピック候補: 環境同伴チェックリスト、「マウス＋姿勢＋机」3要素ガイド、誤った姿勢例 vs 正しい姿勢
   AI露出阻害仮説: AIは「痛み軽減」クエリを受けるとマウス単独ではなく環境ガイドまでまとめて答える傾向があり、環境ガイドのないページは応答構成で部分引用に留まる
   ➌ [共通ギャップ] 外部レビュー・媒体RTB引用領域
   AI応答根拠: AI応答1番・2番・3番すべて外部媒体引用 — :k[다나와], :k[건초염이 없어졌다], :k[carpal tunnel pain 줄었다] など専門媒体・コミュニティ・ユーザーレビューを直接引用
   自社ページ点検: 自社ページに :k[사용자 테스트 완료. 인체공학자 인증.] のような自社検証文言はあるが、外部媒体・コミュニティ・実ユーザーレビュー引用が不在 — 意味的に隣接するがRTB種別が異なる
   必要エンティティ候補: 専門媒体レビュー引用、コミュニティレビュー引用、臨床／使用事例引用
   必要トピック候補: レビュー・媒体引用ボックス、「痛みが減った」ユーザー報告まとめ、媒体レビュー要約
   AI露出阻害仮説: AIはRTBシグナルとして外部媒体を優先的に引用するため、自社主張だけのページはRTB出典になれず、回答本文に自社ページリンクが定着しない
   ➍ [共通ギャップ] 「左／右を交互に使う」シナリオマッチング — ラインアップ可視性問題
   AI応答根拠: AI応答1番・2番・3番 — :k[양손 번갈아 쓰는 스타일이면 거의 필수 후보], :k[좌/우 각각 모델 있음], :k[왼손 전용 모델] をシナリオ単位でまとめて推奨
   自社ページ点検: 自社ページに :k[왼손, 오른손 어디에나 딱 맞는 Lift], :k[왼손용도 있어요] はあるが、「左／右を交互に使うユーザーに左／右各モデルをペアで運用する」というシナリオガイドは不在 — 部分意味一致だがシナリオマッチングは欠落
   必要エンティティ候補: :k[Lift] 左／右ペア、:k[좌/우 각각 모델 있음] ラインアップシグナル
   必要トピック候補: 「左／右交互ユーザー」シナリオページまたはLiftペア運用ガイド
   AI露出阻害仮説: ユーザー意図(左／右交互) → ラインアップマッチングがページでシナリオとしてまとまっていないため、AIは同じシナリオを :k[Perixx PERIMICE-713]・:k[Evoluent VerticalMouse 4] のような外部ラインアップで埋める
   ➎ [差異ギャップ] 素早いテスト推奨組み合わせ — 単一モデル推奨ではなく「組み合わせ」案内
   登場応答: AI応答2番にのみ明確に登場 — 「MX Vertical (メイン) + Perixx (左／右クロステスト用)」のような組み合わせ推奨
   自社ページ点検: 自社ページはモデル別の単独領域構成。ユーザーシナリオに応じた「組み合わせ運用」案内が不在
   必要エンティティ候補: メインモデル＋補助モデルのペアラベル
   必要トピック候補: シナリオ別組み合わせ推奨、「角度の問題か／左・右使用のためか両方確認可能」検証シナリオ
   AI露出阻害仮説: ユーザーが「原因検証」を目的とするとき、AIは組み合わせ回答を作るが、自社ページは単一モデル回答に限定されて呼び出される
   ➏ [差異ギャップ] 正直な短所・限界の認識 — 信頼度シグナル
   登場応答: AI応答2番 — :k[처음 2~3일은 오히려 어색함], :k[작은 손이면 큰 모델 불편], :k[게임용으로는 부적합]
   自社ページ点検: 自社ページに限界・短所の言及がない。便益一辺倒のメッセージ
   必要エンティティ候補: 非適合シナリオ、適応期の違和感、小さな手／大きなモデルのミスマッチ
   必要トピック候補: 「こういう場合は不向き」正直コピー、非適合シナリオ案内
   AI露出阻害仮説: AIはバランスの取れた回答のため短所も併せて引用するが、自社が短所を扱わなければ短所引用は外部から取得され、回答内の自社比重が下がる
   ➐ [差異ギャップ] 手の大きさ別モデルマッチングガイド
   登場応答: AI応答2番・3番 — :k[작은 손이면 큰 모델 불편], 「ELECOMは手が小さめ向け」、「MX Verticalは大きくて重い」
   自社ページ点検: 自社ページのLift領域に :k[조금 작거나 보통 크기의 손에 잘 맞아요] が部分的に存在。ただしMX Vertical側で「大きな手に適合／小さな手には不向き」式のマッチングシグナルが不在 — 部分意味一致、マッチング標準化は欠落
   必要エンティティ候補: 手の大きさラベル(小／普通／大)、モデル別の手の大きさ推奨
   必要トピック候補: 手の大きさマッチングガイド、「自分の手に合うモデルの選び方」
   AI露出阻害仮説: ユーザーが「自分の手の大きさ」を変数として考慮するとき、マッチングガイドが欠落しているためAIが外部ラインアップまで持ち込む :::
4. 補強推奨
   導出された7つのギャップのうち、体感タイムライン・環境ガイド・手マッチング・ラインアップシナリオは既存ページ補強(統合型)、外部レビューRTB・統合人間工学ハブは別ページ／外部領域(分離型)に向かわせるのが適切である。

   エンティティ候補: :k[즉각 효과 (1~3일)], :k[적응 기간 (3~7일)], :k[장기 효과 (2주+)]

   トピック候補: 入門ガイド、段階別チェックリスト
   チャネルヒント: オウンド
   分離判断根拠: ガイドシグナルが複数製品で共通するため、単一ハブに分離してこそ外部検索で「ガイド」という意図マッチングが生じる
   ➏ [統合型／サンプル] 正直な短所・限界の認識コピー (製品領域の短所段落)
   対象ギャップ: 意味的ギャップマッピングの ➏ 正直な短所・限界の認識
   補強方向: 各製品領域に「こういう場合は不向き」正直コピー段落を短く設置し、信頼度シグナルを補強すべき
   エンティティ候補: 非適合シナリオ、:k[작은 손이면 큰 모델 불편], :k[게임용으로는 부적합], :k[처음 2~3일은 오히려 어색함]
   トピック候補: 「こういう場合は別モデルを推奨」分岐ガイド
   チャネルヒント: サンプル (短いコピー単位) + オウンド (ページ領域)
   統合判断根拠: 短所コピーは短く製品ごとに異なるため、各製品領域に統合するのが適切 :::
