# ai-optimizer 개선 이력

> v.3.0.0 (구 v.0.2.2) 이후 진행한 압축·정합성·가독성 개선의 누적 이력입니다. 새 작업이 끝날 때마다 본 문서에 추가합니다.

---

## 버전 체계 정의 (2026-05-28 도입)

`vX.Y.Z` (SemVer) 표기를 사용합니다. 4개 에이전트(gap·owned·earned·noneURL)는 **동기화 버전**을 유지합니다 — 한 곳만 변경되어도 4개 모두 같은 버전으로 올립니다.

### 트리거

| 단위 | 의미 | 트리거 |
|---|---|---|
| **X (MAJOR)** | 구조·계약 변경. 결과물 형태 자체가 바뀜 | 출력 섹션 구성 변경 (상위 `## 1) / ## 2)` 헤딩의 개수·이름·순서) · 워크플로우 자체 변경 (분석 방법론 재정의) · 페르소나/사용 맥락 변경 |
| **Y (MINOR)** | 구조 안에서 의미 있는 변경 | 섹션 내부 sub-block(➊➋➌) 개수·역할 변경 · 표 컬럼 구성·헤더·카디널리티 변경 · 라벨 어휘·기호 체계 재정의 · IO/SAMPLE_DATA 스키마 추가·삭제 |
| **Z (PATCH)** | 표현 다듬기 | 문구·어휘 다듬기 (의미 동일) · 글자수 가이드 미세 조정 · 오타·문법 수정 · 답변(answer) 파일만 영향 |

### 향후 운영 규칙

1. answer 파일 첫 줄 변경 포인트 노트에 SemVer 분류 명시 — 예: `> v.4.2.0 (MINOR) 변경 포인트: …`
2. 새 버전 작업 시 본 문서에 한 섹션 추가 (배경 / 변경 요지 / 산출물 / 검증)
3. 한 에이전트만 변경되어도 4개 모두 동기 버전. 변경되지 않은 에이전트는 직전 버전의 사본을 새 버전명으로 복사
4. in-place 누적 패치가 MINOR 이상이라면 새 버전을 끊는 것을 우선 — 같은 파일에 누적 시 외부 식별성 다시 깨짐

## v.3.0.0 → v.4.0.0 (구 v.0.2.2 → v.0.2.3, 2026-05-15, 금 17시대) — 4 섹션 구조 → 2 섹션 구조 대대적 압축

**배경**: v.0.2.2까지는 모든 에이전트가 `1) 분석 개요 / 2) 갭 진단 내용 요약 / 3) 개선 제안 / 4) 인사이트` 4섹션 구조였음. 실제 마케터·컨설팅 의뢰자 사용 흐름에서 (a) 분석 개요는 매번 같은 메타 진술 반복, (b) 인사이트는 다른 섹션과 중복, (c) 4섹션 헤딩 자체가 시선을 분산시켜 의사결정에 직결되지 않음. 마케터 브리핑 톤 원칙(분야 전문 용어 미노출)을 따르면서, **출력 섹션을 핵심 진단 단위 1~2개로 압축**하고 표·해설 표준을 통일하는 것이 목적.

**변경 요지 (에이전트별)**

1. **gap** — 3 섹션(`1) 분석 개요`·`2) 브랜드 노출 진단`·`3) 콘텐츠 공백 도출 및 우선 순위 도출`) → **2 섹션**(`1) 브랜드 노출 분석`·`2) 의미적 갭 매핑`). 분석 개요는 폐지, 브랜드 노출 진단과 콘텐츠 공백 도출은 갭 매핑으로 통합. 헤더 수 34 → 28.
2. **owned** — 4 섹션(`1) 분석 개요`·`2) 갭 진단 내용 요약`·`3) 개선 제안`·`4) 인사이트`) → **단일 출력 섹션 `# 개선 제안`**. 나머지 3개는 내부 사고 단계로 흡수. 헤더 수 33 → 23.
3. **earned** — 4 섹션(분석 개요·갭 진단·개선 제안·인사이트) + noneURL 모드 4 섹션 → **2 매트릭스만**(토픽별 인용 현황 + 토픽별 액션). 모든 진단 메시지는 매트릭스 + 통합 해설에 압축. noneURL 모드도 컬럼·해설 적응형으로 단일 흐름 유지. 헤더 수 28 → 29(소폭 증가지만 메인 구조는 통합).
4. **noneURL** — 4 섹션(`1) 분석 개요`·`2) 브랜드 노출 진단`·`3) 응답 핵심 진단`·`4) 인사이트`) → **2 섹션**(`1) 응답 구조 분석`·`2) 브랜드 언급 맥락 및 답변 인용 출처 분석`). 섹션명도 마케터 친화 용어로 전면 재명명. 헤더 수 36 → 29.

**공통 분석 원칙 신설 (gap 기준 7·8·9번)**

- 7. 토픽 그룹 구성 원칙 — 4~5개 그룹(A./B./C./D./[E.])으로 통합, 자사 콘텐츠 제작 액션 단위 1:1 매칭
- 8. 표 셀 표기 원칙 — §1 ➊ 토픽 그룹 정의 표 3컬럼·§2 ➊ 콘텐츠 갭 표 4컬럼(이 시점) 제한, `✅/⚠️/❌ N/M` 셀 기호 표준
- 9. 표 직후 해설 원칙 — 셀 숫자를 그대로 읽지 말고 한 단계 위로 해석하라는 가이드 명시

**산출물**: KR 16개 파일 (4 prompt + 4 answer × KR — JP/EN은 동기화 안 됨, 후속 사이클에서 진행)

**검증**

### 일관 규칙

- 그룹 라벨 = `**A. 토픽명**` 형식 알파벳 prefix (좁은 셀에서도 해설이 기호로 그룹 식별 가능)
- gap §1·§2는 **동일 그룹 → 동일 라벨** cross-section 정합 (좌·우 페어 = §1·§2 모두 A)
- §1에 등장하는 모든 그룹은 §1 ➊ 표에 먼저 정의
- 셀에 못 담는 부가 정보(인용 현황 · 추천 채널 · 보조 인용 · 유도 콘텐츠 · 도입 형식 · 약하게 다룬 의도)는 모두 통합 해설에서 자연어로 풀어쓰기
- 점유 제품·매체·도메인 등 결정적 굵게 인용은 해설에 보존
- "~입니다" 정중체, `:::accordion` 미사용, 절대적 한 줄 원칙(One-Line Rule), 토픽 그룹 좌측 행 고정

### 미적용 상태

- **JP/EN 동기화**: v.0.2.5 in-place 패치는 KR만 적용, JP/EN은 v.0.2.5 base 상태
- **`description/0518/description.md`의 추가 피드백** — 차기 라운드에서 반영 예정:
  - 표현 다듬기: "신뢰 통제권" → "외부 페이지를 인용의 증거로 사용", "허브" → "안내 페이지" 등
  - gap §2 컬럼 재구성: `그룹 / 콘텐츠 액션 / 우선순위` → `그룹 / 개선 우선순위 / 해결 전략`
  - 우선순위 라벨 표현 변경: 결정적·기회·보강 → 위험·양호·안전 류
  - owned "흡수 방식" 표현 다듬기
  - gap §2 콘텐츠 갭 표 + 갭 상세 통합 검토

## v.4.1.0 → v.4.2.0 (구 v.0.2.5 → v.0.2.6, 2026-05-18, 월) — 0518 description 적용 + 표 표준 재정의
