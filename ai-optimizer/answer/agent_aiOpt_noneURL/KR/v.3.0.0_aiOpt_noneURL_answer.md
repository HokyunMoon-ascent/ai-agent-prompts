## 2) 응답 구조 분석

**① 한눈에 보는 결론**

3개 응답 모두 "기준 정리 → 1순위 추천 → 좌/우 대안 → 후기·적응 가이드" 4단 흐름으로 동일하게 전개되며, :k[Logitech MX Vertical]을 1순위 표준으로 두고 좌/우 시나리오를 보조 후보로 분산 배치합니다. :k[엄지 측면 버튼]은 4단 흐름 안에서 비교적 약하게 다뤄집니다.

:::accordion{title="응답 구조 상세"}
**② 그렇게 판단한 이유**

AI 응답 1번은 산문형 단락, 2번은 :k[📊 핵심 비교] 표 단위, 3번은 :k[🥇 Best overall] 메달 헤딩으로 형식이 다르지만, 1순위·대안·후기 순서는 공통입니다. :k[1~2주 적응 기간]·:k[처음 2~3일은 오히려 어색함] 같은 솔직한 단점은 모든 응답이 본론 후반에 배치하며, :k[엄지가 닿기 쉬운 측면 버튼]은 한두 줄로만 처리됩니다.
:::
