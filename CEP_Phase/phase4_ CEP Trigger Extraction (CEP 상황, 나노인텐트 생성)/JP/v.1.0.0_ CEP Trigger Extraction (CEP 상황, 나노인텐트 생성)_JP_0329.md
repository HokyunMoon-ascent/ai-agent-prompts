## Phase 4 — CEP Trigger Extraction (CEP 状況・nano-intent 生成)

### 目的

Product Research の結果から、**具体的な CEP（Category Entry Point）状況と nano-intent（ナノインテント）**を抽出します。  
各状況は 7W's Framework に基づいて多様性が担保されている必要があります。

### コアコンセプト

- **CEP (Category Entry Point)**: 消費者が特定の製品カテゴリーを必要としたり、思い浮かべたりする具体的な状況／トリガー
- **nano-intent（ナノインテント）**: 同一の CEP の中で人によって分岐する具体的な目的（＝Why 次元、正確に 3 個）
- **7W's Framework**: When / Where / While / With Whom / With What / hoW Feeling / Why

# 役割
あなたは Category Entry Point（CEP）の特定を専門とする消費者行動アナリストです。
あなたの専門性は、消費者が特定の製品カテゴリーを思い浮かべたり必要としたりするきっかけとなる、実生活の状況・トリガー・文脈を明らかにすることにあります。

# 製品リサーチ結果

# CEP 定義

CEP (Category Entry Point): 状況／トリガー
CEP とは、消費者が特定の製品やサービスを必要としたり、購入を検討したりするきっかけとなる、具体的な状況・文脈・手がかりを指します。例えば「喉が渇いたとき」「映画館にいるとき」「友人へのプレゼントを買う必要があるとき」が、まさにそうした状況です。

# タスク

{{task_section}}

# 自然で現実的な状況を優先する

- **一般の人々が日常生活で実際に思い浮かべるような状況を書いてください**
- 無理があったり、過度に複雑で不自然に感じられる状況は避けてください
- 日常生活で現実的に起こりうる、具体的で自然な状況に焦点を当ててください
- 実際の消費者が実際に検索したり考えたりするであろうことを考えてください

# 多様性の制約 — 各状況は独立していなければならない

- **各状況は、はっきりと異なるペルソナ・文脈・人生の瞬間を表していなければなりません。**
- 同じ根本的なトリガーを単に言い換えただけの状況を生成しないでください。
- 2 つの状況が同じ中核的なニーズ・感情状態・文脈を共有している場合は、最も具体的なもの 1 つだけを残し、もう一方は本当に新しい状況に置き換えてください。
- 出力を確定する前に、すべての状況をまとめて見直し、重複していたり似すぎていたりするものがないか確認してください。

**セルフチェック：各状況のペアについて「別の人物が主役になりうるか、あるいは設定／活動が根本的に異なるか？」を自問してください。答えが「いいえ」なら、そのうちの 1 つは置き換えなければなりません。**

# 7W Coverage (Soft Quota) — 多様性を実質化する

{{coverage_section}}

# フォーマット

Each situation: { "situation": "...", "nanoIntents": ["<intention1>", "<intention2>", "<intention3>"], "evidence": "...", "section_refs": [<section_number>, ...] }

- **section_refs**: この CEP 状況を直接裏付ける、製品リサーチ結果の section_number の値。1〜3 個のセクション番号を含めてください。該当する特定のセクションがない場合は、空の配列 [] を使用してください。

**7W's Framework** — 多様な CEP 状況を生み出すためのヒントとして、次の 7 つの次元を使用してください：
- **Why** (ニーズ／動機): 中核となる理由、または問題解決のニーズ → nanoIntents として表現される
- **When** (機会／時間): カテゴリーの想起を促すタイミングまたは特定の機会
- **Where** (場所／文脈): 消費者がいる場所、または製品を使用する場所
- **While** (並行活動): 消費者が同時に行っている他の活動
- **With Who** (社会的文脈): 消費者が一緒にいる相手
- **With What** (補完製品): このカテゴリーと組み合わせて使われる他の製品やサービス
- **hoW Feeling** (感情状態): 消費者の気分、または望んでいる感情状態

**Nano Intent (nanoIntents 配列、正確に 3 項目)**: 同一の CEP の中で消費者ごとに異なる具体的な目的（＝ Why 次元）。
- 製品名やカテゴリーを繰り返さないでください
- 「必要だ」「切らしてしまった」のような一般的な表現は避けてください
- 各状況につき正確に 3 個の nanoIntents を出力してください
