## 8. Phase 5-1 — KBF User Prompts (AI 챗봇 예시 질문 생성)

### 이 초안이 선 자리

요청 025(2026-08-25)의 지적 — 생성된 예시 질문에 제품 맥락이 없어 "무슨 맥락으로 묻는 질문인지" 알 수 없다 — 를 받아 만든 초안입니다.
같은 문제를 겨눈 초안이 이미 하나 있습니다(`미채택/v.1.2.0_..._0825.md`). v1.2.0은 **카테고리 소환 조건**과 **자가 점검**을 넣었지만,
정작 이 프롬프트는 **카테고리가 무엇인지 모르는 상태**로 실행됩니다. 입력 변수가 `{{cep}}`·`{{kbf}}`·`{{response_language_label}}` 셋뿐이기 때문입니다.
v1.3.0은 그 구멍을 메우고 v1.2.0의 나머지 조항을 승계합니다.

> ⚠ **백엔드 정합 선행 필수** (이 초안은 백엔드 반영 없이는 동작하지 않습니다)
>
> 1. `buildKbfUserPromptsPrompt(...)` 에 `category_line` 인자 추가 — Phase 5가 이미 받는 값과 같은 값을 넘기면 됩니다.
> 2. 응답 배열 길이 검증값을 **4 고정 → 1~4 가변**으로. 지금 고정 4면 KBF 0개 카드가 실패합니다.
> 3. 배포된 템플릿 문자열에 예시 CEP·KBF(`아침 샤워 후 머리 빠질 때`, `약산성 pH 제품, 무향, 저자극`)가 섞여 들어가 있지 않은지 확인. ③의 관측은 그 오염을 시사합니다.

### 목적

CEP와 KBF를 기반으로 실제 사용자가 AI 챗봇에 입력할 법한 **자연스러운 질문**을 생성합니다.

**개수는 `1 + KBF 개수`입니다. 고정값이 아닙니다.**
KBF 3개면 4개, 2개면 3개, 1개면 2개, 0개면 1개입니다.

| 순번 | 구성 | 설명 |
| --- | --- | --- |
| 1 | CEP 단독 | CEP 상황 자체를 질문으로 옮긴 것. KBF는 언급하지 않되, **문제 영역은 남깁니다.** |
| 2 | CEP × KBF 1 | CEP 상황에서 첫 번째 KBF를 조건으로 붙인 질문 |
| 3 | CEP × KBF 2 | CEP 상황에서 두 번째 KBF를 조건으로 붙인 질문 |
| 4 | CEP × KBF 3 | CEP 상황에서 세 번째 KBF를 조건으로 붙인 질문 |

▎**KBF가 2개면 3번까지만 만듭니다.** 4번 자리를 채우려고 KBF 두 개를 섞은 질문을 추가하지 마세요.

> 개정 이력
>
> - 미확정) v.1.3.0 (0825): `{{category_line}}` 입력 변수 신설 · 예시값 오염 차단 조항 · v1.2.0 조항 승계.
> - 미채택 v.1.2.0 (0825): 1번 질문에 문제 영역 유지 조건과 카테고리 소환 자가 점검 추가. 개수 표기를 4 고정에서 가변으로 교체.
> - v.1.1.0 (0814): 출력 9개(KBF당 3개) → 4개(CEP 단독 1 + CEP×KBF 3)로 변경.
> - v.1.0.0 (0714): 나노인텐트가 Phase 4 출력에서 제거됨에 따라 입력 변수 `{{nano_intent}}` 제거.

### 입력 변수

| 변수 | 설명 |
| --- | --- |
| `{{cep}}` | CEP 상황 (`card.cep`) |
| `{{kbf}}` | 카드의 모든 KBF를 `", "` 로 연결한 문자열. KBF가 없으면 빈 문자열 |
| `{{category_line}}` | **신설.** 카테고리 한 줄 정의. Phase 5가 받는 값과 동일 |
| `{{response_language_label}}` | 응답 언어 라벨 (locale KR/JP/US 기준, 기본값 Korean) |

**예시값을 이 표에 적지 마세요.** 표의 예시 문자열이 모델 출력에 그대로 새어 나온 사례가 확인됐습니다(변경점 ③).
설명이 필요하면 이 문서의 본문에 산문으로 적고, 템플릿과 변수 표에는 넣지 않습니다.

**KBF 순서가 곧 질문 순서입니다.** 백엔드에서 KBF 순서를 재정렬하면 질문 순서도 함께 바뀝니다.

### 출력 형식

JSON 배열 (**길이 = 1 + KBF 개수**, 최대 4개). KBF가 0개면 1번 질문 하나만 출력합니다.
Phase 5 v.2.1.0부터 근거를 붙이지 못한 KBF는 내지 않으므로 0개가 정상입니다.

### Prompt 템플릿

```
<!-- 미확정) v.1.3.0_phase5-1_AI 챗봇 예시 질문 생성_KR_0825.md -->
아래의 CEP (Category Entry Point)와 KBF (Key Buying Factors)를 활용해, 실제 사용자가 AI 챗봇(ChatGPT, Gemini, Perplexity 등)에 물어볼 법한 자연스러운 질문을 생성하세요.

**만들 질문의 개수는 `1 + KBF 개수`입니다.** 먼저 KBF가 몇 개인지 세고 시작하세요.
KBF 3개 → 4개 / 2개 → 3개 / 1개 → 2개 / 0개 → 1개.
AI 검색에서 흔히 나타나는, 구매 의도가 높은 프롬프트에 집중하세요.
톤: 도움을 주는 친구와 대화하듯 친근하고 편안하며 다가가기 쉬운 스타일로 작성하세요.

Input:
- Category: {{category_line}}
- CEP (Category Entry Point): {{cep}}
- KBFs (Key Buying Factors): {{kbf}}

KBFs는 ", " 로 구분된 목록입니다. 앞에서부터 순서대로 KBF1, KBF2, KBF3입니다.

Category는 이 질문이 어느 카테고리의 것인지 알려주는 **배경 정보**입니다.
질문에 카테고리 이름을 그대로 박으라는 뜻이 아닙니다. 아래 '카테고리 소환 조건'을 읽고 쓰세요.

질문의 구성은 아래 순서로 고정합니다. 순서를 바꾸지 마세요.
**KBF가 없는 번호는 만들지 않습니다.**
1. CEP 상황 자체를 질문으로 옮깁니다. KBF는 언급하지 않습니다.
2. CEP 상황에 KBF1을 조건으로 붙인 질문
3. CEP 상황에 KBF2를 조건으로 붙인 질문
4. CEP 상황에 KBF3을 조건으로 붙인 질문

작성 규칙:
- 각 질문은 하나의 KBF만 다룹니다. 두 개 이상의 KBF를 한 질문에 섞지 마세요.
- **개수를 채우려고 KBF를 섞은 질문을 덧붙이지 마세요.** KBF가 2개면 질문은 3개에서 끝입니다.
  ("A와 B를 함께 고려해서…", "A 말고도 어떤 점을…" 같은 문장이 나왔다면 잉여 질문을 만든 것입니다.)
- KBF 표현을 그대로 옮겨 붙이지 말고, 사용자가 실제로 쓸 법한 말로 자연스럽게 녹여 쓰세요.
- 모든 질문이 같은 CEP 상황 안에 있어야 합니다. 상황을 바꾸거나 새로 만들지 마세요.
- 브랜드명이나 제품명은 넣지 마세요.
- 질문마다 문장 구조를 달리해, 같은 문형이 반복되지 않게 하세요.
- **위 Input에 실제로 들어온 값만 쓰세요.** 이 지시문에 예시로 적힌 상황·조건이 있더라도
  그것을 KBF나 상황으로 삼지 마세요. KBF 자리가 비어 있으면 비어 있는 것이지, 채워 넣을 것이 아닙니다.

카테고리 소환 조건:
- 1번 질문은 KBF를 쓰지 않지만, **무엇을 하려다 막혔는지(문제 영역)는 반드시 남깁니다.**
  영역까지 지우면 이 카테고리와 무관한 생활 상담 질문이 됩니다.
  (✗ 아이 낮잠 시간에 큰 소리가 날까 봐 신경 쓰이는데 어떻게 대처할까? — 답은 백색소음기·방음이 된다)
  (✓ 무릎 꿇고 바닥을 닦다 보니 헹구고 짜는 게 번거로운데 어떤 방식이 덜 지칠까? — 답에 이 카테고리가 들어온다)
- **자가 점검** — 만든 질문을 AI 챗봇에 넣었다고 상상하세요. 답에 Category가 후보로 나옵니까?
  생활 조언이나 관리 요령만 나온다면, 그것은 질문의 문제가 아니라 **CEP 문장에 영역이나 수단이 빠진 것**입니다.
- 그런 경우에도 **CEP에 없는 말을 넣어 억지로 카테고리를 부르지 마세요.** CEP 상황에 있는 말로만 씁니다.
  상황을 보정해 그럴듯하게 만들면 상류 단계(Phase 3·4)의 문제가 가려집니다. 있는 그대로 쓰세요.
  Category는 이 점검을 하기 위한 기준일 뿐, 질문에 넣을 재료가 아닙니다.

Output language: {{response_language_label}}

출력 직전 자가 점검:
1. **배열 길이가 `1 + KBF 개수`와 같습니까?** 세어 보고 다르면 맞추세요.
2. **Input에 없던 조건을 쓴 질문이 있습니까?** 있으면 지우세요.

응답 형식(오직 JSON 배열만 출력하고 그 외에는 아무것도 출력하지 마세요):
["질문1", "질문2", ...]   ← 길이는 1 + KBF 개수
```
