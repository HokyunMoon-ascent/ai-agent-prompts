# 현재 상태(누락 양상) 분류 기준

`v.4.3.0` 기준 ai-optimizer 에이전트의 **"현재 상태" 컬럼 분류 기준**을 원문에서 추출한 결과입니다.

> **표기 전환 (v.4.3.0_0529)**: 기존 `개선 우선 순위` 컬럼(🔴 위험 / 🟡 양호 / 🔵 안전 신호등 라벨)은
> 에이전트가 **우선순위를 단정(verdict)** 하는 인상을 주어, 비즈니스 맥락을 아는 마케터가 반발할 여지가 있었습니다.
> 이를 **"현재 상태"** 컬럼 + **중립 마커 `○ / ◐ / ●`** 로 바꿔, 에이전트는 **"어떻게/얼마나 누락되었는가"만 중립적으로 표시**하고
> **우선순위 판단은 사용자(마케터)에게 맡기는** 가벼운 넛지로 전환했습니다.
> 3개 에이전트(owned·gap·earned)가 같은 마커 체계(○/◐/●)를 공유하되, **마커가 가리키는 의미는 에이전트별 차원에 따라 다릅니다.**

## 공통 마커 체계 (fill = 커버리지 은유)

| 마커 | 의미(공통)             | 기존 라벨 대응 |
| ---- | ---------------------- | -------------- |
| ○    | 핵심 영역 통째 누락 — 가장 큰 공백 | (구) 🔴 위험   |
| ◐    | 일부 단서만 존재       | (구) 🟡 양호   |
| ●    | 거의 충족              | (구) 🔵 안전   |

> 마커는 색상 의존 없는 유니코드 기하 도형이라 KR/JP/EN 공통입니다.
> **빈 원(○) = 커버리지 비어 있음(가장 큰 누락), 찬 원(●) = 거의 채워짐** 의 직관을 따릅니다.
> 정렬은 **○ → ◐ → ●**(누락 큰 순)이며, 이는 "어디부터 보면 좋을지"의 가벼운 안내일 뿐 우선순위 단정이 아닙니다.

## 에이전트별 분류 기준 (원문 인용)

### 1) Owned — 자사 페이지 보유 영역 기준 ✅ **명시되어 있음**

> 출처: `agent_aiOpt_owned/KR/v.4.3.0_aiOpt_owned_KR_0528.md`

- **○ 통째 누락** — 자사 페이지가 **핵심 영역을 통째로 놓치고 있어** 신규 페이지 또는 대폭 보강이 필요한 토픽
- **◐ 일부 존재** — 자사 페이지에 **단서가 일부 있으나 보강 여지가 있는** 토픽
- **● 거의 충족** — **미세 조정만으로 충분한 보조** 토픽

분류 후 "해결 전략" 셀은 `신규 페이지` / `기존 페이지 보강` 2값으로 매핑합니다.
일반적으로 ○ 통째 누락은 신규 페이지/대폭 보강, ◐ 일부 존재·● 거의 충족은 기존 페이지 보강과 짝지어집니다(우선순위 판단은 사용자 몫).

### 2) Gap — 자사 vs 경쟁사 점유 분포 기준 ✅ **명시되어 있음**

> 출처: `agent_aiOpt_gap/KR/v.4.3.0_aiOpt_gap_KR_0528.md` (분석 로직 6번 "현재 상태 분류")

- **○ 자사 공백** — **자사가 비어 있고 경쟁사가 점유한 자리**
- **◐ 진입 가능** — **진입 가능성이 있는 자리**
- **● 신뢰 보강** — **신뢰 보강 자리**

(주의: 원문의 `자사 ❌ 0/N vs 경쟁사 ✅ N/N`은 분류 기준이 아니라 **행 정렬 규칙** — 공백(격차)이 가장 큰 그룹을 맨 위에 배치하라는 표시 순서 지침입니다.)

### 3) Earned — 외부 인용 점유 분포 기준 ✅ **명시되어 있음**

> 출처: `agent_aiOpt_earned/KR/v.4.3.0_aiOpt_earned_KR_0528.md`

- **○ 인용 공백** — 자사가 핵심 채널·매체에서 인용되지 않고 **경쟁사가 점유한** 토픽 (자사 `❌ 0/N` + 경쟁사 `✅` 다수 구도가 동시에 작동)
- **◐ 일부 단서** — 자사 인용이 **일부 채널에 단서로 존재**하나 채널 범위·인용 표현 보강 여지가 있는 토픽
- **● 인용 균형** — **인용 분포가 균형 잡혀 있어** 보조 점검·균형 회수만 필요한 토픽

분류 후 "해결 전략" 셀은 `(채널 5분류 중 1~2개) + (형식 1~2개) + AI 인용 후보 1개` 한 줄로 작성합니다.

### 4) noneURL — 사용하지 않음 ✅ **명시되어 있음**

> 출처: `agent_aiOpt_noneURL/KR/...`

- 자사 페이지가 없어 갭 우선순위 개념 자체가 부재하므로 ○/◐/● 마커링을 **적용하지 않습니다**
- (owned 에이전트 내부의 noneURL 모드에서는 ○/◐/● 를 그대로 사용합니다)

## 정렬·표시 규칙

- 표 행은 **○ → ◐ → ●** 순(누락 큰 순)으로 정렬합니다.
- gap의 경우 §1 표는 공백 정도 순으로 알파벳 라벨 부여 후, §2 표는 현재 상태(○/◐/●)별로 행을 재배열할 수 있으나 라벨은 §1과 동일 유지합니다.
- 토픽 그룹 라벨은 `**A. 토픽명**`·`**B. 토픽명**` 형식으로 알파벳 prefix를 굵게 부여합니다.
- 각 에이전트 표·범례 끝에 **"우선순위 판단은 사용자 몫"** 넛지 문구를 명시합니다.

## 정리

| 에이전트 | 분류 기준 명시 여부 | 마커 의미 요약                                          |
| -------- | ------------------- | ------------------------------------------------------- |
| owned    | ✅ 명시             | 자사 페이지의 누락(○)/단서 일부(◐)/거의 충족(●)         |
| gap      | ✅ 명시             | 자사 공백(○)/진입 가능(◐)/신뢰 보강(●)                  |
| earned   | ✅ 명시             | 인용 공백(○)/일부 단서(◐)/인용 균형(●)                  |
| noneURL  | ✅ 명시 (미사용)    | 마커링 자체를 적용하지 않음                              |
