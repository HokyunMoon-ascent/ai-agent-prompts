- 언드미디어 에이전트(RTB 가이드 에이전트) 프롬프트를 만들고자 합니다. 자매 에이전트 `agent_aio_gap`(KR/v.0.1.0_aio_gap_KR_0430.md)의 양식을 그대로 참고하여 동일한 4섹션 골격으로 생성합니다.
- 정의·자료 출처: <https://notebooklm.google.com/notebook/05ec663f-e655-4075-8538-683558ca5157>
- 선행 의존: `agents/ai_agent/agent_aio_gap`의 출력(③ 의미적 갭 매핑 + ④ 보강 권장 중 채널 힌트=언드 항목)이 본 에이전트의 1차 입력입니다.

## 회의록 요약 (사용자 제공 원문)

회의록 내용에 따르면, 언드미디어 에이전트(RTB 가이드 에이전트)는 자사 매체가 아닌 외부 커뮤니티나 소셜 채널에서의 전략을 다룹니다. 구체적으로 진단하고 제공하는 항목은 다음과 같습니다.

### 1. 무엇을 진단(추출)하는가?

- **인용된 외부 매체 추출**: AI가 답변을 생성할 때 근거로 인용하거나 언급한 외부 매체(예: 레딧, 화해, 네이버 블로그 등)가 무엇인지 파악하고 추출합니다.

### 2. 언드미디어 에이전트는 무엇을 제공하는가?

- **채널별 전략 제안**: 추출된 외부 매체 데이터를 바탕으로, 각 채널 특성에 맞는 전략 단위의 대응 방안을 제안합니다.
- **RTB(Reason to Believe) 기반 가이드**: 단순히 채널만 알려주는 것이 아니라, "특정 커뮤니티나 소셜 채널에 구체적으로 어떤 내용의 근거가 올라가야 하는가"까지 분석하여 가이드로 제공합니다.
- **비윤리적 바이럴 제안 배제**: 커뮤니티에 가이드를 제공할 때 '몰래 일반 유저인 척 작성하라'는 식의 어뷰징 제안은 명시적으로 배제하도록 프롬프트가 설계되어 안전한 방향성을 제시합니다.

## NotebookLM 자료에 명시된 사항 (근거 있음)

본 프롬프트 v.0.1.0 의 설계는 NotebookLM 노트북 `05ec663f-e655-4075-8538-683558ca5157` 의 다음 명시 사항을 근거로 합니다.

| 항목 | 명시 내용 |
|---|---|
| 입력 | AI 응답 원문(C) + 갭 분석 결과(Findings)가 핵심 입력 |
| 추출 대상 매체 예시 | 레딧, 화해, 네이버 블로그 (구체 카테고리 체계는 노트북에 미정의) |
| 출력 목표 | "어떤 커뮤니티(채널)에 어떤 근거가 올라가야 하는가"를 채널·전략 단위로 제안 |
| 윤리 가드 | "몰래 유저인 척 작성하는 식의 제안은 명시적으로 배제"를 프롬프트에 규정 |
| 파이프라인 위치 | ① Findings → ② Owned → ③ **Earned (본 에이전트)** → ④ Action Items → 샘플 작성 에이전트 |

| 항목 | 본 프롬프트 v.0.1.0 기본안 |
|---|---|
| 매체 분류 체계 | 5 카테고리 — 커뮤니티 / 리뷰사이트 / 블로그·SNS / PR·뉴스 / 전문가 인용 |
| RTB 출력 표준 양식 | 6 필드 — 출처 갭 / 현재 인용 매체 / 필요 RTB / 1순위 매체 카테고리 / 보조 매체 카테고리 / AI 노출 저해 가설 |
