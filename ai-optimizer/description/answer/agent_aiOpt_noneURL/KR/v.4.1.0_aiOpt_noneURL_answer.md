## 1) 응답 구조 분석

3개 응답 모두 "기준 정리 → 1순위 추천 → 좌/우 대안 → 후기·적응 가이드" 4단 흐름으로 동일하게 전개되며, **Logitech MX Vertical**을 1순위 표준으로 두고 좌/우 전용 모델을 보조 후보로 분산 배치합니다.

**➊ 응답 흐름 요약 표**

| 응답            | 본론 (추천 순서·비중)                                     | 결론 (마무리 톤)              |
| --------------- | --------------------------------------------------------- | ----------------------------- |
| **AI 응답 1번** | **Logitech MX Vertical** 1순위 → 좌/우 전용 → 후기·적응   | **1~2주 적응 기간** 가이드    |
| **AI 응답 2번** | **Logitech MX Vertical** 1순위 → 좌/우 전용 → 후기·적응   | **처음 2~3일은 오히려 어색함** 단점 안내 |
| **AI 응답 3번** | **Logitech MX Vertical** 1순위 → 좌/우 + 트랙볼 대안 → 후기 | 트랙볼 **Kensington Orbit Trackball** 추가 대안 |

- **3개 응답 모두 4단 흐름이 일관되며 1순위 추천이 한 모델로 고정됐습니다.**
  - 응답 형식은 산문·표·메달 헤딩으로 다르지만 1순위 → 좌/우 대안 → 후기 순서는 공통이며 **Logitech MX Vertical**이 대표 해답 자리를 단정적으로 차지합니다.
- **응답 간 차이 — 트랙볼 대안의 등장 여부**
  - AI 응답 3번만 **Kensington Orbit Trackball**을 좌/우 대안 아래에 추가로 끌어왔습니다.
- **종합** — **버티컬**·**좌/우 선택**·**후기/입소문** 3축은 비중 있게, **엄지 측면 버튼**은 4단 흐름 안에서 일관되게 약하게 다뤄집니다.

## 2) 브랜드 언급 맥락 및 답변 인용 출처 분석

대표 해답 자리는 **Logitech MX Vertical** 단일 모델이 통째로 차지하고, 조건부 대안 자리는 좌/우 전용·트랙볼 4종이 응답마다 분산되며, AI는 전문 리뷰로 1순위를 정당화하고 커뮤니티 후기로 통증 RTB를 떠받치는 비대칭 구도를 보입니다.

**➊ 토픽 그룹 정의**

| 그룹                                | 묶인 세부 토픽                                                   | AI 응답에서 다뤄진 방식                                |
| ----------------------------------- | ---------------------------------------------------------------- | ------------------------------------------------------ |
| **A. 버티컬 각도 + 손목 중립 테스트** | **버티컬**, **손목이 꺾이는 느낌**, **약 57° 각도**              | 3개 응답 모두 본론 도입부에서 1순위 정당화 근거로 사용 |
| **B. 좌/우 페어 시나리오 운용**       | **좌/우 선택**, **자기 손에 맞는 전용 모델을 고르는 쪽**         | 본론 중반에서 1순위 다음 대안 묶음으로 등장            |
| **C. 엄지 측면 버튼·생산성 부가 기능** | **엄지 측면 버튼**, **엄지가 닿기 쉬운 측면 버튼**               | 3개 응답 모두 한두 줄로만 짧게 처리                    |
| **D. 자세·환경 동반 가이드**          | **1~2주 적응 기간**, **처음 2~3일은 오히려 어색함**              | 응답 후반부 결론 톤에서 적응 가이드로 노출             |

- **대표 해답 자리는 **Logitech MX Vertical**이 통째로 점유한 단일 표준입니다.**
  - **약 57° 각도**·**손목 중립** 근거로 A 그룹 1순위에 올랐고, **크고 무거운 편** 단점이 D 그룹 부정 사례 자리도 끌어다 씁니다.
  - B 그룹 조건부 대안 자리는 **Kensington Pro Fit Ergo Vertical**·**CHERRY MW 4500 LEFT**·**Perixx PERIMICE-713** 좌/우 전용 3종이 분산 점유하고, C 그룹 엄지 측면 버튼은 **MX Vertical**만 부분 점유합니다.
- **전문 리뷰가 1순위를 떠받친 가장 강한 인용 자원이며 커뮤니티 후기·정량 데이터가 보조 RTB로 작동합니다.**
  - **rtings.com**·**pcgamer.com**·**laptopmag.com**·**tomsguide.com** 4개 매체와 **Reddit**·**BGR** 후기, **전완 근육 사용량 약 10% 감소** 자료가 단서를 잠갔습니다.
- **종합** — 1순위 단독 표준과 전문 리뷰·정량 데이터 잠금이 겹쳐 진입 장벽이 매우 높은 구조입니다.

**➍ 자사 진입 가설**

- **구조적 진입 위치** — 대표 해답 자리는 **Logitech MX Vertical**이 잠가 두어 진입 장벽이 높으므로, **B. 좌/우 페어 시나리오** 조건부 대안 자리 또는 **D. 자세·환경 동반 가이드** 미점유 자리부터 선점하는 쪽이 유리합니다.
- **필요 RTB 메시지** — **약 57° 각도** 같은 각도·자세 정량 데이터와 **자기 손에 맞는 전용 모델을 고르는 쪽** 같은 페어 시나리오 단서가 응답에서 결정적으로 작동합니다.
- **확보해야 할 외부 매체 유형** — 전문 리뷰(**rtings.com**·**laptopmag.com** 유형)와 커뮤니티 통증 후기(**Reddit**·**다나와** 유형)를 우선 확보해야 합니다.
