journey_finder_brand

**v. 25.11.07**

### Instruction

주어진 검색어를 보고 이 검색어가 '브랜드 검색어' 인지 판단합니다.  
**'브랜드 검색어'**란 **특정 브랜드** 혹은 **특정 제품/모델**과 직접 연관된 검색어를 말합니다.  
**'브랜드'라는 단어가 포함되어 있더라도, 특정 브랜드를 지칭하는 것이 아니라 일반 명사로서 사용된 경우 (예: 순위, 추천, 종류 등과 결합)에는 '일반 검색어'로 판단합니다.**

주어진 검색어가 '브랜드 검색어' 라면 "brand"에 "True", '일반 검색어'라면 "False"를 반환하세요.  
검색어가 '브랜드 검색어'라면 판단된 "brand part"에 근거가 되는 **검색어의 일부분**을 **추출**하여 함께 반환하세요. (**검색어 그대로 반환하세요.**)  
검색어가 '일반 검색어'라면 "brand part"에 빈 문자열을 반환하세요.

추가 설명 없이 결과만 반환하세요.

**브랜드 검색어:**

- 회사 이름 (예: LG, 삼성)
- 서비스 이름 (예: 유튜브, 넷플릭스)
- 브랜드 이름 (예: 갤럭시, 그램, 아이폰)
- 특정 브랜드의 주요 **제품(모델) 이름** (예: s25, 프로 16)
- 브랜드 이름과 제품군이 결합된 검색어 (예 : 시디즈 게이밍 의자)

**일반 검색어:**

- 일반 제품 카테고리 (예: 스마트폰, 노트북, 세탁기, 냉장고, 세정제, 화장품)
- 일반 명사 (예: 레티놀, 사과)
- **'브랜드'라는 단어가 포함된 일반적인 키워드 (예: 골프 브랜드 순위, 2025 최고의 브랜드)**

**검색 결과:**

- 검색 결과는 검색어의 의미가 모호하거나 특정 제품명인지 확인이 필요할 때만 참고하며, 검색 결과에 포함된 브랜드 키워드로 브랜드 검색어 여부를 판단하지 않습니다.
- 검색어 자체에 특정 브랜드명이 포함되어 있지 않다면, 검색 결과에 브랜드명이 나타나더라도 **일반 검색어**로 판단합니다.

### Output Format

{{
"keyword": str -> 입력의 'keyword' 값을 그대로 복사,
"target_kewyord": str -> 입력의 'target keyword' 값을 그대로 복사,
"brand": bool,
"brand_part": str
}}
