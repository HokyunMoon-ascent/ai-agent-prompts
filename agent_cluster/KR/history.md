- 최신 버전 항목을 맨 위에 추가하는 역순(reverse chronological) 정책을 유지합니다.

### v.0.7.2 — 2026-06-02
**파일**: `v.0.7.2_cf_KR_0602.md` (기준: `v.0.7.1_cf_KR_0602.md`)
**변경 요약**: 입력 키워드는 `버티컬 마우스`였는데 출력이 통째로 `로프리 마우스` 시장으로 나오던(엉뚱한 시드 앵커) 문제 수정. **시드 키워드를 표준 플레이스홀더 `{{keyword}}` 하나로 고정.**
- **원인**: v.0.7.1의 시드 확정이 데이터 휴리스틱("시드=클러스터 A(0번) `h=TRUE` 허브")에 의존 → 혼합/다중 시장 데이터에서 클러스터 A가 입력 키워드라는 보장이 없어, 클러스터 A에 잡힌 다른 제품(로프리)을 시드로 오인. 단일 cf 프롬프트에 사용자 입력 키워드와의 권위 있는 연결 고리(`{{keyword}}`)가 부재했고, 이전 대화(`{{prev_q}}/{{prev_a}}`) 주제로 표류.
- **핵심**: `{{keyword}}`는 리포 표준 플레이스홀더(GEO prompt builder의 "클러스터파인더에 최초 입력된 검색어 = {{keyword}}"). 단일 cf 프롬프트에는 누락돼 있었음.
- **신설**: `### 입력 키워드(분석의 절대 기준)` 블록을 역할 소개 직후(상단)에 추가 — `클러스터파인더에 최초 입력된 검색어 = {{keyword}}`, 시드는 `{{keyword}}` 하나로 고정.
- **`### 단일 시드 키워드 고정 규칙(최우선)` 재작성**: 시드=`{{keyword}}`(절대 기준), `{{keyword}}`에 해당하는 row·클러스터 시장 내부만 분석, 검색량 최댓값·클러스터 A 위치로 시드 교체 금지, 이전 대화 표류 금지, `{{keyword}}` 대응 데이터가 없으면 "대응 데이터 없음" 명시(다른 제품군 임의 분석 금지), `{{keyword}}` 공란일 때만 클러스터 A 허브로 추정(예외).
- 섹션 1 첫 문장 `:k[{{keyword}}]` 단일 시장 선언, 섹션 2 step0/섹션 3 경로 필터를 `{{keyword}}` 기준으로 명확화, 최종 출력 규칙에 `{{keyword}}` 단일 시드 못박음 + 미대응 시 표류 금지.
- **유지**: v.0.7.1의 타 제품군 완전 배제·"OO 시장" 명명 금지. 자가검증 게이트는 계속 미추가(인라인 규칙).
- 표현 다듬기(동작 무관, in-place·버전 범프 없음): 섹션 1의 어색한 "단일 시장의 내부 구조" 선언 문구를 "이번 분석이 :k[{{keyword}}] 한 키워드를 다룬다"는 쉬운 서술로 교체(해석 기준 + Output Format 주석, 3종).
- 검증: KR/JP/EN 3종 구조 패리티(H1=4·H2=22·H3=7·불릿=70·`{{keyword}}` 22회·256행 동일). 구버전 `v.0.7.1_cf_KR_0602.md`는 `_archive/`로 이동.

### v.0.7.1 — 2026-06-02

- **신설**: `### 단일 시드 키워드 고정 규칙(최우선)` — 시드=클러스터 A(0번) 허브(`h=TRUE`), `src` 단일값=단일 입력, 검색량 큰 브랜드/범용어로 시드 교체 금지, 시드 제품 외 타 제품군(키보드·마우스패드·손목보호대·그립) 완전 배제, "OO 시장"/두 번째 키워드 명명 금지.

- 섹션 2 공통 분석 로직에 0번(타 제품군 클러스터 사전 제외) 추가, 섹션 3에 시드 내부 클러스터 간 이동만 사용 규칙 추가.
- 최종 출력 규칙에 단일 시드 1개 시장·타 제품군 미출력·독립 시장 명명 금지 못박음.
- **사용자 결정 반영**: 인접 제품군 = 완전 배제(보조 축 유지 아님), 출력 전 자가검증 게이트 = 추가 안 함(인라인 규칙으로만 강제).
- 검증: KR/JP/EN 3종 구조 패리티(H1=4·H2=22·H3=6·불릿=64·247행 동일). 구버전 `v.0.7.0_cf_KR_0602.md`는 `_archive/`로 이동.
