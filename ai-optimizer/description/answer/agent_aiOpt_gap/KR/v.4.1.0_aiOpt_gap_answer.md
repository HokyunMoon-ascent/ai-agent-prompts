## 1) 브랜드 노출 분석

자사 **MX Vertical** 한 모델만 손목 중립 영역에서 호출됐을 뿐 **Lift**·**MX ERGO** 라인업은 좌/우 페어·엄지 측면 버튼 영역에서 통째로 빠져 있고, AI가 자사 브랜드를 다룰 때에도 근거 인용은 자사 페이지가 아닌 외부 매체에 통제권이 있어 신뢰 단서까지 외부에 끌려가 있는 구도입니다.

**➊ 토픽 그룹 정의**

| 그룹                                   | 묶인 세부 토픽                                                       | 자사 대응 액션                                 |
| -------------------------------------- | -------------------------------------------------------------------- | ---------------------------------------------- |
| **A. 좌/우 페어 시나리오 운용**        | **좌/우 선택**, **자기 손에 맞는 전용 모델을 고르는 쪽**, 좌/우 페어 | **Lift** 왼손·오른손 페어 운용 시나리오 페이지 |
| **B. 엄지 측면 버튼·생산성 부가 기능** | **엄지 측면 버튼**, **추가 엄지 버튼 2개**                           | **MX ERGO** 엄지 버튼 활용 시나리오 가이드     |
| **C. 버티컬 각도 + 손목 중립 테스트**  | **버티컬**, **손목이 꺾이는 느낌**, 손목 중립 즉시 검증              | 자사 라인업 비교형 손목 중립 가이드 콘텐츠     |
| **D. 자세·환경 동반 가이드**           | **책상 높이(팔꿈치 각도)·마우스 간격**, **1~2주 적응 기간**          | Ergo Series 공용 적응·환경 가이드 허브         |
| **E. 신뢰 보강**                       | 외부 매체·실사용 후기, **사용자 테스트 완료. 인체공학자 인증.** 자체 주장, **처음 2~3일은 오히려 어색함** 단점 안내 | 외부 매체·실사용 후기·**1~2주 적응 기간** 회수 허브 |

- **A. 좌/우 페어 시나리오는 경쟁사 3종이 통째로 점유한 가장 큰 진영 격차입니다.**
  - **Kensington Pro Fit Ergo Vertical**·**CHERRY MW 4500**·**Perixx PERIMICE-713**이 **좌/우 전용 모델**로 호출됐고, **왼손, 오른손 어디에나 딱 맞는 Lift**가 페어로 묶이지 못했습니다.
  - B 그룹도 경쟁사 1종(**CHERRY MW 4500**)만 부분 점유한 공백으로 **MX ERGO** 엄지 시나리오가 응답에서 빠져 있고, C 그룹은 자사·경쟁 모두 1/3로 박빙입니다.
- **E. 신뢰 보강 영역도 결정적 공백 — 자사 응답조차 자사 페이지를 인용하지 못해 신뢰 통제권이 외부 매체에 있습니다.**
  - 경쟁사 응답 3종은 자사 페이지·외부 매체 양쪽 모두 인용된 반면 자사 응답은 외부 매체 인용만 작동합니다.
- **부족 신호** — **사용자 테스트 완료. 인체공학자 인증.** 자체 주장만 있고 외부 후기 부재(신호 1) · **Lift** 페어 시나리오 미연결(신호 2).
- **종합** — A·E 영역에서 라인업 인지 단서와 RTB 신뢰 단서가 동시에 비어 결정적 점유 공백이 가장 큰 구조입니다.

## 2) 의미적 갭 매핑

자사 페이지는 **57° 손목이 편한 각도**·**자세 교정** 같은 효익 설명에는 강점이 있지만, AI가 답변에 끌어다 쓰는 좌/우 페어 시나리오·외부 후기·환경 가이드 자리에서 라인업 단위로 비어 있어 **Lift**·**MX ERGO**가 호출되지 못하는 직접 원인이 되고 있습니다.

**➊ 토픽 그룹별 콘텐츠 갭 표**

| 토픽 그룹                              | 콘텐츠 액션                                         | 우선순위  |
| -------------------------------------- | --------------------------------------------------- | :-------: |
| **A. 좌/우 페어 시나리오 운용**        | **Lift** 왼손·오른손 페어 운용 시나리오 페이지 신설 | 🔴 결정적 |
| **E. 신뢰 보강**                       | 외부 매체·실사용 후기·**1~2주 적응 기간** 회수 허브 | 🔴 결정적 |
| **B. 엄지 측면 버튼·생산성 부가 기능** | **MX ERGO** 엄지 버튼 시나리오 가이드               |  🟡 기회  |
| **C. 버티컬 각도 + 손목 중립 테스트**  | 자사 라인업 3종 비교형 손목 중립 가이드             |  🟡 기회  |
| **D. 자세·환경 동반 가이드**           | Ergo Series 공용 적응·환경 가이드 허브              |  🟡 보강  |

> 🔴 결정적 (즉시 제작) · 🟡 기회/보강 (2~3순위)

- **🔴 결정적 액션 2개(A·E)가 가장 시급한 공백 — 자사 0/3 vs 경쟁사 3/3 구도가 동시에 작동합니다.**
  - **왼손, 오른손 어디에나 딱 맞는 Lift**가 페어로 묶이지 못하고, **사용자 테스트 완료. 인체공학자 인증.** 자체 주장만 있고 **처음 2~3일은 오히려 어색함** 같은 단점 안내가 빠져 있습니다.
- **🟡 기회·보강 액션(B·C·D)** — B는 **MX ERGO** 엄지 시나리오로 차별화, C는 1/3 점유라 **Lift**·**MX ERGO** 비교형 가이드로 선점, D는 양 진영 공백이라 환경 가이드 선점 가능합니다.
- **종합** — A·E를 즉시 제작하고 B·C·D는 순차 보강하는 방향이 자사 우선순위입니다.

**➋ 갭 상세 (공통 갭 / 차이 갭 분리)**

각 🔴 결정적 갭마다 다음 7항목을 채웁니다.

- **갭 라벨 (A)**: **Lift** 좌/우 페어 시나리오 페어로 묶기
  - **어떤 자리에서 빠졌는가**: 연관 토픽 연결 부재(1순위) + 구매 직전 상황 단서 부재(보조)
  - **AI가 못 끌어간 원인**: 답변 의도와의 거리 + 표현 다양성 부족
  - **AI 응답 근거**: 응답 1번이 **자기 손에 맞는 전용 모델을 고르는 쪽**을 페어 정답으로 다루며 경쟁사 3종 호출
  - **자사 페이지 점검**: **왼손, 오른손 어디에나 딱 맞는 Lift**는 있으나 페어 시나리오 단위로 묶이지 않음(인접 부재)
  - **필요 엔티티 후보**: **Lift**, **왼손용도 있어요**
  - **필요 토픽 후보**: 좌/우 페어 운용 시나리오 가이드(왼손×오른손 페어 구성 예시)
  - **AI 노출 저해 가설**: 라인업이 단일 제품 페이지에 흩어져 AI가 페어 단서로 묶지 못합니다.
