## 2. 온드미디어 전략 분석가

- image-3.png를 보면, 상단 테이블로 '토픽 그룹'의 타이틀을 주고 있는데, 이게 하단 상세 안내에서 그대로 사용되지 않음.
  예를 들어 'A. 손 크기 측정 및 제품 핏 토픽'이 토픽 그룹명으로 지정되었다면 하단에도 동일한 이름을 사용하기.
- 묶인 세부토픽 및 근거 설명 시 어떤 응답에서 나온 출처인지 명시
- URL이 없을 시
  - 자사 콘텐츠(URL)가 입력되지 않았을 때 **온드미디어 가이드 에이전트**는 기존 문서를 수정하는 '교정' 방식이 아니라, AI 결과 분석을 바탕으로 **새로운 브랜드 지식 구조를 구축하기 위한 전략적 가이드**를 제공합니다.
  - 구체적인 응답 방식과 특징은 다음과 같습니다.
  - **진단에서 전략으로의 전환:** URL이 없으면 내 콘텐츠와의 비교(갭 분석)를 할 수 없으므로, 에이전트는 **AI가 도출한 핵심 구매 요소(KBF)와 응답 프레임을 바탕으로 "어떤 종류의 콘텐츠나 엔티티(Entity)가 새롭게 필요한가"**를 제안합니다.
  - **구조적 가이드 제시:** "이 문장을 이렇게 고쳐라"는 식의 직접적인 지시 대신, AI가 읽기 쉽고 답변으로 활용하기 좋은 **정보 구조(AEO)를 어떻게 설계해야 하는지**에 초점을 맞춥니다.
  - **페이지 구성 방식 판단:** 필요한 정보를 **하나의 페이지에 통합하여 구축할지, 아니면 사용자 편의와 AI의 이해를 돕기 위해 여러 개의 별도 페이지로 분리할지**를 AI가 직접 판단하여 제안합니다.
  - **질문에 답하는 콘텐츠 설계:** AI가 특정 소비자 상황(CEP)에서 우리 브랜드를 호출할 수 있도록, **추상적 주장보다는 구체적인 답변과 비교 가능한 정보**를 담은 온드미디어 구축 방향을 제시합니다.
  - **실행 예시(Action Items)로의 연결:** 가이드 제시에서 그치지 않고, 제안된 구조를 바탕으로 **실제 어떤 식의 콘텐츠를 작성해야 하는지 구체적인 샘플**까지 생성하여 사용자가 즉시 실행에 옮길 수 있도록 돕습니다.
  - 결론적으로 URL이 없을 때의 온드미디어 에이전트는 **"AI 생태계에서 특정 질문의 답으로 선택받기 위해 제로 베이스에서 어떤 온드미디어 지식 구조를 세워야 하는가"**에 대한 나침반 역할을 수행합니다.
