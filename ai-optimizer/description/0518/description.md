  > '허브'라는 표현이 의미하는 것을 알 수 없습니다. '안내 페이지' 정도로 사용할 수 있을 것 같습니다.

[Owned]

1. 개선 제안

- ASIS
  - 자사 페이지가 비어 있는 토픽은 적응 단계 가이드 / 좌·우 페어 운용 / 외부 후기·매체 인용 세 흐름이며, 자사가 제품의 좋은 점을 자세히 설명하고 있는 반면 살지 말지 결정하기 직전에 찾는 정보는 외부 매체로 새고 있어 AI가 자사 페이지를 호명할 단서가 부족합니다. 이 세 흐름을 3개 토픽 그룹으로 묶어 기존 페이지 보강 2건 + 신규 페이지 1건의 정보구조(IA)를 제안합니다.
  - 흡수 방식이라는 표현이 와닿지 않습니다.

- TOBE
  - '자사 페이지가 비어 있는 토픽'이라는 표현보다는, '자사 페이지에서 부족한 토픽'이라는 표현이 더 자연스러울 것 같습니다.
  - '흡수 방식' 대신 '개선 방법'으로 바꾸는 것이 더 명확할 것 같습니다. 흡수라는 표현은 전반적으로 사용되어, 개선이라는 뉘앙스로 모두 변경하세요.
