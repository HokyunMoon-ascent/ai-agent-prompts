- **Three-layer decomposition — Response frame**: the AI interprets the user question as "a problem of reducing wrist pronation load via an angle/posture mechanism"
- **Three-layer decomposition — Brand mention**: :k[Logitech MX Vertical] is positioned as the No. 1 representative answer, and :k[Kensington Pro Fit Ergo Vertical] (47°) and :k[Evoluent VerticalMouse 4] (near-vertical) are placed as alternatives by correction intensity
- **Three-layer decomposition — Evidence citation**: official spec (:k[약 57° 바디 각도]) + media review (:k[rtings.com]) + quantitative effect (:k[전완 근육 사용량 약 10% 감소])
